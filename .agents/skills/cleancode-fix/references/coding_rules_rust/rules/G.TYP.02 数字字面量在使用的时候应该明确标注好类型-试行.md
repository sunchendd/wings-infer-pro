# G.TYP.02 数字字面量在使用的时候应该明确标注好类型-试行

- **规则ID**：b16c9c76-9187-47d4-adb3-9743b313a1c9
- **更新时间**：2025-06-05 04:40:02

**【问题级别】**

提示

**【描述】**

如果数字字面量没有被指定具体类型，那么单靠类型推导，整数类型会被默认绑定为 i32 类型，而浮点数则默认绑定为 f64类型。这可能导致某些运行时的意外。

**【正确示例】**

```
let i = 10u32;
let f = 1.23f32;

```
**【错误示例】**

```
let i = 10; // i32
let f = 1.23; // f64

```
