# G.CTL.03 慎用goto语句

- **规则ID**：4cc66a8f-7058-468c-af76-2cd121d6f9d1
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

goto语句会破坏程序的结构性，goto语句容易导致代码的混乱和不可读性，同时也容易引起一些难以调试的问题。因此，除非必须要使用goto语句，否则不应该使用。

**【正确示例】**

```
##### 场景1：使用了goto语句。
- 修复示例：非必须场景，不应使用goto语句，可使用结构化的控制语句（如if、for、while等）来实现程序逻辑。
    ```go
    for m := 1; m < 5; m++ { // 符合
        fmt.Println(m)
    }
    ```


```
**【错误示例】**

```
##### 场景1：使用了goto语句。
- 错误示例：

    ```go
        m := 1
    LOOP:
        if m < 5 {
            fmt.Println(m)
            m++
            goto LOOP // 不符合：使用了goto语句
        }
    ```


```
**【修复建议】**

1. 如果goto语句不是必须的，不应使用goto语句，可使用结构化的控制语句（如if、for、while等）来实现程序逻辑。

2. 如果goto语句是必须的，不要向上跳转，只能向下跳，可参考[G.CTL.04 goto语句只能向下跳转]。
