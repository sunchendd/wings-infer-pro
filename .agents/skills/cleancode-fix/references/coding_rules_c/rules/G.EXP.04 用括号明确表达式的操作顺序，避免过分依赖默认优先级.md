# G.EXP.04 用括号明确表达式的操作顺序，避免过分依赖默认优先级

- **规则ID**：b24e952f-88b7-4be6-b803-4f26bc7b189a
- **更新时间**：2026-04-07 04:10:03

**【问题级别】**

一般

**【描述】**

当表达式包含不常用，优先级易混淆的操作符时，推荐使用括号。

**【正确示例】**

```
##### 场景1：位操作符没有加括号
- 修复示例：

```cpp
c = (a & 0xFF) + b; // 符合，涉及位操作符，需要括号
```

```
**【错误示例】**

```
##### 场景1：位操作符没有加括号
- 错误示例：

```cpp
c = a & 0xFF + b; // 不符合
```

```
