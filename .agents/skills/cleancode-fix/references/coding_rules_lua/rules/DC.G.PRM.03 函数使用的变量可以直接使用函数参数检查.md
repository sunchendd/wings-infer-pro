# DC.G.PRM.03 函数使用的变量可以直接使用函数参数检查

- **规则ID**：06ecd1fa-5285-41cf-9146-48679e2769df
- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：“xxx”调用的入参可以直接使用函数体定义的传入参数，请调整

**【正确示例】**

```
```
local foo (var1)
    bar(var1) -- 直接使用var1
end
```

```
**【错误示例】**

```
```
local foo (var1)
    local var2 = var1
    bar(var2)
end
```

```
**【修复建议】**

定义函数中无意义的变量赋值会带来不必要的开销，因此应避免定义冗余的函数入参副本
