# G.FMT.12 保持代码紧凑，避免过多空行

- **规则ID**：65521775-63f1-4a68-8d41-c23347777fff
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

1. 大括号内的代码块行首之前和行末之后不要加空行。

2. 函数内部、类型定义内部、宏内部、初始化表达式内部，不同的逻辑之间最多加 1 个空行来分隔。

3. 其它场景代码块之间最多使用连续2个空行来分隔。

**【正确示例】**

```
##### 场景1：大括号内代码块行首空行
- 修复示例：

```cpp
void Foo(int x, int y)
{
    x = 1; // 符合
}
```
##### 场景2：函数内使用连续空行
- 修复示例：

```c
void Foo()
{
    int x;
    int y; // 符合
}
```
##### 场景3：函数返回值判断没有紧跟返回值，两者之间有多余的空行
- 修复示例：

```c
void Foo()
{
    int num = GetNumber();
    if (num == 0) { // 符合
        // ...
    }
}
```
##### 场景4：函数外连续3个空行
- 修复示例：

```c
void Foo1()
{
    // ...
}

void Foo2()  // 符合
{
    // ...
}
```

```
**【错误示例】**

```
##### 场景1：大括号内代码块行首空行
- 错误示例：

```cpp
void Foo(int x, int y)
{

    x = 1; // 不符合，上方多余空行
}
```
##### 场景2：函数内使用连续空行
- 错误示例：

```c
void Foo()
{
    int x;


    int y; // 不符合，函数内连续空行
}
```
##### 场景3：函数返回值判断没有紧跟返回值，两者之间有多余的空行
- 错误示例：

```c
void Foo()
{
    int num = GetNumber();

    if (num == 0) { // 不符合，函数返回值判断需要紧跟返回值
        // ...
    }
}
```
##### 场景4：函数外连续3个空行
- 错误示例：

```c
void Foo1()
{
    // ...
}



void Foo2()  // 不符合，函数外连续三个空行
{
    // ...
}
```
