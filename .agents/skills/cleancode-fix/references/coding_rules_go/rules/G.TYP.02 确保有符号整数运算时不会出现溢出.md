# G.TYP.02 确保有符号整数运算时不会出现溢出

- **规则ID**：28aefaa6-bc72-4ef7-a406-c4de1370b5cf
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

严重

**【描述】**

算术运算导致的溢出可能导致缓冲区溢出、执行任意代码等问题。

因此，对于算术运算（包括加、减、乘、递增和递减）的操作数要进行合理校验，防止出现溢出。

**【正确示例】**

```
##### 场景1：有符号整数参与加法运算前未校验导致溢出
- 修复示例：

```go
func Int_OverFlow_good1() {
    val1 := math.MaxInt64
    val2 := 1
    val3 := 2
    val4 := 3
    if val1 > math.MaxInt64 - val2 - val3 - val4 {
        // 符合：赋值前判断当前数据是否超过目标类型的最大值
        fmt.Println("integer overflow")
        //错误处理
    } else {
        sumValue := val1 + val2 + val3 + val4
        ...
    }
}
```

```
**【错误示例】**

```
##### 场景1：有符号整数参与加法运算前未校验导致溢出
- 错误示例：

```go
func Int_OverFlow_bad1() {
    val1 := math.MaxInt64
    val2 := 1
    val3 := 2
    val4 := 3
    // 不符合: 超过类型最大值，溢出了
    sumValue := val1 + val2 + val3 + val4
    ...
}
```

```
**【修复建议】**

有符号整数运算前进行校验，用以保证算术运算时不会出现溢出。
