# G.FMT.04-01 语句换行时使用左右括号格式检查

- **规则ID**：84f205f3-d14d-4e76-8043-030a9efc4313
- **更新时间**：2026-04-07 04:45:00

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：语句换行时,应该左括号在行末,右括号在行首,“xxx”位置不对

**【正确示例】**

```
```
local a = {             
    100, 200, 300, 400
}  
local a = { 100, 200,   
    300, 400 }
```

```
**【错误示例】**

```
```
local tab= {
    100， 200， 300 }
```

```
**【修复建议】**

如果左括号留在行末，则对应右括号需另起一行

如果左括号被内容跟随，则右括号也应跟随内容
