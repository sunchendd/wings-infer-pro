# G.EXP.41-CPP 避免在基本for循环的循环体中修改循环控制变量

- **规则ID**：8fc667a5-8b30-4574-b56b-4829d55c251f
- **更新时间**：2025-03-25 19:22:40

---

**【问题级别】**

一般

**【描述】**

在for循环体内修改循环控制变量会降低代码的可读性，甚至引发错误。

**【正确示例】**

```
for (int i = 0; i < MAX_COUNT; ++i) {
    std::cout << i;                         // 符合：没有修改控制变量i
}

```
**【错误示例】**

```
for (int i = 0; i < MAX_COUNT; ++i) {
    if (i > specialValue) {
        ++i;                                // 不符合：修改了控制变量i
    }
    std::cout << i;
}

```
**【修复建议】**

尽量将对循环变量的修改放在for语句中
