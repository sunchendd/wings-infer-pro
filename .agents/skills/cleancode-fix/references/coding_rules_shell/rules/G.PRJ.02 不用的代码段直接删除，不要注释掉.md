# G.PRJ.02 不用的代码段直接删除，不要注释掉

- **规则ID**：c6bcbb17-6e73-4584-8034-8ae78e488598
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

1. 被注释掉的代码，无法被正常维护；当企图恢复使用这段代码时，极有可能引入易被忽略的缺陷。

2. 正确的做法是，不需要的代码直接删除掉。若再需要时，考虑移植或重写这段代码。

**【正确示例】**

```
```shell
#!/bin/bash
read -rs passwd
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 不符合：不用的代码段直接删除，不要注释掉
#passwd=$1
read -rs passwd
```

```
**【修复建议】**

删除注释掉的代码。
