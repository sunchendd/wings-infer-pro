# G.CGO.04 避免直接将C代码嵌入在Go文件中

- **规则ID**：6ff726e9-3621-4238-80fd-df83e9058a5c
- **更新时间**：2026-04-07 04:20:00

---

**【问题级别】**

一般

**【描述】**

C代码和Go代码在同一个文件中，代码耦合度高、不利于维护、隔离性差。

因此，建议C代码和Go代码在不同文件中，将对应的C文件编译打包为静态库或动态库文件供Go文件使用。

**【正确示例】**

```
##### 场景1：C代码和Go代码在同一个文件中。
- 修复示例：建议C代码和Go代码在不同文件中，将对应的C文件编译打包为静态库或动态库文件供Go文件使用。

```go
// foo.h
int sum(int a, int b)
```


```
**【错误示例】**

```
##### 场景1：C代码和Go代码在同一个文件中。
- 错误示例：

    ```go
    package main

    /*
    static int sum(int a, int b) {
        return a + b;
    }
    */
    import "C"

    func main() {
        println(C.sum(1, 1)) // 不符合： sum函数源码也在Go文件中
    }
    ```


```
**【修复建议】**

建议C代码和Go代码在不同文件中，将对应的C文件编译打包为静态库或动态库文件供Go文件使用。
