# G.EXP.36-CPP 控制表达式的结果应是布尔值

- **规则ID**：a4b4af7e-95b9-4f97-8f1b-2a58b0aa0820
- **更新时间**：2025-03-25 19:23:52

---

**【问题级别】**

一般

**【描述】**

使用强类型可以减少编程风险，控制表达式的结果必须是布尔值或者如下表达式的运算结果：



关系表达式< <= >= >

相等类表达式== !=

逻辑表达式&& || !

使用控制表达式的语句包括：



if语句

while语句

do语句

for语句

**【正确示例】**

```
int value = ...
if (value != 0) {       // 符合： 使用的是逻辑表达式
    ...
}
while (true) {          // 特殊场景中可以使用布尔类型常量  
    ...
}
char* p = ...
if (p != nullptr) {     // 符合
    ...
}

```
**【错误示例】**

```
int value = ...
if (value) {            // 不符合： 不是布尔类型变量
    ...
}

```
**【修复建议】**

（1）变量类型修改为bool类型，或者（2）条件表达式使用比较操作符
