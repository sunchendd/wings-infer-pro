# G.CMT.01-CPP 注释符与注释内容间留有1个空格

- **规则ID**：b56ce600-41e8-4849-bf84-008e1869a78c
- **更新时间**：2025-03-25 19:21:44

---

**【问题级别】**

一般

**【描述】**

注释符与注释内容之间留有1个空格。

注释符包括： /* */和 //。

**【正确示例】**

```
##### 场景1：注释符与注释内容之间没有空格
- 修复示例：

```cpp
// 单行注释         // 符合

/* 单行注释 */     /* 符合 */

// 以下通过“/*”与“*/”多行注释，符合规则
/*
 * 多行注释
 * 第二行
 */

// 以下通过“//”多行注释，符合规则
// 另外一种多行注释
// 第二行
```

```
**【错误示例】**

```
##### 场景1：注释符与注释内容之间没有空格
- 错误示例：

```cpp
//单行注释          //不符合

/*单行注释*/      /*不符合*/

/*
 *多行注释
 *第二行
 */

//另外一种多行注释
//第二行
```

```
**【修复建议】**

按要求增加/减少空格
