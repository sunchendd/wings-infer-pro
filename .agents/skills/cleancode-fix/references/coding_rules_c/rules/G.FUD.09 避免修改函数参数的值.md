# G.FUD.09 避免修改函数参数的值

- **规则ID**：77053df5-a2f0-48f5-986c-b84ea795756d
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

不应该修改函数参数的值，否则可能发生无法预期的错误。

**【正确示例】**

```
##### 场景1：修改函数参数值
- 修复示例：

```c
int Func(int input, int *output)
{
    int x = input;
    x += 1; // 符合，使用x作为工作变量
    return x;
}
```

```
**【错误示例】**

```
##### 场景1：修改函数参数值
- 错误示例：

```c
int Func(int input, int *output)
{
    input += 1; // 不符合，input值被修改
    return input;
}
```

```
**【修复建议】**

使用单独的局部变量作为工作变量。
