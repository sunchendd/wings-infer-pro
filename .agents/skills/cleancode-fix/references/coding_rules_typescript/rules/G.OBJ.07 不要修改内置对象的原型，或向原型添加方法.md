# G.OBJ.07 不要修改内置对象的原型，或向原型添加方法

- **规则ID**：4316b5ec-dd94-4e47-a573-7fa1d1bb6f59
- **更新时间**：2026-04-07 04:35:02

---

**【问题级别】**

一般

**【描述】**

修改内置对象的原型，可能会破坏接口语义，引入意想不到的问题。

**【正确示例】**

```
##### 场景1：原型
- 修复示例：不修改原型方法，自定义属于自己的方法。

```javascript
function indexOfBySelf = function (a) {    // 自定义属于自己的方法
  ...
  return -1;
}

// 其它地方使用的时候
const arr = [1, 1, 1, 1, 1, 2, 1, 1, 1];
console.log(indexOfBySelf(2)); // 输出-1

```

```
**【错误示例】**

```
##### 场景1：原型
- 错误示例：直接修改内置对象的原型方法。

```javascript
Array.prototype.indexOf = function () {    // 不符合，直接修改
  ...
  return -1;
}

// 其它地方使用的时候
const arr = [1, 1, 1, 1, 1, 2, 1, 1, 1];
console.log(arr.indexOf(2)); // 输出-1

```

```
**【修复建议】**

永远不要修改内置对象的原型，或向原型添加方法。
