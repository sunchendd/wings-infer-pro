# G.PRJ.01 脚本中不能使用~作为当前用户路径，需使用$HOME变量

- **规则ID**：9e720aa4-ac3a-4cd4-b7d2-247843a63e66
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

脚本中不能使用~作为当前用户路径，需使用$HOME变量。

**【正确示例】**

```
```shell
#!/bin/bash
ls "$HOME"  # $HOME变量能在引号中正确展开
ls ~/
```

```
**【错误示例】**

```
```shell
#!/bin/bash
ls "~/"
# 运行报错 ls: cannot access '~/': No such file or directory
```

```
**【修复建议】**

1. 使用$HOME变量代替引号中的~/。

2. ~/放到引号外。
