# G.TYP.01 不要重复定义基础类型

- **规则ID**：99e2d8d6-8502-4dda-af53-af6932ed0689
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

严重

**【描述】**

避免滥用 typedef/#define 对基本类型起别名。

**【正确示例】**

```
##### 场景1：重复定义基础类型

```
**【错误示例】**

```
##### 场景1：重复定义基础类型
- 错误示例：

```cpp
typedef unsigned int uint32_t; // 不符合
```

```
**【修复建议】**

删除重新定义的基础类型，建议优先使用符合C99，C11标准定义的类型（如：在一个产品中统一使用stdint.h中定义的整数类型）。
