# G.VAR.04 多变量赋值语句，最后一个变量不可以是哑变量

- **规则ID**：2d1e9bf5-3fe0-4843-a10b-f33577ae6a14
- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

一般

**【描述】**

行号：xxx，列号：xxx: 多变量赋值语句xxx最后一个变量不可以是哑变量

**【正确示例】**

```
```
_, a = f1()     -- OK: 忽略第1个返回值
```

```
**【错误示例】**

```
```
_, _ = f1()     -- Bad: 单独使用占位符，毫无意义
_ = f2()        -- Bad!
```

```
**【修复建议】**

不需要处理返回值，直接忽略即可。

例：

f1()            -- Good: 忽略返回值

f2()            -- Good: 忽略返回值
