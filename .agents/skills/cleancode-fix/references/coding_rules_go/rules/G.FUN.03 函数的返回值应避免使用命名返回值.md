# G.FUN.03 函数的返回值应避免使用命名返回值

- **规则ID**：a6c30219-fd47-40e4-87ef-8a70ff6c8556
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

不要仅仅为了避免在函数内声明变量而使用命名返回值，这是以不必要的API的冗长为代价来换取一个次要的实现简洁性。因此，函数的返回值应避免使用命名返回值。

**【正确示例】**

```
##### 场景1：使用命名返回值，导致存在冗余的信息
- 修复示例：

  ```go
  func (n *Node) Good() (*Node, error) // 符合
  ```


```
**【错误示例】**

```
##### 场景1：使用命名返回值，导致存在冗余的信息
- 错误示例：

  ```go
  func (n *Node) Bad() (node *Node, err error) // 不符合：命名的返回值与其类型存在冗余的信息
  ```


```
**【修复建议】**

函数的返回值直接采用类型返回值。
