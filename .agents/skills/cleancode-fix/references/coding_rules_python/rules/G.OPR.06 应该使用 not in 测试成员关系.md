# G.OPR.06 应该使用 not in 测试成员关系

- **规则ID**：27c6d5fd-bbea-4887-a338-580929ccbf37
- **更新时间**：2026-04-07 04:15:01

---

**【问题级别】**

一般

**【描述】**

使用`x not in the_list`而不是`not x in the_list`来测试成员关系，这样可以提升代码可读性和一致性，后者会导致代码可读性变差。

**【正确示例】**

```
##### 场景1：测试成员关系
- 修复示例：通过not in来测试成员关系
```python
if item not in items:
    ...
```


```
**【错误示例】**

```
##### 场景1：测试成员关系
- 错误示例：通过not取反来测试成员关系
```python
if not item in items:
    ...
```


```
**【修复建议】**

使用 not in和in来测试成员关系。
