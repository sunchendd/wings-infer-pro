# G.CTL.02 避免在循环体中修改循环控制变量

- **规则ID**：716f25b1-592c-4604-bf27-e1ecf305e7e5
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

严重

**【描述】**

如果在循环体的操作中修改循环控制参数的数值，可能导致循环退出条件永远达不到（死循环）或者循环执行次数不符合预期。

因此，不建议在循环体中修改循环变量。

**【正确示例】**

```
##### 场景1：在循环体中修改循环变量
- 修复示例：重构代码，使之符合不要在循环体中修改循环变量`i`的规则

    ```go
    func main() {
        for i := 0; i < 10; i++ {
            ...
        }
    }
    ```

```
**【错误示例】**

```
##### 场景1：在循环体中修改循环变量
- 错误示例：存在异向修改，循环将执行多少次取决于代码中if的条件在循环过程中的满足情况，很可能永远无法退出循环
    ```go
    func main() {
        for i := 0; i < 10; i++ {
            ...
            if ... {
                i -= 2  // 不符合
            }
        }
    }
    ```

```
**【修复建议】**

不在循环体中修改循环变量。
