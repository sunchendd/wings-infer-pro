# G.EXP.02 用括号明确表达式的操作顺序，避免过分依赖默认优先级

- **规则ID**：49f189d1-69ac-43bc-8916-39959d4dd464
- **更新时间**：2026-04-07 04:40:01

---

**【问题级别】**

提示

**【描述】**

并不是每个人都能记得住优先级，所以最好使用括号把优先级顺序区分出来，增加可读性。

**【正确示例】**

```
```
(1 << 2) + 3
(-1i32).abs()
```

```
**【错误示例】**

```
```
1 << 2 + 3
-1i32.abs()
```

```
**【修复建议】**

宜使用括号强调表达式的优先级顺序，增加可读性，防止开发者因不熟悉默认的优先级而导致错误。
