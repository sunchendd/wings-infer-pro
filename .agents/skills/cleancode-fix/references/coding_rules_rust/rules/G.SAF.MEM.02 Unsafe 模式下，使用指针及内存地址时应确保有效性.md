# G.SAF.MEM.02 Unsafe 模式下，使用指针及内存地址时应确保有效性

**【描述】**

在 Unsafe Rust 中，通过裸指针方式申请分配内存应注意：



- **指针解引用前应确保指向的内存已初始化**

 

    访问未初始化内存会导致未定义行为。



- **FFI函数调用返回的指针应先检查是否为空再使用**

 

    解引用空指针会导致程序崩溃。



- **不应将局部变量的栈地址返回到作用域之外**

 

    栈内存会在函数返回后被回收，访问会导致未定义行为。



- **指针指向的内存释放后禁止继续访问**



    指针指向的内存释放后，继续通过指针访问会导致未定义行为。
