# G.EXP.01 表达式的比较，应该遵循左侧倾向于变化、右侧倾向于不变的原则

- **规则ID**：94ef5a53-285e-4e9a-ab78-90b5c3716fb8
- **更新时间**：2026-04-07 04:25:02

---

**【问题级别】**

提示

**【描述】**

当变量或方法调用与常量比较时，如果常量放左边，如 if (MAX == v) 不符合阅读习惯，而 if (MAX > v) 更是难于理解。应该按人的正常阅读、表达习惯，将常量放右边。

**【正确示例】**

```
##### 场景1：表达式
- 修复示例：不变的值置于右侧。
```javascript
if (color === 'red') {
  // ...
}
```

```
**【错误示例】**

```
##### 场景1：表达式
- 错误示例：不变的值放在了左侧。

```javascript
if ('red' === color) {
  // ...
}
```

```
**【修复建议】**

表达式的比较，倾向于不变的值应该置于右侧。
