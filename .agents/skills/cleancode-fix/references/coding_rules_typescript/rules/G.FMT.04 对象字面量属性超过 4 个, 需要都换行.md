# G.FMT.04 对象字面量属性超过 4 个, 需要都换行

- **规则ID**：d177e901-9ec6-4e32-a8e2-460fc3911617
- **更新时间**：2025-06-05 04:35:00

---

**【问题级别】**

提示

**【描述】**

对象字面量要么每个属性都换行, 要么所有属性都在同一行。当对象字面量属性超过4个的时候，建议统一换行。

**【正确示例】**

```
const yourObj = {
  name: 'a',
  age: 'b',
  value: 'c',
  bar: 'd',
  foo: 'e',
  ha: 'f',
};

```
**【错误示例】**

```
const yourObj = { name: 'a', age: 'b', value: 'c', bar: 'd', foo: 'e', ha: 'f' };

```
**【修复建议】**

对象字面量属性超过 4 个, 需要都换行
