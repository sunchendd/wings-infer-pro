# G.FMT.06 把 else/catch 放在 if/try 代码块关闭括号的同一行

- **规则ID**：e87bdb73-ac36-4cfb-9449-f1bcf12918e6
- **更新时间**：2025-06-05 04:35:03

---

**【问题级别】**

提示

**【描述】**

在写条件语句时，建议把 else 放在 if 代码块关闭括号的同一行。同样 ，在写异常处理语句时，建议把catch 也放在 try 代码块关闭括号的同一行。

**【正确示例】**

```
if (isOk) {
  doThing1();
  doThing2();
} else {
  doThing3();
}

```
**【错误示例】**

```
if (isOk) {
  doThing1();
  doThing2();
}
else {
  doThing3();
}

```
**【修复建议】**

在写条件语句时，建议把 else 放在 if 代码块关闭括号的同一行。同样 ，在写异常处理语句时，建议把catch 也放在 try 代码块关闭括号的同一行。
