# G.TYP.01 确保除法运算和模运算中的除数不为0

- **规则ID**：cda9e63f-634c-4b66-a7dd-a4525c2bfd77
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

确保除法运算和模运算中的除数不为0。

**【正确示例】**

```
```shell
#!/bin/bash
a=2
b=0

function f1(){
    echo $((a/b))
}
if [[ b -ne 0 ]];then
    f1
fi
```

```
**【错误示例】**

```
```shell
#!/bin/bash
a=2
b=0

function a(){
    echo $((a/b))
}
a
```

```
**【修复建议】**

1. 获取运算表达式除数的值，判断运算表达式节点中除数是否为0。

2. 若运算表达式中除数为0，则判断运算表达式外层的测试语句中是否对除数变量0值判断。

3. 如果运算表达式在函数体内，若函数内层未判断除数是否为0，则需要判断函数调用处是否有判断。
