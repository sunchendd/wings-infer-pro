# G.VAR.06 禁止将局部变量的地址传递到其作用域外

- **规则ID**：8d0e5cae-9dd9-432a-a176-5acf9eca79b9
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

严重

**【描述】**

当指针指向的对象到达其生存期结束时，指针的值将变得不确定，此时访问该指针会导致访问到无效的内存地址，进而导致程序产生未定义行为。

因此，在访问对象的地址时，应禁止将该地址传递到此对象的作用域外。

**【正确示例】**

```
##### 场景1：将局部变量的地址传递到其作用域外
- 修复示例：重构函数返回值类型，使其返回一个整数值。

    ```c
    char GoodCase01()
    {
        char c = 0;
        // 符合
        return c;
    }
    char GoodCase02()
    {
        char c = 0;
        char *p = &c;
        ...
        // 符合
        return *p;
    }
    ```


```
**【错误示例】**

```
##### 场景1：将局部变量的地址传递到其作用域外
- 错误示例：函数返回了局部变量的地址，在调用处解引用该指针程序会产生未定义行为。

    ```c
    char* BadCase01()
    {
        char c = 0;
        // 不符合： return局部变量地址
        return &c;
    }
    char* BadCase02()
    {
        char c = 0;
        char *p = &c;
        ...
        // 不符合： return指针指向局部变量地址
        return p;
    }
    ```


```
**【修复建议】**

应该避免在作用域外访问变量的地址，可以通过将变量的值传递到作用域外部来避免这种问题。
