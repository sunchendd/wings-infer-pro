# G.CTL.01 控制表达式的结果应是布尔值

- **规则ID**：c7731c4b-e9cc-492c-a720-0b9192ab5369
- **更新时间**：2026-04-07 04:10:01

---

**【问题级别】**

严重

**【描述】**

使用强类型可以减少编程风险，控制表达式的结果应是布尔值或者如下表达式的运算结果：

关系表达式（< 、 <= 、 >= 、 >）、相等类表达式（== 、 !=）、逻辑表达式（&& 、 || 、 !）。



使用控制表达式的语句包括：if 语句、while 语句、do 语句、for 语句。

**【正确示例】**

```
##### 场景1：控制表达式结果为int
- 修复示例：

```c
int value = ...
if (value != 0) { // 符合
    ...
}
```


```
**【错误示例】**

```
##### 场景1：控制表达式结果为int
- 错误示例：

```c
int value = ...
if (value) { // 不符合：不是布尔类型变量
    ...
}
```


```
**【修复建议】**

控制表达式（if、while、do、for）的结果应是布尔值以及如下表达式的运算结果：

- 关系表达式（< 、 <= 、 >= 、 >）

- 相等类表达式（== 、 !=）

- 逻辑表达式（&& 、 || 、 !）。
