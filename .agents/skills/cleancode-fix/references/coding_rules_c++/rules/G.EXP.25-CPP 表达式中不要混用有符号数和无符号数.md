# G.EXP.25-CPP 表达式中不要混用有符号数和无符号数

- **规则ID**：cfe26d62-b2c1-47ae-a602-369a2145db16
- **更新时间**：2025-03-25 19:23:14

---

**【问题级别】**

一般

**【描述】**

在表达式中混用有符号数和无符号数时，可能会因隐式转换而导致非预期的结果。因此应尽量在表达式中使用相同符号类型的变量。

对于无法使用相同符号类型的场景，应将不同类型的变量显式转换为相同类型，当表达式中的无符号数隐式转换为另一个有符号数类型时，如果这个有符号数类型能够完全涵盖无符号数类型的值域，则可以不做显式类型转换，如：int32 = uint8。

本条款所涉及的混用有符号数和无符号数的场景包括：二元操作符的左、右操作数（不包括逻辑运算和按位运算）以及三元操作符的二、三操作数。

**【正确示例】**

```
使用相同类型
unsigned int GetLength();

void Test_good01()
{
    unsigned int signX = 0;
    //右值为函数返回值，与左值类型一致
    signX = GetLength();
}

```
**【错误示例】**

```
如下代码中，混用有符号数和无符号数，可能期望输出-1，但是实际输出0。

uint32_t x = 1;
int32_t y = -1;

std::cout << x / y << std::endl; // 不符合：混用有符号数和无符号数的结果可能是非预期的

```
**【修复建议】**

使用相同的数值类型，避免类型转换错误。不要混用有符号数和无符号数。202206版本7月小版本开始，1.添加开关"report_sizeof_strlen"默认true打开检查运算式中sizeof、strlen函数(不检查赋值语句)。

2.添加开关"report_enum"默认true打开，检查枚举有无符号类型。

3.添加开关"report_type_promotion"默认true打开，考虑运算式中的类型提升(32位以下类型混用可不告警)。false不考虑类型提升，仅检查原始类型有无符号是否混用。
