# G.TYP.03 确保参与移位的操作数的位数足够

- **规则ID**：fcf2f6a6-11c9-4c95-9dba-dbabff8d0e6c
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

严重

**【描述】**

进行移位操作时，自动推导出的类型宽度有可能小于实际对移位结果进行（比较）运算所要求的宽度。

因此，确保移位的左操作数是无符号数，且参与移位的操作数的位数足够。

**【正确示例】**

```
##### 场景1：自动推导出的类型宽度小于实际对移位结果进行（比较）运算所要求的宽度。
- 修复示例：
    ```go
    func foo(num uint16, bits uint8) bool {
        if uint32(num) > uint32(1) << bits { // 符合
            return true
        }
        return false
    }
    func main() {
        fmt.Print(foo(65535, 16))
    }
    ```


```
**【错误示例】**

```
##### 场景1：自动推导出的类型宽度小于实际对移位结果进行（比较）运算所要求的宽度。
- 错误示例：
    ```go
    func foo(num uint16, bits uint8) bool {
        // 不符合：这里(1 << bits) 将被推导为uint16类型，可被移位操作回绕
        if num > (1 << bits) {
            return true
        }
        return false
    }
    func main() {
        fmt.Print(foo(65535, 16))
    }
    ```


```
**【修复建议】**

确保移位的左操作数是无符号数，且参与移位的操作数的位数足够。
