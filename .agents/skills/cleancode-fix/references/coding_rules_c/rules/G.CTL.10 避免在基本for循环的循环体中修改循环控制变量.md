# G.CTL.10 避免在基本for循环的循环体中修改循环控制变量

- **规则ID**：19f2c854-fd43-455a-86fe-21d2add5264e
- **更新时间**：2026-04-07 04:10:02

---

**【问题级别】**

一般

**【描述】**

在for循环体内修改循环控制变量会降低代码的可读性，甚至引发错误。



因此在for循环体内，禁止修改循环控制变量。

**【正确示例】**

```
##### 场景1：在for循环体内改变循环控制变量。
- 修复示例1：在for语句中，改变i += 2。

```c
for (uint32_t i = 0; EXT_CARD_COUNT != 0 && i <= EXT_CARD_COUNT; i += 2) {
    Foo(i);  // 符合：循环体内没有修改循环控制变量 i
}
```


```
**【错误示例】**

```
##### 场景1：在for循环体内改变循环控制变量。
- 错误示例：

```c
for (uint32_t i = 0; i < EXT_CARD_COUNT; ++i) {
    if (i % 2 != 0) {
        i++;  // 不符合：循环体内修改循环控制变量 i
    }
    Foo(i);
}
```


```
**【修复建议】**

将对循环变量的修改放在for语句中。
