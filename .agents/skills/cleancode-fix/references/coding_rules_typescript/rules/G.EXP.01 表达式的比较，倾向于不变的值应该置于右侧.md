# G.EXP.01 表达式的比较，倾向于不变的值应该置于右侧

- **规则ID**：3ca5f620-d048-4911-ba71-b7cf79d0be56
- **更新时间**：2025-06-05 04:35:01

---

**【问题级别】**

提示

**【描述】**

当变量或方法调用与常量比较时，如果常量放左边，如 if (MAX == v) 不符合阅读习惯，而 if (MAX > v) 更是难于理解。应该按人的正常阅读、表达习惯，将常量放右边。

**【正确示例】**

```
if (color === 'red') {
  // ...
}

```
**【错误示例】**

```
if ('red' === color) {
  // ...
}

```
**【修复建议】**

表达式的比较，倾向于不变的值应该置于右侧
