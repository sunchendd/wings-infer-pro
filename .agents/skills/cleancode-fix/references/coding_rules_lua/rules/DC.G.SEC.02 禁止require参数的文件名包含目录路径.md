# DC.G.SEC.02 禁止require参数的文件名包含目录路径

- **规则ID**：f396b2b1-ccc3-4b91-9ca2-2722d824980a
- **更新时间**：2026-04-07 04:45:01

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：require的参数必须是文件基名（不含路径/后缀）："xxx"

**【正确示例】**

```
```
require("base")
```

```
**【错误示例】**

```
```
require("../../base")
```

```
**【修复建议】**

数通产品对运行于设备上的Lua文件的存放目录进行了统一规划，参数中使用目录路径不仅没有必要，而且还会增加不安全文件的注入风险，因此禁止require参数的文件名包含目录路径
