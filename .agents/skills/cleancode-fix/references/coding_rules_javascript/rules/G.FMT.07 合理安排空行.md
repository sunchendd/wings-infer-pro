# G.FMT.07 合理安排空行

- **规则ID**：28b1d8f4-f64e-47ab-aeef-be95055e3487
- **更新时间**：2025-06-05 04:25:00

---

**【问题级别】**

提示

**【描述】**

使用空行可以凸显出代码块的相关程度，能提升代码的可读性。

**【正确示例】**

```
const obj = {
  foo() {},

  bar() {},
};

```
**【错误示例】**

```
const obj = {
  foo() {},
  bar() {},
};

```
**【修复建议】**

使用空行可以凸显出代码块的相关程度，能提升代码的可读性。
