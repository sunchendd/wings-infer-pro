# G.FMT.08 用空格突出关键字和重要信息

- **规则ID**：3e72d83f-45af-4b5c-bffb-05444c788890
- **更新时间**：2026-04-07 04:35:00

---

**【问题级别】**

提示

**【描述】**

空格应该突出关键字和重要信息。

**【正确示例】**

```
// if 和左括号之间加一个空格
if (isJedi) {
  fight();
}

```
**【错误示例】**

```
// if 和左括号 ( 之间没有加空格
if(isJedi) {
  fight ();
}

```
**【修复建议】**

空格应该突出关键字和重要信息。
