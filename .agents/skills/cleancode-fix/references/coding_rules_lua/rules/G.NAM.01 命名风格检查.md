**【问题级别】**

一般

**【描述】**

行号：xxx，列号：xxx：“xxx”命名不符合规范，函数名必须以小写字母开头

**【正确示例】**

```
```
some_net_func
```

```
**【错误示例】**

```
```
Some_net_func
```

```
**【修复建议】**

所谓 snake_case，即 lower_case_with_underscores，用下划线来分割多个全小写单词
