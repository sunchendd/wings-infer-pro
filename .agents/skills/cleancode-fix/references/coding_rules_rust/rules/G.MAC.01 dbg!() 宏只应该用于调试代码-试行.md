# G.MAC.01 dbg!() 宏只应该用于调试代码-试行

- **规则ID**：05b66391-89ca-4491-afa1-6da5015f4164
- **更新时间**：2025-06-05 04:40:03

---

**【问题级别】**

提示

**【描述】**

dbg!() 宏是 Rust 内置的宏，其目的是用于调试代码，仅用于 Debug 模式。不要将含有 dbg! 宏的代码加入到版本控制下。



将其用在 Release 模式下，调试信息也会被打印出来，不安全。

**【正确示例】**

```
// Debug 模式编译
let foo = false;
dbg!(foo); 
// Release 模式编译
let foo = false;
// dbg!(foo);

```
**【错误示例】**

```
// Release 模式编译
let foo = false;
dbg!(foo);

```
