# G.SEC.06 禁止在代码中的PATH环境变量中添加相对路径

- **规则ID**：1f170349-89dd-44d6-a053-1d82abb4e965
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

不使用相对或绝对路径的方式执行，该命令就会从系统当前 PATH 中去寻找，如果 PATH 包含“.”和“..”，则当用户不小心进入了一个恶意目录，就有可能执行到恶意目录下的命令，导致权限提升，造成安全隐患。比如攻击者在一个目录下埋藏了一些与系统命令同名的木马、病毒程序，如果 PATH 设置不当，在用户执行系统命令的时候，就有可能会执行这些恶意程序。

**【正确示例】**

```
```shell
#!/bin/bash
PATH=/work_dri/executable:${PATH}
ls -l
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 不符合：如果当前目录下有名为ls的可执行文件，ls命令会调用当前目录下的文件
PATH=.:${PATH}
ls -l
```

```
**【修复建议】**

在脚本中修改PATH环境变量时必须使用绝对路径。
