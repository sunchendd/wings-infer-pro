# G.FMT.09 每行不超过一个语句

提示

**【描述】**

一行应只写一条语句。

**【正确示例】**

```
##### 场景1：多个语句放在一行
- 修复示例1：每行只放一个语句，合理进行断行

  ```java

  int bb;
  ```


```
