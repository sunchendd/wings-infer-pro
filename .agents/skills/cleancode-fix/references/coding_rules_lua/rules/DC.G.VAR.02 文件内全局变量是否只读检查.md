# DC.G.VAR.02 文件内全局变量是否只读检查

- **规则ID**：f7d8ef1a-10f5-4ae7-9494-1fc162d3e46a
- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：文件内的全局变量：“xxx”必须只读，定义在第xx行、第xx列

**【正确示例】**

```
```
local v1 = 1 -- OK: 新定义了文件作用域的local变量 v1
...
v1 = 2       -- OK: 未在函数中修改 v1
```

```
**【错误示例】**

```
```
local function foo()
    v1 = 2   -- Bad: 在函数 foo 中对文件作用域的local变量 v1 进行了修改
en
```

```
**【修复建议】**

文件内全局变量不要修改
