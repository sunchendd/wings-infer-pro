# G.NAM.01 标识符应由不超过64字符的字母、数字和下划线组成

- **规则ID**：c4b894b2-c1fc-4f4c-a371-e78f13a9d27e
- **更新时间**：2026-04-07 04:00:05

---

**【问题级别】**

提示

**【描述】**

变量名应该只以字母数字下划线组成，且长度在[1,maxLength]之间。maxLength的默认值是64，可动态配置（上限是64）。

**【正确示例】**

```
##### 场景1：标识符里包含了除字母、数字和下划线之外的其他字符
- 修复示例：
  ```java
  int num; // 【GOOD】去掉标识符里面的$符号
  ```


```
**【错误示例】**

```
##### 场景1：标识符里包含了除字母、数字和下划线之外的其他字符
- 错误示例：
  ```java
  int num$;  // 【不符合】标识符里面含有$符号
  ```


```
**【修复建议】**

删除变量名称中的不合规字符或缩短变量名长度。
