# G.EXP.22-CPP 确保除法和余数运算不会导致除零错误(被零除)

- **规则ID**：eeb67e67-a6e4-465a-81e5-b9ea2e35e438
- **更新时间**：2025-03-25 19:23:37

---

**【问题级别】**

一般

**【描述】**

整数的除法运算或取余运算的除数为0会导致程序产生未定义的行为。如果涉及到除法或者取余运算，必须确保除数不为0。



在二进制浮点数算术标准ISO/IEEE Std 754-1985中规定了浮点数被零除的行为及结果，但是仍然取决于程序所运行的软硬件环境是否遵循该标准。

因此，在做浮点数被零除的运算前，应确保软硬件环境已遵循二进制浮点数算术标准，否则仍然存在未定义行为。

**【正确示例】**

```
如下代码中，添加a是否为0的校验，防止除零错误。

size_t a = ...          // 来自外部数据
if (a == 0) {
    ... // 错误处理
}
size_t b = 1000 / a;    // 符合：确保a不为0
size_t c = 1000 % a;    // 符合：确保a不为0
…

```
**【错误示例】**

```
size_t a = ...          // 来自外部数据
size_t b = 1000 / a;    // 不符合：a可能是0
size_t c = 1000 % a;    // 不符合：a可能是0
...

```
**【修复建议】**

校验作为除数的值，确保不为0
