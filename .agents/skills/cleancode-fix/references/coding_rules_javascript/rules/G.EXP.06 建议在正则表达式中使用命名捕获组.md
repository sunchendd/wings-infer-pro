# G.EXP.06 建议在正则表达式中使用命名捕获组

- **规则ID**：9c832e86-713c-4b92-ad65-c3eb9c1e6470
- **更新时间**：2025-06-05 04:25:01

---

**【问题级别】**

提示

**【描述】**

随着 ECMAScript 2018 的发布，命名捕获组可以用于正则表达式中，这可以提高正则表达式的可读性。

**【正确示例】**

```
const foo = /(?<id>ba[rz])/;

```
**【错误示例】**

```
const foo = /(ba[rz])/;

```
**【修复建议】**

建议在正则表达式中使用命名捕获组
