# G.TYP.05 确保整数转换不会造成数据截断或符号错误

- **规则ID**：2c600d17-8373-4f74-a18c-bd8fb8113a5f
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

严重

**【描述】**

将一个较大整型转换为较小整型，并且该数的原值超出较小整型的表示范围，就会发生截断错误，原值的低位被保留而高位被丢弃。截断错误会引起数据丢失，甚至可能引发安全问题。特别是将运算结果用于以下用途：



作为数组索引

作为对象的长度或者大小

作为数组的边界（如作为循环计数器

**【正确示例】**

```
func foo() {

   var a int32 = math.MaxInt32

   var b int16

   // 【修改】进行校验以确保在进行类型转化时不会产生截断

   if (a < math.MinInt16) || (a > math.MaxInt16) {

       // 错误处理

  } else {

       b = int16(a)

  }

   // 后面索引等代码略……

}

```
**【错误示例】**

```
func foo() {

   var a int32 = math.MaxInt32

   b := int16(a) // 【错误】不同类型强制转化会发生数据截断

   // 后面索引等代码略……

}

```
**【修复建议】**

当不同数据类型强制转化时需要校验数据的范围，以确定是否会发生数据的丢失。
