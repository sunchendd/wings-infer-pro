# G.EDV.03 确保用于数组和slice的下标不越界

- **规则ID**：8ebfcd68-3aef-4045-ab71-2511feb90d3d
- **更新时间**：2026-04-07 04:20:03

---

**【问题级别】**

严重

**【描述】**

如果函数和方法是公开的（API）、有时甚至是内部的函数和方法（见正确示例5），当需使用它的参数索引数组和切片时（数组、切片可以是全局的、或内部的、甚至传入的数组和切片），应确保此参数在合法索引的范围，不会导致越界。此类参数必须通过if等语句加以判断，不满足合法索引范围时返回错误，或不执行相应的操作，或返回合理的结果。



在调用者与被调函数/方法共同使用某个数组或切片情形下，调用者需要使用外部方法/函数的返回值，如需要使用返回值直接索引此数组或切片的（不继续做其他运算）。一般：1、外部API约定了错误值，可由判断错误值，来保证返回值可用于在合法范围内索引；2、外部API如果约定使用int复用索引结果值和出错情况的，应判断索引值>=0（一般会约定-1表示出错，建议在使用索引结果值时，用>=0做判断），才可以进行索引。3、如需间接索引，比如有加一或减一等运算，先应依照前面两条判断返回值合法，再应判断其间接索引的值在数组和切片的合法范围，才可以进行索引。



对于模块内部的私有函数实现，如果在任意的外部调用流程下，此模块内部实现均可确保参数或变量，在数组和切片合法访问范围内，则可直接使用它索引数组和切片，而无需冗余判断索引的范围。



主要需要注意以下两点：



1、对从外部输入或计算的值，如需要用于数组和切片索引，必须确保此值的范围在数组和切片的索引范围内。

2、代入并验证循环边界的范围，以保证不越界访问数组和切片。

**【正确示例】**

```
```
var buffer [BUFSIZ]byte var i = 0

for i = 0; i < BUFSIZ-1; i++ { // 【正确】循环上界可保证合法访问数组

   buffer[i] = buffer[i+1]

}
```

```
**【错误示例】**

```
```
var buffer [BUFSIZ]byte var i = 0

for i = 0; i < BUFSIZ; i++ { // 【错误】循环的上界可导致数组越界访问

   buffer[i] = buffer[i+1]

}
```

```
**【修复建议】**

1、对从外部输入或计算的值，如需要用于数组和切片索引，必须确保此值的范围在数组和切片的索引范围内。



2、代入并验证循环边界的范围，以保证不越界访问数组和切片。
