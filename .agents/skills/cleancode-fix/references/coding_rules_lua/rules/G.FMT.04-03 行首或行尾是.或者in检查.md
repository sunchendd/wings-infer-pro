# G.FMT.04-03 行首或行尾是.或者in检查

- **规则ID**：53ec80a7-ca12-4a3a-8368-8de42d0cfd06
- **更新时间**：2026-04-07 04:45:00

---

**【问题级别】**

一般

**【描述】**

行号：xxx，列号：xxx：'.'或者'in'不可以出现在行首或行尾

**【正确示例】**

```
```
local tab.nestedTable = { ... }
```

```
**【错误示例】**

```
```
local tab.
nestedTable = { ... }
local tab
.nestedTable = { ... }
```

```
**【修复建议】**

不要以.或in开始或者结尾一行
