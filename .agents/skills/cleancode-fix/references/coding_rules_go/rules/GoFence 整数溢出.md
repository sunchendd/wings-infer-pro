# GoFence 整数溢出

- **规则ID**：d0423163-af7b-4bc5-a3f5-469c2e16b0bc
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

计算机中各整数类型都有一个宽度，有最大值-最大值范围。当试图保存超过该范围的数据时，有符号数就会发生整数溢出

**【正确示例】**

```
```
func Foo(a, b int32) {
    var c int32 // 正确：添加校验确保不会发生整数溢出
    if (b > 0 && a > (math.MaxInt32-b)) || (b < 0 && a < (math.MinInt32-b)) {
        fmt.Println("溢出错误处理代码")
    } else {
        c = a + b
        fmt.Println(c)
    }
}
```

```
**【错误示例】**

```
```
下面代码中假设a为16位最大的整数，b为大于0的任意16位整数，两者相加可能会产生符号溢出。
func Foo() {
    var a int16 = math.MaxInt16
    var b int16 = 2
    var c int16 = a + b
    fmt.Println("c=", c)
    fmt.Println("a=", a)
    // 输出结果  ： c= -32767  a= 32767
}
```

```
**【修复建议】**

在有符号整数加法运算之前添加校验，确保不会产生溢出。---------------------参考华为go语言编程规范3.1
