# G.FMT.15-CPP 声明中的非类型描述符应该在类型描述符左边

- **规则ID**：504f8019-2e2b-4a5b-8e7f-a4b254154437
- **更新时间**：2025-03-25 19:21:57

---

**【问题级别】**

一般

**【描述】**

非类型描述符放在类型描述符的左边，更符合阅读习惯。

**【正确示例】**

```
static int i;       // 符合：static 放在 int 左边
virtual void Fun(); // 符合：virtual 放在 void 左边

```
**【错误示例】**

```
int static i;       // 不符合
void virtual Fun(); // 不符合

```
**【修复建议】**

将非类型描述符放在左边
