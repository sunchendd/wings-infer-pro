# G.DCL.02 避免使用全局变量

- **规则ID**：8ba7b507-aa28-455e-86f9-c851da719325
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

使用全局变量会导致业务代码和全局变量之间产生数据耦合，并且很难跟踪数据的变化，应避免使用全局变量，且禁止将全局变量导出。

**【正确示例】**

```
##### 场景1：导出的全局变量可能导致并发问题
- 修复示例1：将其改为不导出的全部变量，并检查该变量是否存在并发读写问题

  ```go
  // 符合：全局变量未导出
  var mySumValue uint = 0
  ```


```
**【错误示例】**

```
##### 场景1：导出的全局变量可能导致并发问题
- 错误示例：

  ```go
  // 不符合：全局变量禁止导出
  var MySumValue uint = 0
  ```


```
**【修复建议】**

改为局部变量或者不导出
