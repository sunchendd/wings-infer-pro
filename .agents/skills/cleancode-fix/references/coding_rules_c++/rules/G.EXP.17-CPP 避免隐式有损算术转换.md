# G.EXP.17-CPP 避免隐式有损算术转换

- **规则ID**：3741f183-2920-402f-8e90-e6ac9d71371c
- **更新时间**：2025-03-25 19:23:09

---

**【问题级别】**

一般

**【描述】**

有损算术转换会导致数据丢失或者解释错误，当发生隐式有损算术转换时，其结果可能非预期的，且错误不易察觉。

如果实际场景中必须要做有损的转换处理时，应当明确使用c++类型转换操作（如：static_cast）将数据转换到指定的类型。

**【正确示例】**

```
【正例】
考虑是否必须要做有损的算术转换，如非必要，宜使用相同类型。
long b = 512;
long y = b; // 符合

【正例】
在必须做数据有损的算术转换时，应明确使用显式类型转换。
double a = 1.5;
int i = static_cast<int>(a); // 符合

```
**【错误示例】**

```
double a = 1.5;
long b = 512;
int c = 512;

int i = a;                   // 不符合：窄化
signed char x = a;           // 不符合：窄化
signed char y = b;           // 不符合：窄化
signed char z = c;           // 不符合：窄化

```
**【修复建议】**

如果实际场景中必须要窄化处理，需要在代码中用c++类型转换操作(例如static_cast)明确转换，避免隐式转换。
