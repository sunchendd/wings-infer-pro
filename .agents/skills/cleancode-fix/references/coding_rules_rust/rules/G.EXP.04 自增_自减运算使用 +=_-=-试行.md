# G.EXP.04 自增/自减运算使用 +=/-=-试行

- **规则ID**：2790aad3-36b9-4ace-8651-7582d0c2bfcf
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

一般

**【描述】**

C/Cpp 等编程语言常用的自增自减操作，如 ++i 、i++ 、i-- 等不是合法的 Rust 表达式， --i 虽然是合法的 Rust 表达式，但是表达对i取反两次，而不是自减语义。

**【正确示例】**

```
let mut x = 3;
x -= 1; // x == 2

```
**【错误示例】**

```
let mut x = 3;
--x; // x == 3

```
