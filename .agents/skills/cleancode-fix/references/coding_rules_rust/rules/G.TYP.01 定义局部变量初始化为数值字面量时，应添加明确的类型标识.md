# G.TYP.01 定义局部变量初始化为数值字面量时，应添加明确的类型标识

- **规则ID**：70e3e4ae-73cf-43ed-9607-a7b62c653c3f
- **更新时间**：2026-04-07 04:40:00

---

**【问题级别】**

一般

**【描述】**

如果数值字面量没有被指定具体类型，那么单靠类型推导，整数类型会被默认绑定为 i32 类型，而浮点数则默认绑定为 f64 类型。这可能导致某些运行时的意外，比如因为类型预期错误，导致应该在编译期发现的问题遗留到运行时，比如导致数据计算溢出等问题。

**【正确示例】**

```
let i = 10i32;
let f = 1.23f64;

```
**【错误示例】**

```
let i = 10;
let f = 1.23;

```
**【修复建议】**

数值字面量要添加明确的类型标识
