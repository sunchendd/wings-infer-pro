# G.OTH.03 不用的代码段直接删除，不要注释掉

- **规则ID**：aebd7b9d-bd40-4fa6-b5be-bac924fd7475
- **更新时间**：2025-06-05 04:35:02

---

**【问题级别】**

一般

**【描述】**

被注释掉的代码，无法被正常维护；当企图恢复使用这段代码时，极有可能引入易被忽略的缺陷。



无效或永不执行的代码（即无效代码或无法访问的代码）通常是编程错误的结果，并且可能导致意外行为。



正确的做法是，不需要的代码直接删除掉。若再需要时，考虑移植或重写这段代码。无效或永不执行的代码应及时识别，删除或修正。

**【正确示例】**

```
不用的代码段直接删除，不要注释掉

```
**【错误示例】**

```
mModel.reloadIcons();
// if (!mModel.isAllAppsLoaded()) {
//   function make(tag) {
//     return element;
//   }
// }

```
**【修复建议】**

不用的代码段直接删除，不要注释掉
