# DC.G.EXP.02 多值赋值语句中左值右值个数不匹配

- **规则ID**：49ca6733-43a0-4567-9343-bddd7af8be48
- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

一般

**【描述】**

行号：xxx，列号：xxx：赋值语句xxx中,左右值个数不相等,右值个数为xxx

**【正确示例】**

```
```
local a, b = 10, 20 local a = 10
```

```
**【错误示例】**

```
```
local a, b = 10, 20, 30
local a, b = 10
```

```
**【修复建议】**

多赋值语句中左值和右值个数必须相匹配
