# G.CMT.02 注释行与下方代码没有保持相同缩进

- **规则ID**：8fca67e8-f143-4c1c-b2a9-7b575b12cf45
- **更新时间**：2026-04-07 04:45:01

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：置于代码上方的注释行应与下方代码缩进相同，置于代码行右侧的注释换行时应保持'--'对齐

**【正确示例】**

```
```
if exp then 
    -- 这里是注释
    ...
end
```

```
**【错误示例】**

```
```
if exp then 
-- 这里是注释
    ...
end
```

```
**【修复建议】**

注释行与下方代码保持相同缩进
