# G.MEM.BOX.02 一般情况下，不要直接对已经在堆上分配内存的类型进行 Box 装箱-试行

- **规则ID**：795a828f-8354-449d-a5dc-86798f34fb9c
- **更新时间**：2025-06-05 04:40:03

---

**【问题级别】**

一般

**【描述】**

像 Vec<T> / String 这样的类型，已经在堆上分配了内存。就没有必要再使用 Box<T> 对其进行装箱操作，这样没有任何好处。当然也存在例外情况。

**【正确示例】**

```
struct X {
    values: Vec<Foo>,
}

```
**【错误示例】**

```
struct X {
    // Vec已在堆上分配了内存
    values: Box<Vec<Foo>>,
}

```
