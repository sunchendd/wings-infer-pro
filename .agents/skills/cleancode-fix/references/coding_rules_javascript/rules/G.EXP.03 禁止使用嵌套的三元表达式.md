# G.EXP.03 禁止使用嵌套的三元表达式

- **规则ID**：36bd7e33-5442-45d7-8141-5385a5391e5e
- **更新时间**：2026-04-07 04:25:01

---

**【问题级别】**

一般

**【描述】**

嵌套的三元表达式使代码更加难以理解。因此，应使用条件语句来代替嵌套的三元表达式。

**【正确示例】**

```
##### 场景1：三元表达式
- 修复示例：使用条件语句

```javascript
if (foo) {
  if (baz === qux) {
    quxx();
  } else {
    foobar();
  }
} else {
  bar();
}
```

```
**【错误示例】**

```
##### 场景1：三元表达式
- 错误示例：使用嵌套的三元表达式

```javascript
foo ? baz === qux ? quxx() : foobar() : bar();
```

```
**【修复建议】**

使用条件语句来代替嵌套的三元表达式。
