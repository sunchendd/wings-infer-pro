# G.FMT.14 不应插入多余空格使代码垂直对齐

- **规则ID**：a0219d71-8c21-4ee6-8177-a4950431c0fb
- **更新时间**：2026-04-07 04:00:01

---

**【问题级别】**

提示

**【描述】**

代码中的JavaDoc注释性描述内容前，不应该通过空格的方式使注释垂直对齐。



如果描述长短差异较大，无规律插入的空白呈凹凸状，并不美观；

另外对后续的维护者可能会困扰是否在有必要刻意追求对齐

**【正确示例】**

```
```java
    private int size;
    private String name;
```

```
**【错误示例】**

```
```java
    private int    size; // 维护者可能不得不修改这些对齐空格数
    private String name; // 不必与上行对齐注释
```

```
**【修复建议】**

推荐使用HiCode的codecheck插件的检查和修复功能，或使用开源项目EasyCode中的代码格式化模板对代码进行格式化处理。
