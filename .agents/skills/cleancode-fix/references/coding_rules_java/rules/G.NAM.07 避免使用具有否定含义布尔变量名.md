# G.NAM.07 避免使用具有否定含义布尔变量名

- **规则ID**：a83d4cb9-bba2-42ad-b961-ad204a119aff
- **更新时间**：2026-04-07 04:00:01

---

**【问题级别】**

提示

**【描述】**

布尔型变量使用否定含义的变量名，会增加代码理解的难度，尤其是再对该变量进行逻辑非运算，如`!isNotError`。

**【正确示例】**

```
##### 场景1：boolean型变量名中不能含有no或者not
- 修复示例：
  ```java
  boolean isError; // 【GOOD】去掉标识符里面的no
  ```


```
**【错误示例】**

```
##### 场景1：boolean型变量名中不能含有no或者not
- 错误示例：
  ```java
  boolean isNoError; // 【不符合】标识符里含有no
  ```


```
**【修复建议】**

修改变量名，去除否定含义的单词。
