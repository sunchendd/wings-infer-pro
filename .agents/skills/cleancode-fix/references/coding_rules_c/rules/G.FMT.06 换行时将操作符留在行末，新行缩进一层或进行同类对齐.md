# G.FMT.06 换行时将操作符留在行末，新行缩进一层或进行同类对齐

- **规则ID**：2aba8962-31a9-426b-9c22-78be259f26a7
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

换行时二元操作符放在行末。

**【正确示例】**

```
##### 场景1：换行时二元操作符放在行首
- 修复示例：

```c
void Func(int32_t val1, int32_t val2)
{
    int32_t sum = val1 + // 符合：换行时'+'位于行末
        val2;
}
```

```
**【错误示例】**

```
##### 场景1：换行时二元操作符放在行首
- 错误示例：

```c
void Func(int32_t val1, int32_t val2)
{
    int32_t sum = val1
        + val2; // 不符合：换行时'+'位于行首
    ...
}
```

```
**【修复建议】**

换行时将二元操作符放在行末。
