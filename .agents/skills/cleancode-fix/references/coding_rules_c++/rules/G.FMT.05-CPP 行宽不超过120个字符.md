# G.FMT.05-CPP 行宽不超过120个字符

- **规则ID**：c7c7b309-c3bb-4de8-b5f0-28c9281fcbb2
- **更新时间**：2025-03-25 19:21:50

---

**【问题级别】**

一般

**【描述】**

代码行宽不宜过长，否则不利于阅读。

控制行宽可以间接的引导程序员去缩短函数、变量的命名，减少嵌套的层数，提升代码的可读性。

建议每行字符数不要超过 120 个；除非超过 120 能显著提升可读性，并且不会隐藏信息。
