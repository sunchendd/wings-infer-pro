# 安全TOP问题-使用scrypt算法计算口令单向哈希时，内存占用参数至少为2^14、盐值至少16字节、块规模参数至少为8、并行化参数至少1，输出长度不少于256比特

- **规则ID**：fe0e4cd9-e9ae-4bb8-9094-cc0836915d64
- **更新时间**：2025-03-25 19:24:00

---

**【问题级别】**

一般

**【描述】**

使用scrypt算法计算口令单向哈希时，内存占用参数至少为2^14、盐值至少16字节、块规模参数至少为8、并行化参数至少1，输出长度不少于256比特，若违反这些条件则告警

**【正确示例】**

```
void test_good_case(const SEC_UCHAR *passwd, 
     size_t passwdlen, 
     const SEC_UCHAR *salt,
     SEC_UCHAR *result)
{
 size_t saltlen = 16;
 SEC_UINT64 N_ = pow(2,14);
 SEC_UINT32 r_ = 8;
 SEC_UINT32 p_ = 1;
 size_t rlen = 32;

 ipsi_scrypt(passwd,passwdlen,salt,saltlen,N_,r_, p_,result,rlen);
}

```
**【错误示例】**

```
void test_bad_case(const SEC_UCHAR *passwd, 
    size_t passwdlen, 
    const SEC_UCHAR *salt,
    SEC_UCHAR *result)
{
 size_t saltlen = 5; /*盐值不足16字节*/
 SEC_UINT64 N_ = pow(2,13); /*内存占用参数不足2^14*/
 SEC_UINT32 r_ = 7; /*块规模参数不足8*/
 SEC_UINT32 p_ = 0; /*并行化参数不足1*/
 size_t rlen = 31; /*输出长度不足256=32*8*/

 ipsi_scrypt(passwd, passwdlen, salt, saltlen, N_, r_, p_, result, rlen);
}

```
**【修复建议】**

参照《安全及隐私保护设计检视Checklist_v3.0》对应子检查项D-CAS-24-2：使用scrypt算法计算口令单向哈希时，内存占用参数至少为2^14、盐值至少16字节、块规模参数至少为8、并行化参数至少1，输出长度不少于256比特。
