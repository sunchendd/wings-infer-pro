# G.DCL.01 不要声明或定义保留的标识符

- **规则ID**：346d709f-0a71-467f-a231-76dfa59f8cd3
- **更新时间**：2026-04-07 04:10:02

---

**【问题级别】**

严重

**【描述】**

不要声明或定义保留的标识符。

规则当前检查的保留的标识符有：双下划线开头，或下划线加一个大写字母开头的所有标识符。

**【正确示例】**

```
##### 场景1：定义双下划线开头的标识符
- 修复示例：

```c
#define FUNC // 符合
```
##### 场景2：定义单下划线加一个大写字母开头
- 修复示例：

```c
#ifndef HEADER // 符合
#define HEADER

#endif
```


```
**【错误示例】**

```
##### 场景1：定义双下划线开头的标识符
- 错误示例：

```c
#define __FUNC__ // 不符合，双下划线的，或者以单下划线加一个大写字母开头的标识符，为实现保留
```
##### 场景2：定义单下划线加一个大写字母开头
- 错误示例：

```c
#ifndef _HEADER_ // 不符合，单下划线加一个大写字母开头
#define _HEADER_

#endif
```


```
**【修复建议】**

修改标识符名称。
