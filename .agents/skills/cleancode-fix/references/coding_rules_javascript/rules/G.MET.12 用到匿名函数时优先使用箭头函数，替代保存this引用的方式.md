# G.MET.12 用到匿名函数时优先使用箭头函数，替代保存this引用的方式

- **规则ID**：322876d1-5915-4aa4-b9b9-76e129bc7a1e
- **更新时间**：2026-04-07 04:25:01

---

**【问题级别】**

一般

**【描述】**

箭头函数提供了更简洁的语法，并且箭头函数中的this对象指向是不变的，this绑定到定义时所在的对象，有更好的代码可读性。而保存this引用的方式，容易让开发人员搞混。

**【正确示例】**

```
##### 场景1：匿名函数
- 修复示例：用到匿名函数时优先使用箭头函数。

```javascript
foo(a => a)
```

```
**【错误示例】**

```
##### 场景1：匿名函数
- 错误示例：匿名函数未使用箭头函数

```javascript
foo(function(a) { 
  return a;
});
```

```
**【修复建议】**

用到匿名函数时优先使用箭头函数。
