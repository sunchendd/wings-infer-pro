# G.CMT.04 注释符与注释内容间要有1个空格

- **规则ID**：71af5681-54e6-4ed7-a1ac-df794215d4da
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

注释符包括： `/*` `*/`和 `//`。注释符与注释内容之间留有1个空格。

**【正确示例】**

```
##### 场景1：注释符与注释内容之间无空格
- 修复示例1：在注释符与注释之间加空格

```go
// 符合：注释符和注释之间有一个空格

// 单行注释

/* 单行注释 */
```


```
**【错误示例】**

```
##### 场景1：注释符与注释内容之间无空格
- 错误示例：

```go
//不符合：注释符和注释之间无空格

//单行注释

/*单行注释*/
```


```
**【修复建议】**

保证注释符与注释内容之间要有至少一个空格
