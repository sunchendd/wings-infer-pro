# G.TYP.01 确保无符号整数运算时不会回绕

- **规则ID**：8ab84bff-626d-4864-922f-6ca9b5b5f2d8
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

严重

**【描述】**

所谓“回绕”是指无法用无符号整数表示的运算结果，这个结果将会根据该类型可以表示的最大值加1执行求模操作。

后续代码如以此作为分配内存的大小，将导致申请的内存比实际所需过小（或者过大，从而导致内存不足）的问题。

因此，将运算结果用于以下之一的用途，应防止回绕：

- 作为数组、slice的索引

- 作为待申请数组变量的大小

- 作为数组、slice的边界（如作为循环计数器）

**【正确示例】**

```
##### 场景1：相加时会产生无符号整数回绕现象。
- 修复示例：在运算之前添加较验。
    ```go
    func Uint_Inversion() {
        var a uint16 = math.MaxUint16
        var b uint16 = 1
        var b1 uint16 = 1
        var b2 uint16 = 1
        var d uint16
        if a + b + b1 + b2 > math.MaxUint16 {
            //符合：添加校验确保不会发生整数溢出
            fmt.Println("Uint inversion")
            // 错误处理
        } else {
            d = a + b + b1 + b2
            fmt.Println(d)
        }
    }
    ```


```
**【错误示例】**

```
##### 场景1：相加时会产生无符号整数回绕现象。
- 错误示例：
    ```go
    func Uint_Inversion {
        var a uint16 = math.MaxUint16
        var b uint16 = 1
        var b1 uint16 = 1
        var b2 uint16 = 1
        // 超过类型最大值，出现了反转
        d := a + b + b1 + b2 // a为最大值，告警
        fmt.Println(d)
    }
    ```


```
**【修复建议】**

1. 在运算之前添加校验，确保不会产生无符号数回绕。

2. 考虑变量类型是否合理，不合理的要调整变量类型。
