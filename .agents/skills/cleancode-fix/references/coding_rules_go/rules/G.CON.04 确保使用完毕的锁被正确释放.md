# G.CON.04 确保使用完毕的锁被正确释放

- **规则ID**：f4ff05e7-8006-41f1-b920-bf5fcd2c6cbc
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

使用完锁后应及时释放锁，否则会导致其他goroutine在获取该锁时发生阻塞。

在错误或异常条件下，程序可能会提前退出，退出前要确保正确释放当前持有的锁。

**【正确示例】**

```
##### 场景1：加锁后未释放
- 修复示例：加锁后正确解锁
    ```go
    var m sync.Mutex

    func main() {
        var x sync.Mutex
        x.Lock()
        ...
        x.Unlock()  // 符合：使用完解锁
    }
    ```


```
**【错误示例】**

```
##### 场景1：加锁后未释放
- 错误示例：加锁后未释放
    ```go
    var m sync.Mutex

    func main() {
        var x sync.Mutex
        x.Lock()  // 加锁后，一直未解锁
        ...
    }
    ```


```
**【修复建议】**

使用完锁后应及时释放锁。

在错误或异常条件下，程序可能会提前退出，退出前要确保正确释放当前持有的锁。
