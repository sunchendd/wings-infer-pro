# G.UNS.PTR.02 禁止将不可变指针手工转换为可变指针-试行

- **规则ID**：dd42727c-93ee-448c-9733-72b6309b939a
- **更新时间**：2025-06-05 04:40:04

---

**【问题级别】**

严重

**【描述】**

因为将不可变指针手工转换为可变指针可能会引发未定义行为。通常有这种需求，合法的手段是使用 UnsafeCell<T>。

**【正确示例】**

```
use std::cell::UnsafeCell;
fn x(r: &UnsafeCell<i32>) {
   unsafe {
       *r.get() += 1;
   }
}

```
**【错误示例】**

```
fn x(r: &i32) {
    unsafe {
        *(r as *const _ as *mut _) += 1;
    }
}

```
