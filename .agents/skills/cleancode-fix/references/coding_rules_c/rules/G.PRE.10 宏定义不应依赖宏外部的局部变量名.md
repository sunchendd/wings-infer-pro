# G.PRE.10 宏定义不应依赖宏外部的局部变量名

- **规则ID**：27c63041-a947-4ede-b698-4b517bb0e276
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

严重

**【描述】**

宏定义中要使用的变量都要求作为参数传递给宏。

如果宏定义中直接使用宏外部的局部变量名，会导致宏的可重用性差，而且不利于理解。

**【正确示例】**

```
##### 场景1：宏依赖外部局部变量
- 修复示例1：

```c
// 符合：将需要引用的局部变量作为宏参数传递进来
#define INIT(ret, x) do { \
    ret = (x)->y->length; \
} while (0)

...
INIT(count, msg);
```
- 修复示例2：

```c
// 符合：将宏定义中引用外部局部变量的代码分离出去
#define INIT(x) ((x)->y->length)

...
int count = INIT(msg);
```


```
**【错误示例】**

```
##### 场景1：宏依赖外部局部变量
- 错误示例：

```c
// 不符合：宏依赖外部局部变量count
#define INIT(x) do { \
    count = (x)->y->length; \
} while (0)

...
int count;
INIT(msg);
```


```
**【修复建议】**

1. 将需要引用的局部变量作为宏参数传递进来。

2. 将宏定义中引用外部局部变量的代码分离出去。
