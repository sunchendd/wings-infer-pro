# G.PRE.04 禁止把带副作用的表达式作为参数传递给函数式宏

- **规则ID**：53cc2a39-a7fd-45f0-bd8b-800241e1e6a3
- **更新时间**：2026-04-07 04:10:02

---

**【问题级别】**

严重

**【描述】**

由于宏只是文本替换，对于内部多次使用同一个宏参数的函数式宏，将带副作用的表达式作为宏参数传入会导致非预期的结果。

**【正确示例】**

```
##### 场景1：递增表达式作为宏参数
- 修复示例：

```c
#define ADD_TWICE(x, y) ((x) + ((x) + (y)) + (y))

int Fun(int a, int b)
{
    a++;
    return ADD_TWICE(a, b); // 符合
}
```
##### 场景2：递减表达式作为宏参数
- 修复示例：

```c
#define SQUARE(a) ((a) * (a))

int Fun(int a)
{
    a--;
    return SQUARE(a); // 符合
}
```

```
**【错误示例】**

```
##### 场景1：递增表达式作为宏参数
- 错误示例：

```c
#define ADD_TWICE(x, y) ((x) + ((x) + (y)) + (y))

int Fun(int a, int b)
{
    return ADD_TWICE(a++, b); // 不符合：a++有副作用
}
```
##### 场景2：递减表达式作为宏参数
- 错误示例：

```c
#define SQUARE(a) ((a) * (a))

int Fun(int a)
{
    return SQUARE(a--); // 不符合：a--有副作用
}
```

```
**【修复建议】**

不要将带副作用的表达式作为宏的参数。
