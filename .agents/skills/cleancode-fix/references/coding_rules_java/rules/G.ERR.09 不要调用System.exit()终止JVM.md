# G.ERR.09 不要调用System.exit()终止JVM

- **规则ID**：30630d01-8765-4172-b2b9-5c8e9c9f25df
- **更新时间**：2026-04-07 04:00:04

---

**【问题级别】**

一般

**【描述】**

让 Web 应用程序试图关闭自身的容器并不是什么好主意。调用终止方法的操作可能包含在遗忘调试代码中，或者包含在从非 J2EE 应用程序导入的代码中。

**【正确示例】**

```
public void testGood() {
    ...
    // 不要调用终止方法
}

```
**【错误示例】**

```
public void exit() {
    // ...省略
    
    /* POTENTIAL FLAW: 不要调用System.exit(). */
    System.exit(1);
}

```
**【修复建议】**

不要在 Web 应用程序中调用终止方法。
