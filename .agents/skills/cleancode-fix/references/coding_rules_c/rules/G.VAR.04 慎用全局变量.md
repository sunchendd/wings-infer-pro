# G.VAR.04 慎用全局变量

- **规则ID**：e84cbbeb-8fba-4bcc-862c-728794ce7db7
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

使用全局变量会导致业务代码和全局变量之间产生数据耦合，并且很难跟踪数据的变化，建议避免使用全局变量。

  #define HUAWEI_GLOBAL_VARIABLE_AS_INTERFACE_H

  int g_var; // 不符合：使用全局变量
  int g_init = 10; // 不符合：使用全局变量
  extern double g_value; // 不符合：使用全局变量

**【修复建议】**

尽量不用或少用全局变量。

如不可避免需要使用全局变量，需要注意：

- 对于不会被修改的全局变量，应将其定义为全局常量。

- 全局变量的读写宜集中封装。

- 全局变量避免作为模块接口使用。
