# G.TYP.07 不要在数组上定义或使用非数字属性（length 除外）

- **规则ID**：c5a30c79-4d38-440e-95ee-cc4160785edc
- **更新时间**：2025-06-05 04:35:01

---

**【问题级别】**

一般

**【描述】**

在JavaScript中，数组也是对象，可以往数组上添加属性，但为了处理方便和避免出错，数组只应该用来存储有序（即索引连续）的一组数据。必须要添加属性时，考虑用Map或者Object替代。

**【正确示例】**

```
const map = new Map();
map.set('key1', 'val1');
map.set('key2', 'val2');

```
**【错误示例】**

```
const myHash = [];
myHash['key1'] = 'val1';
myHash['key2'] = 'val2';
myHash[0] = '222';

```
**【修复建议】**

不要在数组上定义或使用非数字属性（length 除外）
