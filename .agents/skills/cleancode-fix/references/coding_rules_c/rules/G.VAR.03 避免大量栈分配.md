# G.VAR.03 避免大量栈分配

- **规则ID**：bf236dba-f139-464a-9a1a-412d6e9abb65
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

栈的大小是有限的，如果局部变量定义过大、过多，那么会使用大量的栈内存，可能导致出现栈溢出错误。

**【正确示例】**

```
##### 场景1：局部变量占用空间过大，可能导致栈空间不够。
- 修复示例：通过动态分配内存的方式，避免栈空间占用过大的问题。

```c
#define MAX_BUFF 0x1000000
void GoodCase1()
{
    // 符合
    char *buf = (char *)malloc(MAX_BUFF);
    if (buf == NULL) {
        ... // 错误处理
    }
    ...
}
```
##### 场景2：一个函数内所有局部变量整体占用空间过大，可能导致栈空间不够。
- 修复示例：通过动态分配内存的方式，避免栈空间占用过大的问题。

```c
#define BUFF (10000 - 10)
void GoodCase2()
{
    // 符合
    char *buf1 = (char *)malloc(BUFF);
    if (buf1 == NULL) {
        ... // 错误处理
    }
    char *buf2 = (char *)malloc(BUFF);
    if (buf2 == NULL) {
        ... // 错误处理
    }
    ...
}
```


```
**【错误示例】**

```
##### 场景1：局部变量占用空间过大，可能导致栈空间不够。
- 错误示例：

```c
#define MAX_BUFF 0x1000000
void BadCase1()
{
    // 不符合
    char buff[MAX_BUFF] = {0};
    ...
}
```
##### 场景2：一个函数内所有局部变量整体占用空间过大，可能导致栈空间不够。
- 错误示例：

```c
#define BUFF (10000 - 10)
void BadCase2()
{
    // 不符合： 总体占用栈空间超过可配置的最大数量
    char a1[BUFF];
    char a2[BUFF];
    ...
    char a25[BUFF];
    char a26[BUFF];
}
```


```
**【修复建议】**

建议在定义函数局部变量时(特别是递归调用、循环体中定义变量)，需要充分考虑单个函数及全调用栈的开销，并对函数中的局部变量大小进行一定限制，如果局部变量占用内存过大，可通过动态分配内存的方式申请堆内存，避免因占用过多的栈空间导致程序运行失败。
