# G.CMD.02 正确使用find命令exec参数(试点)

- **规则ID**：750848e8-8cb2-40c7-baa8-eec69fc94f0b
- **更新时间**：2025-06-05 04:30:00

---

**【问题级别】**

严重

**【描述】**

* exec参数后面跟command执行命令，以; 为结束标志。且在; 前最好增加\ 避免被Shell扩展。    

* 如果需要执行Shell组合操作命令，比如 cat {} | wc -l ，需要指定sh或者bash，后接-c参数，将命令用引号包起来。  

* 如果有多个匹配条件且是逻辑或的关系（-o选项）时，需要使用"\\( \\)"格式包含匹配条件，如果是逻辑与的关系不需要"\\( \\)" 格式。

**【正确示例】**

```
#!/bin/bash
  find . -type f -exec file {} \;

```
**【错误示例】**

```
#!/bin/bash
  # 执行失败，没有加 \;
  find . -type f -exec file {}
  find . -type f -exec file {} ;

```
**【修复建议】**

* exec参数后面跟command执行命令，使用"\;"作为结束标志

* 执行Shell组合操作命令，使用sh/bash -c进行执行

* 如果有多个匹配条件且是逻辑或的关系（-o选项）时，使用"\\( \\)" 格式包含匹配条件
