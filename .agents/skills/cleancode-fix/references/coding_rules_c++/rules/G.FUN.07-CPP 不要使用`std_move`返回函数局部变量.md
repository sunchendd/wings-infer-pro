# G.FUN.07-CPP 不要使用`std::move`返回函数局部变量

- **规则ID**：f0e11632-4464-42c5-b8c0-c60a2fa6d442
- **更新时间**：2025-03-25 19:22:04

---

**【问题级别】**

严重

**【描述】**

C++标准中规定当函数返回一个局部变量时，在符合一定条件时编译器可以做返回值优化，即直接在返回值的位置上构造对象，省略任何移动或拷贝。返回值优化的条件之一是返回表达式类型需要和函数的返回类型一致，而对局部变量使用std::move破坏了类型一致性，阻止了编译器的返回值优化。



不用担心当编译器未做返回值优化时会拷贝很大的局部对象。C++标准规定：当满足返回值优化条件时，即使编译器不做返回值优化，也要把返回表达式当做右值处理，优先进行移动而不是拷贝。



因此任何时候返回一个局部变量，都不应当使用std::move。



注意：此要求只适用于返回“局部变量”，如果返回的是函数的入参，则不符合返回值优化的条件，不适用该条款。

**【正确示例】**

```
SomeType Fun()
{
    SomeType result;
    ...
    return result;            // 符合： 编译器可以优化为直接在返回位置构造result
}

```
**【错误示例】**

```
SomeType Fun()
{
    SomeType result;
    ...
    return std::move(result); // 不符合： 阻止了返回值优化
}

```
**【修复建议】**

直接返回局部变量
