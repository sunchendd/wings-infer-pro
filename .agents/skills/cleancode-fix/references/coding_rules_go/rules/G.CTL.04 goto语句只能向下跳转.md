# G.CTL.04 goto语句只能向下跳转

- **规则ID**：1c6985ca-704d-480f-b5b5-9bc4c9ebccfa
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

使用向上跳转的goto语句会导致代码可读性差、程序难以调试等问题。



因此，如果一定要使用goto语句，goto语句只能向下跳转。

**【正确示例】**

```
##### 场景1：特殊场景下使用向上跳转的goto语句。
- 修复示例：特殊场景下使用goto语句，goto语句不要向上跳转，只能向下跳转。
    ```go
        // ...

        goto label // 符合：向下跳转
        // ...

    label:
        // something
    ```


```
**【错误示例】**

```
##### 场景1：特殊场景下使用向上跳转的goto语句。
- 错误示例：

    ```go
        // ...

    label:
        // something

        // ...
        goto label // 不符合：向上跳转
    ```


```
**【修复建议】**

1. 除了特殊场景（如在函数末尾进行错误处理）外，不应使用goto语句，可使用结构化的控制语句（如if、for、while等）来实现程序逻辑。

2. 特殊场景下使用goto语句，goto语句不要向上跳转，只能向下跳转。
