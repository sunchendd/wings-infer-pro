# G.FMT.10-CPP 函数的返回类型及修饰符与函数名同行

- **规则ID**：444fa813-57c7-443b-9da1-3beb72c57186
- **更新时间**：2025-03-25 19:21:53

---

**【问题级别】**

一般

**【描述】**

声明和定义函数时，函数的返回类型以及其他修饰符，保持与函数名同一行；如果行宽度允许，函数参数也应该放在一行；否则，函数参数应该换行，并进行合理对齐。

参数列表的左圆括号总是和函数名在同一行，不要单独一行；右圆括号总是跟随最后一个参数。

**【正确示例】**

```
声明定义函数时，函数的返回值类型以及其他修饰符，保持与函数名同一行。

例：

static inline int ShortFunc(int a, int b);         // 符合

```
**【错误示例】**

```
声明定义函数时，函数的返回值类型以及其他修饰符，保持与函数名同一行。

例：

static inline int
ShortFunc(int a, int b);         // 不符合

```
**【修复建议】**

函数返回值及修饰符与函数名调整到同一行
