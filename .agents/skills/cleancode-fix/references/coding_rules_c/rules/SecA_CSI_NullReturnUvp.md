# SecA_CSI_NullReturnUvp

- **规则ID**：46e06b18-b61a-4517-a631-0e0beb0957dd
- **更新时间**：2025-06-05 04:10:01

---

**【问题级别】**

一般

**【描述】**

检查kmalloc等内存分配函数是否对返回值进行了判空

**【正确示例】**

```
// 全局变量
FILE* fp;

int mian(){
    if (fp != NULL) {
        putc(33, fp);
    }
}

```
**【错误示例】**

```
// 全局变量
FILE* fp;

int mian(){
    //未判空直接使用
    putc(33, fp);
}

```
**【修复建议】**

确保对kmalloc等内存分配函数的返回值进行了判空
