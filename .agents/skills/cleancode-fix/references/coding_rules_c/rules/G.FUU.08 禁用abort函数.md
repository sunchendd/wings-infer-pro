# G.FUU.08 禁用abort函数

- **规则ID**：d8b37da1-6408-4ef2-86d4-e78bb6d5033b
- **更新时间**：2026-04-07 04:10:05

---

**【问题级别】**

一般

**【描述】**

abort()将会导致程序立即退出，资源得不到清理。因为在使用abort()退出程序时，不能保证输入/输出流已经被清空，文件已经正确关闭，或者临时文件已经删除。

**【正确示例】**

```
【例外】只有发生致命错误，程序无法继续执行的时候，在错误处理函数中使用abort退出程序，如：
void FatalError(int sig)
{
  abort();
}
int main(int argc, char *argv[])
{
  signal(SIGSEGV, FatalError);
  ...
}

```
**【错误示例】**

```
abort()将会导致程序立即退出，资源得不到清理。因为在使用abort()退出程序时，不能保证输入/输出流已经被清空，文件已经正确关闭，或者临时文件已经删除

```
**【修复建议】**

禁用abort函数
