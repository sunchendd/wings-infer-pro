# G.CMD.05 使用bc或者awk进行小数计算(试点)

- **规则ID**：1eca1cf3-4bb3-408f-9e9c-d5fbf9a32968
- **更新时间**：2025-06-05 04:30:00

---

**【问题级别】**

严重

**【描述】**

((...)) 方式不支持小数计算，bc或者awk支持小数计算。  

比较运算符不支持小数,使用bc或者awk进行小数比较

**【正确示例】**

```
#!/bin/bash
  x=1.1
  y=2.1
  # 使用bc进行计算
  z=$(echo "${x} + ${y}" | bc)
  echo "z:${z}"
  # 使用awk进行计算
  z=$(echo ${x} ${y} | awk '{print ($1 + $2)}')
  echo "z:${z}"

```
**【错误示例】**

```
#!/bin/bash
  x=1.1
  y=2.1
  # 执行失败 提示报错
  ((z= x+y))
  echo "z:${z}"

```
**【修复建议】**

使用bc或者awk支持小数计算或比较
