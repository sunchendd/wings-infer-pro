# G.CTL.05 不要用逻辑运算符代替控制语句

- **规则ID**：3eea4449-fcfd-457f-8dda-5bf876cd411d
- **更新时间**：2025-06-05 04:35:01

---

**【问题级别】**

提示

**【描述】**

使用逻辑运算符的特性，来达到控制语句的目的，是非常不利于读者理解的。因此，不要用逻辑运算符代替控制语句。

**【正确示例】**

```
if (!isRunning) {
  startRunning();
}

```
**【错误示例】**

```
!isRunning && startRunning();

```
**【修复建议】**

不要用逻辑运算符代替控制语句
