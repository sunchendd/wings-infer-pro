# G.CMT.02 每个包都应该有包注释

- **规则ID**：1b141d63-e352-4dee-b670-dd652b0e6448
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

每个包都应该有包注释，用来介绍该程序包的相关信息。

**【正确示例】**

```
##### 场景1：包注释未紧贴package语句且开头不符合要求
- 修复示例：

  ```go
  // 符合：包注释紧贴package语句且开头（"Package"首字母大写）符合要求

  // Package list 实现了一个单向链表.
  package list
  ```


```
**【错误示例】**

```
##### 场景1：包注释未紧贴package语句且开头不符合要求
- 错误示例：

  ```go
  // 不符合：包注释未紧贴package语句且开头不符合要求

  // package list 实现了一个单向链表.

  package list
  ```


```
**【修复建议】**

每个包增加包注释，以`Package name ...`开头，并尽量使用一句话简述包的功能，需要时可在简述后补充详述。

对于有多个文件的包，包注释仅需要出现在一个文件中，任何一个都可以。
