# G.FUN.01-01 函数规模必须小于等于:50

- **更新时间**：2026-04-07 04:45:01

---

**【问题级别】**

一般

**【描述】**

行号：xxx 函数 xxx 的规模为 xxx，按规范要求必须小于等于:50

**【正确示例】**

```
```
function func()
    ... 
    extarctFunc()
    ...
end
```

```
**【错误示例】**

```
```
function func()
    ... 
    -- 此函数超过50行
    ...
end
```

```
**【修复建议】**

建议将超过50行的超大函数中的功能提取成单独的函数
