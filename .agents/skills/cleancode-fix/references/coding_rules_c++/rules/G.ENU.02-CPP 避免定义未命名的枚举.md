# G.ENU.02-CPP 避免定义未命名的枚举

- **规则ID**：9710068b-3227-47ac-a8de-dc28232cea20
- **更新时间**：2025-03-25 19:22:15

---

**【问题级别】**

一般

**【描述】**

枚举应当被使用来表示一系列相关的命名常量，并且可以作为一个命名类型使用。如果无法命名枚举，那么这些常量可能不应该通过枚举组织在一起。



**【正确示例】**

```
constexpr int MAX_LENGTH = 256;
constexpr int ARG_ERR = 1;

```
**【错误示例】**

```
enum { MAX_LENGTH = 256, ARG_ERR = 1 };

```
**【修复建议】**

给枚举类型命名
