# G.TYP.ARR.01 创建大全局数组时宜使用静态变量而非常量-试行

- **规则ID**：c2420c42-9793-4aaf-b10d-7ae8525ba86d
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

一般

**【描述】**

因为常量会内联，对于大的数组，使用静态变量定义更好。



相关规则：G.CNS.03

**【正确示例】**

```
pub static A: [u32;1_000_000] = [0u32; 1_000_000];

```
**【错误示例】**

```
pub const A: [u32;1_000_000] = [0u32; 1_000_000];

```
