# G.TYP.04 建议字符串使用单引号

- **规则ID**：fbe5f827-c9a6-4947-84c6-d8ae0ab988fe
- **更新时间**：2026-04-07 04:25:01

---

**【问题级别】**

提示

**【描述】**

单引号优于双引号，比如，当创建一个包含 HTML 代码的字符串时可以避免转义字符串中的双引号。

**【正确示例】**

```
##### 场景1：字符串格式
- 修复示例：字符串使用单引号

```javascript
let msg = '<span id="test" name="test">';
```

```
**【错误示例】**

```
##### 场景1：字符串格式
- 错误示例：字符串使用双引号

```javascript
let msg = "<span id=\"test\" name=\"test\">";
```

```
**【修复建议】**

建议字符串使用单引号。
