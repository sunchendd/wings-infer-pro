# G.EDV.06 禁止在if判断中使用-e对含通配符的文件或路径进行判断(试点)

- **规则ID**：59928bcb-1f58-47e9-b6f3-c1550e9a3757
- **更新时间**：2025-06-05 04:30:00

---

**【问题级别】**

严重

**【描述】**

-e参数并不能有效判断通配符，当通配符扩展后的文件超过1个时，会导致代码出错。

**【正确示例】**

```
#!/bin/bash
  for file in *.log
  do
    if [ -e "$file" ]
    then
      echo "log files found."
      break
    fi
  done

```
**【错误示例】**

```
#!/bin/bash
  if [ -e *.log ] # 当有两个.log文件时，会出错
  then
    echo "log files found."
  fi

```
**【修复建议】**

- 使用通配符号检查文件，可以使用 for 循环对所有文件判断

- 使用单双引号将文件名括起来，将直接匹配字符意义上的文件
