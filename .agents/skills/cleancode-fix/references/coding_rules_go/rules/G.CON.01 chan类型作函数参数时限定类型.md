# G.CON.01 chan类型作函数参数时限定类型

- **规则ID**：7c3aa203-ac81-4545-a22a-9e0c5872f2e8
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

`chan`类型作函数参数时限定类型，可以根据函数需要创建最小权限的channel，以增加代码可读性。



如果不希望原数据被接收⽅修改，那么就应该把 channel 的元素类型设定为某个值类型，以免造成数据泄露。如果⼀个 chan的元素类型是某个引⽤类型（包括基于结构体等的指针类型），那么元素值的接收⽅对这个值的修改会影响到发送⽅。这是因为，虽然经由通道的元素值都会被拷⻉，但只是浅拷⻉，引⽤类型的值当中通过指针指向的底层数据结构不会被拷⻉。

**【正确示例】**

```
##### 场景1：chan的参数类型非最小权限
- 修复示例：函数中的chan操作权限与参数权限一致，符合。

  ```go
  func testBidirectionalChanAssignStmt1(ch <-chan int) {  // 符合
      // AssignStmt
      s := <-ch
      fmt.Println(s)
  }
  ```


```
**【错误示例】**

```
##### 场景1：chan的参数类型非最小权限
- 错误示例：函数中的chan只进行读操作，但chan参数权限是`可读可写`，导致chan参数权限过大

  ```go
  func testBidirectionalChanAssignStmt1(ch chan int) {
      // AssignStmt
      s := <-ch // chan参数只读
      fmt.Println(s)
  }
  ```


```
**【修复建议】**

根据函数中chan的使用权限（`只读`，`只写`，`可读可写`），限定chan参数的类型。
