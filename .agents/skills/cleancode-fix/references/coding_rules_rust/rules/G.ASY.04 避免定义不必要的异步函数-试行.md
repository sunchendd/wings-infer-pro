# G.ASY.04 避免定义不必要的异步函数-试行

- **规则ID**：b2d73f45-fc35-4385-9c01-12d9d6178fc3
- **更新时间**：2025-06-05 04:40:04

---

**【问题级别】**

提示

**【描述】**

如果一个异步函数内部没有任何异步代码，相比一个同步函数，它会产生额外的调用成本。

**【正确示例】**

```
fn add(value: i32) -> i32 {
    value + 1
}

```
**【错误示例】**

```
async fn add(value: i32) -> i32 {
    value + 1
}

```
