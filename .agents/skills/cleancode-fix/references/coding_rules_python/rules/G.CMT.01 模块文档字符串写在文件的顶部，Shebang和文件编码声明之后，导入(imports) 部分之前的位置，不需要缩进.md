**【描述】**

模块文档字符串应写在文件开始处，顶格不缩进，整体位置在Shebang和文件编码声明之后，导入(import) 部分之前。使用三引号作为定界符，以前导三引号开头，结束三引号要自成一行。

模块文档字符串通常可以包含版权、当前模块文件的简要描述以及该模块中的类、函数等信息，这些信息以每个一段的形式摘要描述。

模块文档字符串结束后空一行，然后编写其他内容。

**【正确示例】**

```
### 场景1：文档字符串位置
- 修复示例：文档字符串位于文档头部
```python
# coding: utf-8
"""版权所有 (c) 华为技术有限公司 2012-2020
功 能：XXX类，该类主要涉及XXX功能
版权信息：华为技术有限公司，版本所有(C) 2010-2019"""
import os
```
