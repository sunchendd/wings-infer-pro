# G.CMT.02 注释符和注释内容之间留有一个空格

- **规则ID**：4d7cc222-d49a-4106-af3e-e359045c925f
- **更新时间**：2026-04-07 04:25:00

---

**【问题级别】**

提示

**【描述】**

注释符(`//`和`/*  */`)与注释内容之间留有一个空格，这会让注释看起来清晰美观。

**【正确示例】**

```
##### 场景1：使用`//`注释
- 修复示例：`//`后面空一格
```javascript
// 通过 … 复制数组
const itemsCopy = [...items];
```
##### 场景2：使用 `/* */ `注释
- 修复示例：使用 `/* */ `注释时，`*`后面空一格
```javascript
 /* 变量name在使用时进行声明，并赋初始值  */
const name = getName();
```

```
**【错误示例】**

```
##### 场景1：使用`//`注释
- 错误示例：`//`后面没有空一格
```javascript
//通过 … 复制数组
const itemsCopy = [...items];
```
##### 场景2：使用 `/* */ `注释
- 错误示例：注释符`*`后面没有空一格
```javascript
 /*变量name在使用时进行声明，并赋初始值*/
const name = getName();
```

```
**【修复建议】**

1、**使用 `/* */ `**注释时，注释符要和注释内容之间有一个空格

```javascript

/* 单行注释 */

```



```javascript

/*

 * 多行注释

 * 第二行

 */

```

2、**使用`//`**注释时，注释符要和注释内容之间有一个空格

```javascript

// 单行注释  

```



```javascript

// 多行注释

// 第二行

```
