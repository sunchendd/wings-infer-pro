# G.NAM.07 包名采用全小写单词，允许包含数字，无下划线

- **规则ID**：9038779a-7ab5-493d-9522-26581bff33ec
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

包名仅能使用包含小写字母、数字的标志符。包被导入后，会以`packagename.Xxx`的方式使用。在这种情况下使用者会频繁输入包名，所以包名尽量简洁。



为了避免包名冲突而引入的别名，同样也仅使用小写字母、数字。

**【正确示例】**

```
##### 场景1：包名包含下划线
- 修复示例：按规范要求修改包名

  ```go
  // 符合：包名全小写
  package tablecodec
  ```


```
**【错误示例】**

```
##### 场景1：包名包含下划线
- 错误示例：

  ```go
  // 不符合：包含了下划线
  package table_codec
  ```


```
**【修复建议】**

包名采用全小写单词，允许包含数字，无下划线。
