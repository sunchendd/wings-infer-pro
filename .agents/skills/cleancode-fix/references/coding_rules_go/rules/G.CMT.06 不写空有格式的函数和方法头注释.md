# G.CMT.06 不写空有格式的函数和方法头注释

- **规则ID**：c374d235-ce41-4835-b481-1072559e93df
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

尽量通过函数名自注释其功能，**按需**写函数头注释。避免写空有格式的函数头注释；避免写无用、信息冗余的函数头注释。



函数头注释内容**可选**，其内容不限于：功能说明、返回值、性能约束、用法、内存约定、可重入的要求等等。

**【正确示例】**

```
##### 场景1：函数头注释信息冗余
- 修复示例：按需写函数和方法注释，删除不必要的内容

  ```go
  // 符合：函数和方法注释，简要说明其功能即可

  // WriteData 写入字符串
  func WriteData(buf []byte, len uint32) {
  ```


```
**【错误示例】**

```
##### 场景1：函数头注释信息冗余
- 错误示例：

  ```go
  // 不符合：函数和方法注释，简要说明其功能即可，不需要过于复杂

  /*
   * 函数名：WriteData
   * 功能：写入字符串
   * 参数：
   * 返回值：
   */
  func WriteData(buf []byte, len uint32) {
  ```


```
**【修复建议】**

按需写函数和方法注释，删除不必要的内容。
