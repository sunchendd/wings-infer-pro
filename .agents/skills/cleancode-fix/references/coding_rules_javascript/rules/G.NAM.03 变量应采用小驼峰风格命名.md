# G.NAM.03 变量应采用小驼峰风格命名

- **规则ID**：0e774ed2-6b5e-4e05-94cc-bee34b05c9da
- **更新时间**：2026-04-07 04:25:00

---

**【问题级别】**

提示

**【描述】**

变量的名字通常是名词或名词短语，应采用小驼峰命名，以便于理解其含义。如果用于自定义组件名的变量（比如React函数组件名等），可申请误报屏蔽。

**【正确示例】**

```
##### 场景1：变量名
- 修复示例：变量命名建议采用小驼峰命名。

```javascript
const firstName = 'xiaoming';
```

```
**【错误示例】**

```
##### 场景1：变量名
- 错误示例：变量命名未采用小驼峰命名。

```javascript
const first_name = 'xiaoming';
```

```
**【修复建议】**

变量命名应采用小驼峰风格命名。
