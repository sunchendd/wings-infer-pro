# G.NOD.05 禁止日志泄露敏感信息

- **规则ID**：831ba023-f6f6-43b8-b471-1d552205e8d2
- **更新时间**：2025-06-05 04:25:02

---

**【问题级别】**

一般

**【描述】**

禁止在日志中记录系统的敏感数据(例如用户密码、秘钥、敏感异常等)，防止产生敏感信息泄露风险。

**【正确示例】**

```
// 若因为特殊原因必须要记录用户日志信息，应用固定长度的星号（*）代替这些敏感信息。
console.log('Login success, user is ' + userName + ', password is ********.');

```
**【错误示例】**

```
// 在日志中不能记录口令、密钥等敏感信息，包括这些敏感信息的加密密文，防止产生敏感信息泄露风险。
console.log('Login success, user is ' + userName + ', password is ' + password + '.');

```
**【修复建议】**

禁止在日志中记录系统的敏感数据(例如用户密码、秘钥、敏感异常等)，防止产生敏感信息泄露风险。
