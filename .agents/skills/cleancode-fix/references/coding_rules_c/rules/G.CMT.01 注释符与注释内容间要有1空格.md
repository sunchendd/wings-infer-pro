# G.CMT.01 注释符与注释内容间要有1空格

- **规则ID**：5c2809e9-f155-4fd9-aa37-2f8755d464b2
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

注释符（包括： `/*` `*/`和 `//`）与注释内容之间留有1个空格。

**【正确示例】**

```
##### 场景1：注释符与注释内容之间没有空格
- 修复示例：

```c
// 单行注释         // 符合

/* 单行注释 */     /* 符合 */

// 以下通过“/*”与“*/”多行注释，符合规则
/*
 * 多行注释
 * 第二行
 */

// 以下通过“//”多行注释，符合规则
// 另外一种多行注释
// 第二行
```


```
**【错误示例】**

```
##### 场景1：注释符与注释内容之间没有空格
- 错误示例：

```c
//单行注释          //不符合

/*单行注释*/      /*不符合*/

/*
 *多行注释
 *第二行
 */

//另外一种多行注释
//第二行
```


```
