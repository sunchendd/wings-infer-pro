# G.EXP.33-CPP 含有变量自增或自减运算的表达式中禁止再次引用该变量

- **规则ID**：7c37629d-5f21-4b98-97a8-07df616dbc60
- **更新时间**：2025-03-25 19:22:28

---

**【问题级别】**

严重

**【描述】**

含有变量自增或自减运算的表达式中，如果再引用该变量，其结果在C++标准中可能未明确定义。



各个编译器或者同一个编译器不同版本实现可能会不一致。为了更好的可移植性，不应该对标准未定义的运算次序做任何假设。



注意：运算次序的问题不能使用括号来解决，因为这不是优先级的问题。

**【正确示例】**

```
x = b[i] + i;
i++;            // 符合： 单独一行
i++;            // 符合： 单独一行
x = Fun(i, i);

```
**【错误示例】**

```
x = b[i] + i++; // 不符合： b[i]运算跟 i++，先后顺序并不明确
Fun(i++, i);    // 不符合： 传递第2个参数时，不确定自增运算有没有发生

```
**【修复建议】**

自增或自减运算提到表达式之外
