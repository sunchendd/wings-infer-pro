# G.OBJ.02 对象字面量的属性名称使用标识符

- **规则ID**：bb0015f9-6627-4e37-9b05-895cc4ed8957
- **更新时间**：2026-04-07 04:25:01

---

**【问题级别】**

提示

**【描述】**

对象字面量的属性名称建议使用标识符，一般来说，标识符号在主观上更容易阅读。它改进了语法突出显示，并且更容易被许多JavaScript引擎优化。



不要混合使用标识符和字符串，除非必须使用引号，如：属性名中使用非标识符的字符，或者这属性中间有一个空格，像 “one-two”、“one two” 这样。

**【正确示例】**

```
##### 场景1：对象字面量
- 修复示例：属性名称使用标识符。

```javascript
const obj = {
  id: 42, // 标识符的属性
  name: 'hi', // 标识符的属性
};

const good = {
  foo: 3,
  bar: 4,
  'data-blah': 5, // 属性中有特殊符号，所以必须加引号
};

```

```
**【错误示例】**

```
##### 场景1：对象字面量
- 错误示例：属性名称使用字符串表示。
```javascript
const obj = {
  id: 42, // 标识符的属性
  'name': 'hi', // 不符合，字符串的属性
}

```

```
**【修复建议】**

1、对象字面量的属性名称建议使用标识符。

2、若属性名中使用非标识符的字符，或者这属性中间有一个空格，像 “one-two”、“one two” 这样，则必须使用引号。
