# G.EXP.13 行首单词避免使用特殊符号

- **规则ID**：b780c70d-0123-4dae-a004-b0b7ac1bde18
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

1. 避免管道符和逻辑运算符出现在行首。  

2. 避免空字符串作为行首字符。

**【正确示例】**

```
```shell
#!/bin/bash
dmesg | grep "error"

dmesg && echo "done"
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 不符合：dmesg本身是一个完整命令， Shell不知道是否需要继续下一行
dmesg
| grep "error"

# 不符合：dmesg本身是一个完整命令， Shell不知道是否需要继续下一行
dmesg
&& echo "done"
```

```
**【修复建议】**

1. 避免管道符和逻辑运算符出现在行首。如果一行容得下整个管道操作，那么请将整个管道操作写在同一行。否则，应该将整个管道操作分割成每行一个管道，管道操作的下一部分应该将管道符放在新行。这适用于使用管道符| 的合并命令链以及使用|| 和&& 的逻辑运算链。

2. 避免空字符串作为行首字符。
