# G.FUN.01-TS 建议显式声明函数及类方法的返回值类型

- **规则ID**：2fa83f7b-9974-4b40-8471-c512cc15a705
- **更新时间**：2026-04-07 04:35:02

---

**【问题级别】**

提示

**【描述】**

显式声明返回类型，这可确保返回值被分配给正确类型的变量；或者在没有返回值的情况下，调用代码不会尝试把undefined分配给变量。

**【正确示例】**

```
##### 场景1：返回值类型
- 修复示例：显式声明返回值类型

```typescript
function test(): void {
  return;
}

let arrowFn = (): string => 'test';
```

```
**【错误示例】**

```
##### 场景1：返回值类型
- 错误示例：没有声明返回值类型

```typescript
function test() {
  return;
}

let arrowFn = () => 'test';
```

```
**【修复建议】**

建议显式声明函数及类方法的返回值类型。
