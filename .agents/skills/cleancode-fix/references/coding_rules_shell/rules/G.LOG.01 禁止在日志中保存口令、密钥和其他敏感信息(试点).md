# G.LOG.01 禁止在日志中保存口令、密钥和其他敏感信息(试点)

- **规则ID**：532e058b-8afa-4a41-8ccf-0fb679160082
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

在日志中不能保存口令和密钥，其中的口令包括明文口令和密文口令。

代码中不能打印敏感信息（如：密码明文和密文，密钥和License等）到界面和日志。

代码所产生运行日志不能包含"passwd"， "password"， "pvalue"， "secret"， "pwd"， "token"，"secrete"， "key"密码相关的变量名称（不区分大小写），且密码、敏感信息不能使用“*”来代替。

用户在读取日志时，发现“passwd”、“password” 或“*”字样很容易联想到是密码信息，用户可能会怀疑是敏感信息的暴露，造成用户安全感知不理想。

**【正确示例】**

```
#!/bin/bash
# 符合：使用模糊描述
echo "invalid parameter"
# 符合：使用其他描述
echo "info:"$1

```
**【错误示例】**

```
#!/bin/bash
# 不符合：日志打印password字样，打印密码明文
echo "invalid password: ${password}"

```
**【修复建议】**

请取消口令、密钥及其他敏感信息在日志和控制台的输入、输出操作。
