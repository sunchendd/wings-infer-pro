# G.PRJ.01 脚本中不能使用~作为当前用户路径，需使用$HOME变量(试点)

- **规则ID**：63fb9e67-fdfd-4b4e-a238-d899aee78b1f
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

脚本中不能使用~作为当前用户路径，需使用$HOME变量

**【正确示例】**

```
#!/bin/bash
  ls "$HOME"  # $HOME变量能在引号中正确展开
  ls ~/

```
**【错误示例】**

```
#!/bin/bash
  ls "~/"
  # 运行报错 ls: cannot access '~/': No such file or directory

```
**【修复建议】**

- 使用$HOME变量代替引号中的~/

- ~/放到引号外
