# G.CNS.01 禁止使用小写字母“l”作为数值型常量后缀

- **规则ID**：b9d0848d-f570-4ec9-8b51-f48cc92831f8
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

严重

**【描述】**

在视觉上`l`容易和数字`1`混淆，为了避免这种混淆带来的误解，应使用大写字母`L`或`LL`作为数值型常量的后缀。

**【正确示例】**

```
##### 场景1：使用小写字母“l”作为数值后缀
- 修复示例：

```c
#define CONSTANT_BARRETT_REDUCTION 0x1F7011641LL // 符合：通过使用大写字母 L 而不是小写字母 l 来消除视觉上的错觉
```


```
**【错误示例】**

```
##### 场景1：使用小写字母“l”作为数值后缀
- 错误示例：

```c
// 不符合：宏 CONSTANT_BARRETT_REDUCTION 的值为 0x1F7011641，但是视觉上像是 0x1F701164111
#define CONSTANT_BARRETT_REDUCTION 0x1F7011641ll 
```


```
**【修复建议】**

小写"l"替换成大写"L"。
