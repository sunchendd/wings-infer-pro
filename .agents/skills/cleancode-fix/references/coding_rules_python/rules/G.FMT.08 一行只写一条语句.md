# G.FMT.08 一行只写一条语句

- **规则ID**：05cc2296-8d2c-48b1-982a-2bf2e3869ab8
- **更新时间**：2026-04-07 04:15:01

---

**【问题级别】**

一般

**【描述】**

Python虽然支持分号分隔的多条语句，但编写程序时不建议使用这种风格的排版，推荐一行只写一条语句，并且在行尾不加分号。多条语句写在一行，这样做一个很明显的缺点就是在调试的时候无法单步执行。

**【正确示例】**

```
# 【正例1】
rect.length = 0
rect.width = 0

```
**【错误示例】**

```
# 【反例1】
rect.length = 0; rect.width = 0;

```
**【修复建议】**

函数体要单起一行，不能和函数定义部分共用一行
