# G.ARR.07 声明一个带有外部链接的数组时，必须显式指定它的大小

- **规则ID**：730f61f5-94f7-4fa1-9fd3-07a56afa0f38
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

在**声明**具有外部链接的数组时，明确指定其大小。

**【正确示例】**

```
##### 场景1：没有显式指定数组大小
- 修复示例：

```c
// in foo.h
extern int g_array[MAX_LEN];   // 符合：显式指定了数组大小
```
- 修复示例：

```c
// in foo.h
const char g_array[];
const size_t g_arrayLen; // 符合：显式指定了数组大小，且和数组声明之间无间隔
```


```
**【错误示例】**

```
##### 场景1：没有显式指定数组大小
- 错误示例：

```c
// in foo.h
extern int g_array[];     // 不符合：没有显式指定数组大小
```


```
**【修复建议】**

数组声明时，同时显式指定其大小，如：

1、固定长度数组

```c

extern int g_array[MAX_LEN]; 

```

2. 需要通过计算的数组长度，注意**数组和数组长度参数**的声明放一起，中间不要有间隔。

```c

const char g_array[];

const size_t g_arrayLen;

```
