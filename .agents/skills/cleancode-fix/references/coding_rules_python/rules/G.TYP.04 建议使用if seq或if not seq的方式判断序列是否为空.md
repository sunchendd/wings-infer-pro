# G.TYP.04 建议使用if seq或if not seq的方式判断序列是否为空

- **规则ID**：827155e1-87c2-4a4e-8ce1-baa4d3750e5b

**【问题级别】**

一般

**【描述】**

在条件表达式中虽然可以直接使用len()判断序列是否为空，但Python语言本身有非常简单而高效的方式来推断字符串、列表、元组、字典、集合的隐式布尔值，使用if seq 或if not seq判断序列是否为空，是一种非常Pythonic的编程方式，同时也是PEP8推荐的方式。

**【正确示例】**

```
##### 场景1：使用len()判断序列是否为空
- 修复示例：使用if seq或if not seq的方式判断序列是否为空
```python
seq = []

if seq:   # 符合，用列表来隐式判断序列是否为空
    pass

if not seq:   # 符合，用列表来隐式判断序列是否为空
    pass
```


```
**【错误示例】**

```
##### 场景1：使用len()判断序列是否为空
- 错误示例：通过列表长度来判断序列是否为空
```python
seq = [1, 2, 3]

if len(seq):    # 不符合，用列表长度来判断序列是否为空
    pass

if not len(seq):  # 不符合，用列表长度来判断序列是否为空
    pass

if len(seq) == 0:  # 不符合，用列表长度来判断序列是否为空
    pass

if len(seq) != 0:  # 不符合，用列表长度来判断序列是否为空
    pass
```


```
**【修复建议】**

使用if seq或if not seq的方式判断序列是否为空。
