# G.EXP.01 表达式的比较，应该遵循左侧倾向于变化、右侧倾向于不变的原则

- **规则ID**：0c07468c-5096-4e96-a78e-7f3bcf533aef
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

当变量或方法调用与常量比较时，如果常量放左边，如 `if nil == p` 不符合阅读习惯，而 `if Max > v` 更是难于理解。应该按人的正常阅读、表达习惯，将常量放右边。

**【正确示例】**

```
##### 场景1：常量在比较的左边
- 修复示例：

  ```go
  if p != nil && p.v < Max {   // 符合
      // ...
  }
  ```


```
**【错误示例】**

```
##### 场景1：常量在比较的左边
- 错误示例：

  ```go
  if nil != p && Max > p.v { // 不符合："nil != p"和"Max > p.v"都将常量放左边
      // ...
  }
  ```


```
**【修复建议】**

当变量或方法调用与常量比较时，将常量放右边。
