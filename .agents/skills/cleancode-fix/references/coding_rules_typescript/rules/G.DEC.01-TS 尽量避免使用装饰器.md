# G.DEC.01-TS 尽量避免使用装饰器

- **规则ID**：4434bd49-4476-4e35-a0ce-ec1fc9e00a14
- **更新时间**：2025-06-05 04:35:02

---

**【问题级别】**

提示

**【描述】**

通常情况下，尽量避免使用装饰器，这是由于装饰器是一个实验性功能，仍然处于 TC39 委员会的提案阶段，且目前存在已知的无法被修复的 Bug；

如需使用装饰器时，建议使用@为装饰器前缀；

避免定义新的装饰器，只是用框架中已定义的装饰器。

**【正确示例】**

```
@Component({...}) // Angular 内置的组件 Component
class MyComp {
  @Input() myField: string;  // Angular 内置的组件 Input
}

```
**【错误示例】**

```
@Custom({...})
class MyComp {
}

```
**【修复建议】**

尽量避免使用装饰器
