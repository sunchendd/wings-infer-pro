# G.VAR.01 禁止在变量的生命周期内修改其类型

- **规则ID**：8b3d7243-2f36-4c68-a9fe-fd6346ac6be4
- **更新时间**：2026-04-07 04:15:01

---

**【问题级别】**

严重

**【描述】**

在变量的生命周期内，如果变量被赋值为不同类型对象，可能会导致运行时错误，另外变量上下文语义的变化会导致代码复杂度提升，从而难以调试和维护，也不会有任何性能的提升。因此，给变量赋值时，值的类型应该和变量的类型匹配，禁止变量在其生命周期内的值类型发生变化。

**【正确示例】**

```
##### 场景1：变量类型被改变
- 修复示例：
```python
variable: int = 1
variable = 2  # 符合
```

```
**【错误示例】**

```
##### 场景1：变量类型被改变
- 错误示例：
```python
variable: str = 1  # 不符合
variable = b'hello world'
```

```
**【修复建议】**

保证变量在生命周期内部不改变其类型。
