# G.FIL.01 创建文件时必须显式指定合适的文件访问权限

- **规则ID**：b48f458c-5d88-42a8-9bdd-7fd82bfe222f
- **更新时间**：2026-04-07 04:10:02

---

**【问题级别】**

严重

**【描述】**

创建文件时，如果不显式指定合适访问权限，可能会导致非法访问，文件信息泄露。



因此，创建文件时必须显式指定合适的文件访问权限。

**【正确示例】**

```
##### 场景1：使用POSIX open()函数创建文件但未显式指定该文件的访问权限。
- 修复示例：应该在open的第三个参数中显式指定新创建文件的访问权限。可以根据文件实际的应用情况设置何种访问权限。

```c
void Foo(void)
{
    int32_t fd = -1;
    char *filename = NULL;

    ... // 初始化 filename 和指定其访问权限

    // 符合：此处根据文件实际需要，显式指定其访问权限
    int fd = open(filename, O_CREAT | O_WRONLY, S_IRUSR | S_IWUSR);
    if (fd == -1) {
        ... // 错误处理
    }
    ...
}
```


```
**【错误示例】**

```
##### 场景1：使用POSIX open()函数创建文件但未显式指定该文件的访问权限。
- 错误示例：

```c
void Foo(void)
{
    int32_t fd = -1;
    char *filename = NULL;

    ... // 初始化 filename

    fd = open(filename, O_CREAT | O_WRONLY); // 不符合：没有显式指定访问权限
    if (fd == -1) {
        ... // 错误处理
    }
    ...
}
```


```
**【修复建议】**

应该在创建文件的函数（如：open）中显式指定新创建文件的访问权限。可以根据文件实际的应用情况设置何种访问权限。
