# G.LOG.01 禁止在日志中保存口令、密钥和其他敏感信息

- **规则ID**：1b4d6764-2d07-4ff5-84c7-784f89380696
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

用户在读取日志时，发现“passwd”、“password” 或“*”字样很容易联想到是密码信息，用户可能会怀疑是敏感信息的暴露，造成用户安全感知不理想。

**【正确示例】**

```
```shell
#!/bin/bash
# 符合：使用模糊描述
echo "invalid parameter"
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 不符合：日志打印password字样，打印密码明文
echo "invalid password: ${password}"
```

```
**【修复建议】**

1. 在日志中不能保存口令和密钥，其中的口令包括明文口令和密文口令。

2. 代码中不能打印敏感信息（如：密码明文和密文，密钥和License等）到控制台和日志。

3. 代码所产生运行日志不能包含“passwd”， “password”， “pvalue”， “secret”， “pwd”， “token”， “secrete”， “key”密码相关的变量名称（不区分大小写），且密码、敏感信息不能使用“*”来代替。
