# G.EXP.02-CPP 不要重复定义基本类型

- **规则ID**：21af8de5-ea7b-48a9-8b4a-817a4d4c76fa
- **更新时间**：2025-03-25 19:22:17

---

**【问题级别】**

严重

**【描述】**

项目组应规划使用相同版本的类型定义，建议优先使用标准中定义的类型（如：统一使用<cstdint>中定义的整数类型），不要重复定义基本类型。



一个项目中如果存在多种类型定义（如同时使用u32，v32，uint32，uint表示unsigned int类型），会使代码变得更加混乱，难以维护和难以编译，也违反了风格一致原则。

除非有明确的必要性，否则不要用 typedef/#define/using 对基本类型进行重定义。



下面的场景中重新定义了基本类型为Uintptr，其屏蔽了不同平台（CPU/OS）下基本数值类型的位宽差异，是具有必要性的。

**【错误示例】**

```
...

…

...

...

```
**【修复建议】**

如无必要，不要重新定义基础类型
