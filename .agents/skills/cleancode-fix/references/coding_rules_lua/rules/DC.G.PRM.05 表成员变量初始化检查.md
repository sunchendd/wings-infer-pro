# DC.G.PRM.05 表成员变量初始化检查

- **规则ID**：1f8c9ea0-e2c4-46b7-afd3-ba2dfd3db270
- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：“xxx”表成员变量的初始化，建议放在xxx行的{}内

**【正确示例】**

```
```
local tbl = {
    item1 = 1,
    item2 = 2
} -- Good: 一次申请足够的空间并按要求赋值
```

```
**【错误示例】**

```
```
local tbl = {}
tbl.item1 = 1 -- Bad: 有可能再次申请新的空间
tbl.item2 = 2 -- Bad: 有可能再次申请新的空间
```

```
**【修复建议】**

在定义表时就完成初始化可以避免表内部冗余的内存扩充动作，使性能更为高效
