# G.CMT.07 正式交付给客户的代码不应包含TODO/TBD/FIXME注释

- **规则ID**：ab6c454f-42af-4a80-97d0-1cfa2c52ea85
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

`TODO/TBD`注释一般用来描述已知待改进、待补充的修改点。`FIXME` 注释一般用来描述已知缺陷。正式交付给客户的代码中不应包含这类注释。

**【正确示例】**

```
##### 场景1：正式交付给客户的代码中未解决TODO问题
- 修复示例：把待处理问题解决后删除注释。

  ```go
  // 符合
  func accum(fee uint) {
      doSomething()
  }
  ```


```
**【错误示例】**

```
##### 场景1：正式交付给客户的代码中未解决TODO问题
- 错误示例：

  ```go
  // 不符合：未解决TODO问题
  func accum(fee uint) {
      // TODO: ...
      total += fee
  }
  ```


```
**【修复建议】**

方法1：开发过程中代码可以合理使用TODO/TBD/FIXME注释，但是正式交付给客户的代码中不能包含这类注释，需要把待处理问题解决后删除注释。



方法2：如果实在无法修复的应通过问题跟踪的形式管理起来，不要通过直接删除的方式解决告警，否则问题仍然是存在的。
