# G.TYP.05 使用模板字符串（`）实现字符串拼接

- **规则ID**：3eaf4837-b99c-4660-bbae-fcc297448a51
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

提示

**【描述】**

在ECMAScript 6中，动态构建字符串时建议使用模板字符串而不是使用+拼接，主要是因为模板字符串有可读性强，语法明确，换行合理和字符串插值的特点。

**【正确示例】**

```
##### 场景1：模板字符串
- 修复示例：使用模板字符串来拼接
```javascript
function sayHi(name) {
  return `How are you, ${name}?`;  // 符合
}
```

```
**【错误示例】**

```
##### 场景1：模板字符串
- 错误示例：使用+拼接字符串
```javascript
function sayHi(name) {
  return 'How are you, ' + name + '?';  // 不符合
}
```

```
**【修复建议】**

动态构建字符串时建议使用模板字符串而不是使用+拼接。
