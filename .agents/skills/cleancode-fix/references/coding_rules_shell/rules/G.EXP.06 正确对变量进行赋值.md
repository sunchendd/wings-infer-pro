# G.EXP.06 正确对变量进行赋值

- **规则ID**：1ad7f88d-4420-4634-a150-3934c51c25f0
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

1. 等号左侧要求：不要使用${}对应的变量作为赋值操作的左值， 对于位置参数赋值，使用命令set -- first second。

2. 等号右侧要求：建议使用 $((..)) 、 $(..) 、 "..."、整数 作为等号右侧数据。

**【正确示例】**

```
```shell
#!/bin/bash
greeting="Hello World"
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 不符合： 左侧不能是变量
$greeting="Hello World"
${greeting}="Hello World"
```

```
**【修复建议】**

1. 左侧不能是变量，对于位置参数赋值，使用命令set -- first second。

2. 右侧为字符串请使用引号括起来。

3. 右侧为算术表达式，需要使用$((...))括起来。

4. 右侧想获取命令执行的标准输出使用$(...)括起来。
