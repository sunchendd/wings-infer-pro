# G.CMD.01 合理使用exec命令

- **规则ID**：35a7cde1-055c-4e77-a26d-48b197e02716
- **更新时间**：2026-04-07 04:30:00

---

**【问题级别】**

严重

**【描述】**

exec命令执行不会创建新子进程，执行完毕后会直接退出当前进程，不会执行后续的命令。

**【正确示例】**

```
```shell
#!/bin/bash
ls ./
ls /home
```

```
**【错误示例】**

```
```shell
#!/bin/bash
exec ls ./
# 上条ls /xxx 命令执行完毕后 ls /home将不会被执行
exec ls /home
```

```
**【修复建议】**

不使用exec执行命令 。

例外：

如果需要执行出错后就退出，可以使用exec命令。
