# G.FMT.06 禁止连续3个或更多的空行

- **规则ID**：8e0cde19-ec2b-4ad4-bd73-76c2c4713ab8
- **更新时间**：2026-04-07 04:45:01

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：禁止连续3个或更多的空行

**【正确示例】**

```
```
function fun1()
    ...
end

function func2()
    ...
end
```

```
**【错误示例】**

```
```
function fun1()
    ...
end



function func2()
    ...
end
```

```
**【修复建议】**

根据代码行间的相关性，增加空行，禁止连续3个或更多空行。

至于增加 1 行还是 2 行，由代码段之间相关性决定；尽量做到整个模块空行的使用标准统一。
