# G.CMT.05 正式交付给客户的代码不应包含TODO/TBD/FIXME注释

- **规则ID**：98b2315c-a9f8-4945-aa7b-c3a309b7f975
- **更新时间**：2026-04-07 04:10:01

---

**【问题级别】**

一般

**【描述】**

TODO/TBD注释一般用来描述已知待改进、待补充的修改点。 FIXME 注释一般用来描述已知缺陷。 正式交付给客户的代码中不能包含这类注释。

**【正确示例】**

```
##### 场景1：正式交付给客户的代码中包含TODO注释
- 修复示例：把待处理问题解决后删除注释，符合规则

```c
void Func();
```

```
**【错误示例】**

```
##### 场景1：正式交付给客户的代码中包含TODO注释
- 错误示例：

```c
// TODO : 待修改
void Func();
```

```
**【修复建议】**

方法1：开发过程中代码可以合理使用TODO/TBD/FIXME注释，但是正式交付给客户的代码中不能包含这类注释，需要把待处理问题解决后删除注释。

方法2：如果实在无法修复的应通过问题跟踪的形式管理起来，不要通过直接删除的方式解决告警，否则问题仍然是存在的。
