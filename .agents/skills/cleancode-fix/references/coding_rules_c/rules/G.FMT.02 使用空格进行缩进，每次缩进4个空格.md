# G.FMT.02 使用空格进行缩进，每次缩进4个空格

- **规则ID**：775a67ef-8514-45aa-a1ed-a36e061576fc
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

每次缩进为 4 个空格。避免使用制表符`\t`进行缩进。

**【正确示例】**

```
##### 场景1：缩进不是四的倍数
- 修复示例：

```c++
void Func()
{
    int num; // 符合，缩进为4
}
```

```
**【错误示例】**

```
##### 场景1：缩进不是四的倍数
- 错误示例：

```c++
void Func()
{
 int num; // 不符合，缩进为1
}
```

```
**【修复建议】**

改为缩进 4 个空格。不允许使用Tab键进行缩进。

Linux内核缩进风格与本规则有冲突，请参考《华为Linux内核编程规范》。
