# G.TYP.03 浮点型数据判断相等不要直接使用== 或===

- **规则ID**：d40ee3a1-987e-4f8a-bd85-d95bfe39820c
- **更新时间**：2025-06-05 04:35:01

---

**【问题级别】**

一般

**【描述】**

由于浮点数在计算机表示中存在精度的问题，数学上相等的数字，经过运算后，其浮点数表示可能不再相等，因而不能使用相等运算符== 或===判断浮点数是否相等。

**【正确示例】**

```
const num1 = 0.1;

```
**【错误示例】**

```
0.1 + 0.2 == 0.3;

```
**【修复建议】**

浮点型数据判断相等不要直接使用== 或===
