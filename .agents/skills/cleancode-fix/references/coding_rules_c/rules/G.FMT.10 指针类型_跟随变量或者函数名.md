# G.FMT.10 指针类型"*"跟随变量或者函数名

- **规则ID**：2b390d58-9633-4a77-8ade-29b5cc78727c
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

指针类型`*`应该跟随变量或函数名。

**【正确示例】**

```
##### 场景1：指针类型`*`跟随类型
- 修复示例：

```cpp
int *p2;  // 符合: "*"跟随变量
struct Foo *CreateFoo(void); // 符合: "*"跟随函数名
```
##### 场景2：指针类型`*`左右都有空格或者都没有空格
- 修复示例：

```cpp
int *p3; // 符合
int *p4; // 符合
```

```
**【错误示例】**

```
##### 场景1：指针类型`*`跟随类型
- 错误示例：

```cpp
int* p2;  // 不符合
struct Foo* CreateFoo(void); // 不符合
```
##### 场景2：指针类型`*`左右都有空格或者都没有空格
- 错误示例：

```cpp
int*p3;   // 不符合："*"两边都没空格
int * p4; // 不符合："*"两边都有空格
```

```
**【修复建议】**
