**【问题级别】**

一般

**【描述】**

检查while语句可能出现的死循环，主要是以下两种场景：

(1)循环变量的偏移量可能为0。

*如何识别循环变量：当条件是变量时，例如while(a)；当条件是二目表达式，则左右值都是循环变量，例如while(a > b)

* 如何识别偏移量：循环体中有a+=b;a=a+b;a-=b;a=a-b;表达式时，若a是循环变量，则b是偏移量。

(2)两个指向不同对象的指针，以判断非等作为while条件前，没有校验两指针的大小关系。

**【正确示例】**

```
```
场景一：
void good(){
 int a = 1;
 while (a >0){
  ...
 }

}
场景二：
void good2(char *p,char *q){
if(p=q){
 return;
} 
else {
 while (p!=q){
  ...
 }
}

}
```

```
**【错误示例】**

```
```
场景一：
void bad(){
 int a = 1;
 while (a){  }
}
场景二：
void bad2(char *p,char *q){
 while (p!=q){
  ...
 }

}
```

```
**【修复建议】**

循环偏移量需要判断是否非0



对于比较指针的循环变量，例如while(p!=q)， 需要在之前做过两个指针的比较
