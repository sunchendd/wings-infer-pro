# G.PRJ.02 不用的代码段直接删除，不要注释掉(试点)

- **规则ID**：2b540c44-8c8f-4a0e-acce-53792d95d8f5
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

被注释掉的代码，无法被正常维护；当企图恢复使用这段代码时，极有可能引入易被忽略的缺陷。



正确的做法是，不需要的代码直接删除掉。若再需要时，考虑移植或重写这段代码。

**【正确示例】**

```
#!/bin/bash
  read -rs passwd

```
**【错误示例】**

```
#!/bin/bash
  # 不符合：不用的代码段直接删除，不要注释掉
  #passwd=$1
  read -rs passwd

```
**【修复建议】**

- 删除注释掉的代码
