# G.ARR.05 不同类型的对象指针之间不应进行强制转换

- **规则ID**：08462a69-989a-4d02-a792-06f68da31f15
- **更新时间**：2025-03-25 19:21:41

---

**【问题级别】**

一般

**【描述】**

不同的对象类型可能有不同的对齐要求，如果在不同类型的对象指针之间做强制转换，或转化为void指

针后再转换为不同类型的对象指针，对象的对齐方式可能被改变，从而导致程序产生未定义行为。

**【正确示例】**

```
如下代码示例中，char 类型值被保存在一个类型为 int 的对象中，这样指针的值会被正确对齐。
char c = 'x';
int i = c;
int *intPtr = &i;

ASSERT(intPtr == &i);

```
**【错误示例】**

```
如下代码示例中，char类型指针&c 被转换为更严格对齐的int类型指针intPtr再被强制转换为char类型指针charPtr。在某些实现上，charPtr将不匹配&c。因此，如果将一个对象类型的指针转​​换为另一个对象类型的指针，则第二个对象类型的对齐要求不能比第一个更加严格。
char c = 'x';         // 变量c的地址可能不在int对齐(通常为4字节对齐)的内存边界上
int *intPtr = (int *)&c;  // 不兼容的转换
char *charPtr = (char *)intPtr;

ASSERT(charPtr == &c);     // 在一些系统下会因地址不对齐失败

```
**【修复建议】**

应该使用相同类型的指针。
