# G.SEC.04 禁止使用调试方式执行Shell脚本

- **规则ID**：5f184e05-f754-48a3-b198-521ec6a0fa19
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

1. 当使用调试方式执行包含敏感信息变量的代码时会把敏感信息明文显示出来，造成敏感信息泄漏。

2. 含义敏感信息处理的Shell脚本需要在脚本中显示set +x关闭调试模式。

**【正确示例】**

```
```
shell
#!/bin/bash
bash ./test.sh
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 使用调试模式调用其他脚本文件
bash -x ./test.sh
```

```
**【修复建议】**

1. bash、sh命令执行脚本时，去掉-x参数。

2. set命令去掉-x参数。

3. shebang解释器中去掉-x参数。

4. 在脚本中使用set +x关闭调试回响模式。
