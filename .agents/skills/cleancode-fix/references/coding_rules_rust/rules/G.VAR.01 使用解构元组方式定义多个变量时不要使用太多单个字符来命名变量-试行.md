# G.VAR.01 使用解构元组方式定义多个变量时不要使用太多单个字符来命名变量-试行

- **规则ID**：74bf0973-ae78-4378-8031-a30981213472
- **更新时间**：2025-06-05 04:40:01

---

**【问题级别】**

一般

**【描述】**

在解构元组的方式定义多个变量时，有时候变量命名可能是无特别语义的，比如临时值，可以用简单的单个字符来定义变量名，但是不宜太多。

**【正确示例】**

```
// 元组元素超过三个的，建议使用包含语义的变量命。

let (width, high, len, shape, color, status) = (...);

```
**【错误示例】**

```
let (a, b, c, d, e, f, g) = (...);

```
