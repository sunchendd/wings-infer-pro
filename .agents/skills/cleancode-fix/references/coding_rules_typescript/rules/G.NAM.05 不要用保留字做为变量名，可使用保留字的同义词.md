# G.NAM.05 不要用保留字做为变量名，可使用保留字的同义词

- **规则ID**：be0a25e3-708e-4d0b-a2dc-290dc3c94512
- **更新时间**：2025-06-05 04:35:00

---

**【问题级别】**

提示

**【描述】**

保留字在某种意思上是为将来的关键字而保留的单词，因此，不要使用保留字，请用保留字的同义词。

**【正确示例】**

```
let defaults = { clark: "kent" };

```
**【错误示例】**

```
const superman = {
  default: { clark: "kent" },
  private: true,
};

```
**【修复建议】**

不要使用保留字，请用保留字的同义词。
