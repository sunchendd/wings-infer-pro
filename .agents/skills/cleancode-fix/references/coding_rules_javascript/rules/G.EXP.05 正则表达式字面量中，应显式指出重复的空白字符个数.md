# G.EXP.05 正则表达式字面量中，应显式指出重复的空白字符个数

- **规则ID**：c204e46e-462f-4124-9f3d-a7ac72121665
- **更新时间**：2026-04-07 04:25:02

---

**【问题级别】**

提示

**【描述】**

在使用正则表达式时， 如果使用了多个重复的空白字符，会很容易出错，且不易阅读。因此，在正则表达式字面量中，应显式指出重复的空白字符个数。

**【正确示例】**

```
##### 场景1：正则表达式
- 修复示例：在正则表达式中，使用数字显式指出有几个空格。
```javascript
const re = /foo {3}bar/;  // 通过{3}显式指出这里需要3个空格
const re = new RegExp('foo {3}bar');
```

```
**【错误示例】**

```
##### 场景1：正则表达式
- 错误示例：在正则表达式中，包含几个空格，就空几个空格。
```javascript
const re = /foo   bar/;  // 很难看出来这里是几个空格
const re = new RegExp('foo   bar');
```

```
**【修复建议】**

正则表达式字面量中，应显式指出重复的空白字符个数。
