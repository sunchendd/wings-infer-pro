# G.FMT.02 缩进风格检查

- **规则ID**：361eb051-2e89-4b90-a5e3-d76052aafcca
- **更新时间**：2026-04-07 04:45:00

---

**【问题级别】**

一般

**【描述】**

行号：xxx，列号：xxx：不允许使用tab键缩进

**【正确示例】**

```
```
function func()
    ...
end
```

```
**【错误示例】**

```
```
function func()
[tab]...
end
```

```
**【修复建议】**

缩进使用 4 空格而不是TAB，请设置你的编辑器自动扩展 TAB 键为 4 空格。
