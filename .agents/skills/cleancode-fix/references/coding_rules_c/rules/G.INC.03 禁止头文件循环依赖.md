# G.INC.03 禁止头文件循环依赖

- **规则ID**：3350a58d-4cf5-407c-b254-6098e92b5a06
- **更新时间**：2026-04-07 04:10:02

---

**【问题级别】**

严重

**【描述】**

头文件循环依赖是指多个头文件相互包含（include）而形成的循环依赖关系，任意头文件修改都会导致所有包含环中的头文件的代码被重新编译。因此，需要禁止头文件循环依赖。

**【正确示例】**

```
##### 场景1：头文件循环依赖
- 修复示例：

```c
// a.h
#include "b.h" // 符合：a.h，b.h和c.h不构成循环依赖

// b.h
#include "c.h"

// c.h
#include "xx.h"
```

```
**【错误示例】**

```
##### 场景1：头文件循环依赖
- 错误示例：
```c
// a.h
#include "b.h" // 不符合：a.h，b.h和c.h循环依赖

// b.h
#include "c.h"

// c.h
#include "a.h"
```

```
**【修复建议】**

重构代码逻辑，避免头文件循环依赖。
