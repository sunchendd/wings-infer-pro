# GoFence 整数回绕

- **规则ID**：6b9f7307-5f6d-4b4e-b729-a9cb08044b78
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

"回绕"指不能用无符号的整数表示运算的结果，运算结果将会根据该类型表示的最大值加”1“

执行操作。无符号整数的回绕会发生在如下操作中：

+、-、 *、++、--、+=、-=、* =、<<=、<< 和 -后续代码如果以此作为分配内存的大小，将导致申请的内存比实际所需过小或者过大，从而导致内存不足的问题。将运算结果用以下用途，应防止回绕：

* 作为数组、slice的索引

* 作为待申请数组变量的大小

* 作为数组、slice的边界（如作为循环计数器）

**【正确示例】**

```
```
func intewrapgood(b uint8) uint8 {
	var a uint8 = math.MaxUint8
	if b > a-2 {
		return 0 //错误处理,避免出现回绕情况
	} else {
		c := b + 2
		return c
	}
}
```

```
**【错误示例】**

```
```
func interbad() {
	var a uint8 = math.MaxUint8
	c := a + 2 // error，此处会发生回绕
	fmt.Printf("%T, %v
", c, c)
}
```

```
**【修复建议】**

在运算之前添加校验，确保不会产生无符号数回绕。--------参考华为go语言编程规范3.1
