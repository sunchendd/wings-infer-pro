# G.NAM.07 使用统一的文件命名风格，文件扩展名应小写

- **规则ID**：7f5a1890-6081-4869-b401-5a24a3150e8a
- **更新时间**：2025-06-05 04:25:02

---

**【问题级别】**

提示

**【描述】**

使用统一的文件命名风格，文件扩展名应小写

**【正确示例】**

```
// 若存储的文件名为'afilename.txt'，则以下文件名的使用与创建符合
afilename.txt

```
**【错误示例】**

```
// 若存储的文件名为'afilename.txt'，则以下文件名的使用与创建均不符合
afileName.txt
afilename.TXT

```
**【修复建议】**

文件扩展名小写
