# G.PRE.01-CPP 禁止使用宏来表示常量

- **规则ID**：8a77d438-1076-40a4-9482-f3f9e2a22db7
- **更新时间**：2025-03-25 19:22:45

---

**【问题级别】**

严重

**【描述】**

宏是简单的文本替换，在预处理阶段时完成，运行报错时直接报相应的值；跟踪调试时也是显示值，而不是宏名；宏没有类型检查，不安全；宏没有作用域。

**【正确示例】**

```
constexpr int MAX_MSISDN_LEN = 20; // 符合：在C++11及之后的版本中，优先使用constexpr
const int MAX_MSISDN_LEN = 20;     // 符合：使用const常量

```
**【错误示例】**

```
##### 场景1：使用宏来表示常量
- 错误示例：

  ```cpp
  #define MAX_MSISDN_LEN 20 // 不符合
  ```

```
**【修复建议】**

使用constexpr表示常量
