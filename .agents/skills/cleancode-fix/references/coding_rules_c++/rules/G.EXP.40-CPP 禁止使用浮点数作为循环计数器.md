# G.EXP.40-CPP 禁止使用浮点数作为循环计数器

- **规则ID**：df1af0da-db4d-4d03-957c-4e66d8234b88
- **更新时间**：2025-03-25 19:23:18

---

**【问题级别】**

一般

**【描述】**

IEEE浮点数算术标准（IEEE 754）中规定了浮点类型的表示方法。因为存储二进制浮点的bit位是有限的，所以二进制浮点数的表示范围也是有限的，并且无法精确地表示所有实数。因此，浮点数计算结果也不是精确值，不能将浮点变量用作循环计数器。

**【正确示例】**

```
如下代码中，循环计数器由浮点数修改为整数。

for (int count = 0; count < 13000; ++count) {
    ... // 执行13000次 
}

```
**【错误示例】**

```
如下代码中，使用浮点变量用作循环计数器，执行的循环次数可能是非预期的。

for (float x = 0.0f; x < 1.3f; x += 0.0001f) {
    ... // 可能执行12999次  
}

```
**【修复建议】**

禁止使用浮点数作为循环计数器。
