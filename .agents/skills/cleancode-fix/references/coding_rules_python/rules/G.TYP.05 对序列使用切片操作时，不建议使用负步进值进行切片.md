# G.TYP.05 对序列使用切片操作时，不建议使用负步进值进行切片

- **规则ID**：2b8d2fa7-6802-434e-9b37-8c599053fa52
- **更新时间**：2026-04-07 04:15:04

---

**【问题级别】**

一般

**【描述】**

Python提供了example_list[start : end : stride]形式的写法，以实现步进切割，也就是从每stride个元素中取一个出来。但如果stride值为负，则会使代码难以理解，特定使用场景下还会造成错误。

**【正确示例】**

```
my_list = [1, 2, 3, 4, 5, 6, 7, 8]
new_list = my_list[::2]
print(new_list)  # [1, 3, 5, 7]
last_list = new_list[1:-1]
print(last_list)  # [3, 5]

```
**【错误示例】**

```
# 以下例子可以看出，在start : end : stride都使用的情况下使用负的stride，会导致代码难以阅读。因此，尽量使用stride为正数，并且尽量不要同时使用start、 end 、 stride。如果确实要执行这种操作，建议将“步进”切割过程和“范围”切割过程分开，使代码更清晰。
>>> a = [1,2,3,4,5,6,7,8]
>>> a[-2::-2] 
[7, 5, 3, 1]
>>> a[-2:2:-2]  
[7, 5]
>>> a[2:2:-2]
[]

【例外】
在处理类似字符反转的需求时，可使用负步进值进行切片a[::-1]。

```
**【修复建议】**

尽量使用stride为正数，并且尽量不要同时使用start、 end 、 stride。如果确实要执行这种操作，建议将“步进”切割过程和“范围”切割过程分开，使代码更清晰。
