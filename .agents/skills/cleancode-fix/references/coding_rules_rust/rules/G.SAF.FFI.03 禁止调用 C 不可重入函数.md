# G.SAF.FFI.03 禁止调用 C 不可重入函数

- **规则ID**：7696cb4d-c314-40f2-acd5-c0764be48583
- **更新时间**：2026-04-07 04:40:01

---

**【问题级别】**

一般

**【描述】**

禁止调用 C 不可重入函数

**【正确示例】**

```
```
let _tm = libc::localtime(&0i64 as *const libc::time_t);
```

```
**【错误示例】**

```
```
let res = libc::malloc(std::mem::size_of::<libc::tm>());

libc::locatime_r(&0i64 as *const libc::time_t, res);
```

```
**【修复建议】**

在多线程条件下调用外部不可重入函数时，有可能会因竞争条件而导致意外的系统状态和不可预测的结果，或导致拒绝服务和任意代码执行等内存安全问题。一般情况下，开发者可将这些函数替换为其可重入版本，否则需要根据情况解决或预防因竞争而产生的问题。
