# G.NAM.03 类、枚举和接口名应采用大驼峰命名

- **规则ID**：a7671204-6d77-4c1d-b226-edd2fe0fb286
- **更新时间**：2026-04-07 04:00:05

---

**【问题级别】**

提示

**【描述】**

类名、接口名通常是名词或名词短语，接口名还可以是形容词或形容词短语，都应采用**大驼峰命名**，例如：ArrayList（类）、Collection（接口）、Comparable（接口）等。

**【正确示例】**

```
##### 场景1：类名没有使用大驼峰命名
- 修复示例：
  ```java
  class MarcoPolo { // 【GOOD】类名要采用大驼峰命名
      ...  
  }
  ```
##### 场景2：枚举类名没有使用大驼峰命名
- 修复示例：
  ```java
  enum ComparisonResult { // 【GOOD】枚举类名要采用大驼峰命名
      ...  
  }
  ```
##### 场景3：接口名没有使用大驼峰命名
- 修复示例：
  ```java
  interface ParameterSetNameInterface { // 【GOOD】接口名要采用大驼峰命名
      ...  
  }
  ```


```
**【错误示例】**

```
##### 场景1：类名没有使用大驼峰命名
- 错误示例：
  ```java
  class marcoPolo { // 【不符合】类名采用了小驼峰命名
      ...  
  }
  ```
##### 场景2：枚举类名没有使用大驼峰命名
- 错误示例：
  ```java
  enum  comparisonResult { // 【不符合】枚举类名采用了小驼峰命名
      ...  
  }
  ```
##### 场景3：接口名没有使用大驼峰命名
- 错误示例：
  ```java
  interface parameterSetNameInterface { // 【不符合】接口名采用了小驼峰命名
      ...  
  }
  ```


```
**【修复建议】**

类、枚举和接口名应采用大驼峰命名。
