# G.NAM.08 包名应该与所在目录名一致

- **规则ID**：e41aa90b-e74c-4e33-bd5b-94d4416b2153
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

包名应该与其所在目录名一致，如果不一致，会在代码阅读和引用过程中带来困扰。



例如目录`md5`中的包名应该使用`md5`，而不是 `md5_hash`。

**【正确示例】**

```
##### 场景1：目录名与包名不一致
- 修复示例：修改目录名或包名，两者命名保持一致。

  ```go
  // 符合：目录名与包名一致
  md5         // 目录名

  package md5 // 包名
  ```


```
**【错误示例】**

```
##### 场景1：目录名与包名不一致
- 错误示例：

  ```go
  // 不符合：目录名与包名不一致
  md5_hash    // 目录名

  package md5 // 包名
  ```


```
**【修复建议】**

修改目录名或包名，两者命名保持一致。
