# DC.G.FUN.04 函数返回值数量少于多值赋值接受者数量

- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：多值赋值语句xxx中左值右值个数不匹配

**【正确示例】**

```
```
local a = f() -- f()的返回值个数为1
```

```
**【错误示例】**

```
```
local a, b = f() -- f()的返回值个数为1
```

```
**【修复建议】**

多值赋值接受者个数不应多于函数返回值个数
