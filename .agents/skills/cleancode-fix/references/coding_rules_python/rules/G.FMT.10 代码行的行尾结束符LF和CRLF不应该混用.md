# G.FMT.10 代码行的行尾结束符LF和CRLF不应该混用

- **规则ID**：cb18a1dd-94a6-421e-8c70-0774bccb905f
- **更新时间**：2026-04-07 04:15:01

---

**【问题级别】**

一般

**【描述】**

项目文件中，代码行的行尾结束符LF和CRLF不应该混用。UNIX系统应使用LF作为行尾结束符，Window系统应使用CRLF作为行尾结束符。

**【正确示例】**

```
代码中使用单一系统格式的换行符

```
**【错误示例】**

```
代码中使用混合多个系统格式的换行符

```
**【修复建议】**

UNIX系统应使用LF作为行尾结束符，Window系统应使用CRLF作为行尾结束符。
