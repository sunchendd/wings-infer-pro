# G.CMT.05 正式交付给客户的代码不应包含TODO/FIXME注释

- **规则ID**：fee781c4-485e-4c4d-90bb-3d96d2c68053
- **更新时间**：2026-04-07 04:15:01

---

**【问题级别】**

一般

**【描述】**

TODO注释一般用来描述已知待改进、待补充的修改点，大小写均可。FIXME注释一般用来描述已知缺陷，大小写均可。

在版本开发阶段可以使用这两类标签标注一些待处理的问题；对于版本交付的代码中不应存在这两类标签，否则可能会被误解为代码中存在未实现的功能或已知的缺陷。

**【正确示例】**

```
##### 场景1：todo/fixme注释
- 修复示例：准备正式交付的代码中已删除TODO/FIXME注释
```python
def test(x, y):
    ...
    return true
```


```
**【错误示例】**

```
##### 场景1：todo/fixme注释
- 错误示例：准备正式交付的代码中存在TODO/FIXME注释
```python
def test(x, y):
    ...
    # TODO: 补充XX处理
    # FIXME: XX缺陷
    ...
    return true
```


```
**【修复建议】**

正式交付的代码中，排查所有的TODO、FIXME注释，保证功能是完整的，已知缺陷都已经被修复，并将所有的TODO、FIXME注释删除。
