# G.SEC.09 禁止在Shell脚本中保留敏感信息

- **规则ID**：e1f7f19e-0f11-4bd3-9fb2-bc0f9a6a9ca2
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

禁止在Shell脚本中保留敏感信息，包括密码、姓名、工号、联系方式、地址等公司信息，以及可能造成误解的描述，例如攻击、破解等。

**【正确示例】**

```
```shell
#!/bin/bash
ls -l
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# Created by: x30000000
ls -l
```

```
**【修复建议】**

脚本注释中移除敏感信息，以及可能造成误解的描述。
