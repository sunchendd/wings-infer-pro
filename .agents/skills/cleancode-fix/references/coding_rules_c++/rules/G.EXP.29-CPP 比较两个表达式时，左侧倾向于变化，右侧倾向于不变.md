# G.EXP.29-CPP 比较两个表达式时，左侧倾向于变化，右侧倾向于不变

- **规则ID**：9edf59d7-7c48-441d-9e83-3a4f65af753c
- **更新时间**：2025-03-25 19:22:26

---

**【问题级别】**

一般

**【描述】**

当变量与常量比较时，如果常量放左边，如 if (MAX == v) 不符合阅读习惯，而 if (MAX > v) 更是难于理解。应当按人的正常阅读、表达习惯，将常量放右边。

**【正确示例】**

```
if (value == MAX) {
    ...
}

if (value < MAX) {
    ...
}

```
**【错误示例】**

```
if (NULL == ptr) { // 不符合
}

```
**【修复建议】**

将变量放在比较表达式左侧
