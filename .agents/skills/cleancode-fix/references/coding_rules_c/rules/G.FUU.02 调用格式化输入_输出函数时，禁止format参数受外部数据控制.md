# G.FUU.02 调用格式化输入/输出函数时，禁止format参数受外部数据控制

- **规则ID**：75e5bb4a-d967-47e0-b28c-bbacb4ce76b4
- **更新时间**：2026-04-07 04:10:01

---

**【问题级别】**

一般

**【描述】**

外部数据作为格式化字符串参数执行会导致格式化字符串攻击，攻击者可以使被攻击的进程崩溃、查看栈内容、查看内存内容或者在任意内存位置写入数据。

因此，为了防范格式化字符串攻击，只将常量字符串作为format参数。

覆盖的格式化函数如下：

* 格式化输出函数: xxxprintf;

* 格式化输入函数: xxxscanf;

* 格式化错误消息函数: err(), verr(), errx(), verrx(), warn(), vwarn(), warnx(), vwarnx(), error(), error_at_line();

* 格式化日志函数: syslog(), vsyslog().

**【正确示例】**

```
##### 场景1：format参数是变量。
- 修复示例：format参数使用常量字符串，不使用变量，变量可作为字符串输出。

```c
char *msg = GetMsg();
...
err(eval, "%s", msg); // 符合：函数的format参数为字符串常量"%s"，msg作为字符串输出
```


```
**【错误示例】**

```
##### 场景1：format参数是变量。
- 错误示例：

```c
char *msg = GetMsg();
...
err(eval, msg); // 不符合：format参数来自函数返回值，不是字符串常量或空值
```


```
**【修复建议】**

format参数使用常量字符串，不使用变量，变量可作为字符串输出。
