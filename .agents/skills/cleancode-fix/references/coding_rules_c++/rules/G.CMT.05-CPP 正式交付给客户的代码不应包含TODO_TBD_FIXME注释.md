# G.CMT.05-CPP 正式交付给客户的代码不应包含TODO/TBD/FIXME注释

**【问题级别】**

**【描述】**

TODO/TBD注释一般用来描述已知待改进、待补充的修改点。

FIXME 注释一般用来描述已知缺陷。



正式交付给客户的代码中不能包含这类注释，并且它们都应该有统一风格，方便文本搜索统一处理。
