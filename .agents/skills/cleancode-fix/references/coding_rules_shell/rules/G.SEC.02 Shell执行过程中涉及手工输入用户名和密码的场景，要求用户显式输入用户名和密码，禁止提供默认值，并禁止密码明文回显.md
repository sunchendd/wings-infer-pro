# G.SEC.02 Shell执行过程中涉及手工输入用户名和密码的场景，要求用户显式输入用户名和密码，禁止提供默认值，并禁止密码明文回显

- **规则ID**：bd46a678-a254-4509-b197-b610370644b7
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

Shell执行过程中涉及手工输入用户名和密码的场景，要求用户显式输入用户名和密码；如果不关闭密码明文回显，会导致密码明文可见，存在密码隐私泄漏的风险。

**【正确示例】**

```
```shell
#!/bin/bash
echo "Please input password:"
# 符合：关闭密码明文回显
read -s password
```

```
**【错误示例】**

```
```shell
#!/bin/bash
echo "Please input password:"
# 不符合：密码明文回显，存在泄漏风险
read password
```

```
**【修复建议】**

使用read命令输入密码时加上-s参数防止密码回显。
