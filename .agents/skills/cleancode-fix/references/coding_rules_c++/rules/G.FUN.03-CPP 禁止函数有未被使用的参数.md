# G.FUN.03-CPP 禁止函数有未被使用的参数

- **规则ID**：67a0e227-f0c6-4575-8955-477693950499
- **更新时间**：2025-03-25 19:22:00

---

**【问题级别】**

严重

**【描述】**

在函数中不应有未被使用的参数。如果存在未被使用的参数，可能代表着函数的实现与规格不相符，并且容易引起误解，也可能导致传参时出现不正确的参数匹配。



当由于某些原因需要保留未被使用的参数时，应通过注释的方式将该参数修改为未命名参数，或者显式指定出该参数是未被使用的（C++17中提供了[[maybe_unused]]属性）

**【错误示例】**

}
