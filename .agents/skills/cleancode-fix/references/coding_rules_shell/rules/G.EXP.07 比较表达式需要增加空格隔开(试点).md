# G.EXP.07 比较表达式需要增加空格隔开(试点)

- **规则ID**：7be85c06-4641-4ad3-8bab-d30ecf644299
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

比较表达式需要增加空格区分开参数和比较符号。字符串比较和数值比较都适用。

**【正确示例】**

```
#!/bin/bash
  a="1"
  if [ "$a" = "1" ]
  then
     echo "is 1"
  fi

```
**【错误示例】**

```
#!/bin/bash
  a="1"
  # 不符合：把[]里面的内容作为整体判断字符是否为空，该判断一直为true
  if [ "$a"="1" ]
  then
     echo "is 1"
  fi

```
**【修复建议】**

比较表达式需要增加空格区分开参数和比较符号
