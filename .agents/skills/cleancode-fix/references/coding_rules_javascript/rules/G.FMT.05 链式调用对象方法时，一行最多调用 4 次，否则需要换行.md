# G.FMT.05 链式调用对象方法时，一行最多调用 4 次，否则需要换行

- **规则ID**：3e9d1053-249a-46a7-b9ba-b99e81c3ef9e
- **更新时间**：2026-04-07 04:25:00

---

**【问题级别】**

提示

**【描述】**

链式调用对象方法时，一行最多调用 4 次，否则需要换行。换行的时候，需要按照缩进章节的要求进行缩进，并且在前面加点. 强调这是方法调用而不是新语句。

**【正确示例】**

```
##### 场景1：链式调用对象方法
- 修复示例：链式调用对象方法时，当方法个数超过4个时，每个方法单独一行。
```javascript
$('#items')
  .find('.selected')
  .highlight()
  .end()
  .find('.open')
  .updateCount();

```

```
**【错误示例】**

```
##### 场景1：链式调用对象方法
- 错误示例：链式调用对象方法时，方法个数超过了4个，但是没有进行换行。

```javascript
$('#items').find('.selected').highlight().end().find('.open').updateCount();

// 换行时，把.放到了后面
$('#items').
  find('.selected').
  highlight().
  end().
  find('.open').
  updateCount();
```

```
**【修复建议】**

1、链式调用对象方法时，当方法个数没有超过4个时，要么每个方法单独一行，要么所有方法在同一行。

2、链式调用对象方法时，当方法个数超过4个时，建议换行，每个方法单独一行，并且换行时，需要按照缩进章节的要求进行缩进，并且在前面加点`.` 。
