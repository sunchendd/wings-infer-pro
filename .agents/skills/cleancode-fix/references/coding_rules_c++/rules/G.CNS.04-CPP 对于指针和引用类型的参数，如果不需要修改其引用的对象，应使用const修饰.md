# G.CNS.04-CPP 对于指针和引用类型的参数，如果不需要修改其引用的对象，应使用const修饰

- **规则ID**：7d768db7-ee31-43fc-aebb-5a7df5eb6f32
- **更新时间**：2025-03-25 19:22:03

---

**【问题级别】**

严重

**【描述】**

不变的值更易于理解、跟踪和分析，把 const 作为默认选项，在编译时会对其进行检查，使代码更牢固、更安全。

**【正确示例】**

```
SomeType::SomeType(const SomeType& other)
{
    ... // 不会去修改other对象
}

```
**【错误示例】**

```
##### 场景1：引用类型参数未被修改
- 错误示例：

```cpp
void Log(int32_t &val) // 不符合
{
    std::cout << "val = " << val << std::endl;
}
```

```
**【修复建议】**

添加const修饰符
