# G.CTL.04 禁止使用浮点数作为循环计数器

- **规则ID**：6a7a4b28-bc1e-4b48-bb6a-16a173453874
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

浮点数的精度有限，使用浮点数作为循环计数器可能会导致循环次数不准确，包括循环次数过多或过少。

因此，禁止使用浮点数作为循环计数器，建议使用整数作为循环计数器。

**【正确示例】**

```
##### 场景1：使用浮点变量用作循环计数器可能会导致循环次数不准确
- 修复示例：

```c
int x = 0;
for (; x < 10; x++) {           // 符合： 执行的循环次数是10次，符合预期
    count++;
}

int y = 0;
while (y <= 10) {               // 符合： 执行的循环次数是10次，符合预期
    y++;
    ...
}

int z = 0;
do {
    z++;
    ...
} while (z < 10);               // 符合： 执行的循环次数是10次，符合预期
```


```
**【错误示例】**

```
##### 场景1：使用浮点变量用作循环计数器可能会导致循环次数不准确
- 错误示例：

```c
float x = 0;
for (; x < 0.1; x += 0.01) {    // 不符合： 执行的循环次数可能11次，而非预期的10次
    ...
}

float y = 0;
while (y <= 0.1) {              // 不符合： 执行的循环次数可能11次，而非预期的10次
    y += 0.01;
    ...
}

float z = 0;
do {
    z += 0.01;
    ...
} while (z < 0.1);              // 不符合： 执行的循环次数可能11次，而非预期的10次
```


```
**【修复建议】**

建议使用整数作为循环计数器。
