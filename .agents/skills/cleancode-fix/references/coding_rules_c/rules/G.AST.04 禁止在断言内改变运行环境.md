# G.AST.04 禁止在断言内改变运行环境

- **规则ID**：2caaf7ee-b5fd-4016-80e3-ed06c27de7d6
- **更新时间**：2026-04-07 04:10:05

---

**【问题级别】**

严重

**【描述】**

在程序正式发布阶段，断言不会被编译进去，为了确保调试版和正式版的功能一致性，严禁在断言中使用任何赋值、修改变量、资源操作、内存申请等操作。

**【正确示例】**

```
void GoodCase01()
{
    int i = 0；
    int j = 1;
    ASSERT(i == j);
}

```
**【错误示例】**

```
ASSERT(p1 = p2);        // p1被修改
ASSERT(i++ > 1000);     // i被修改
ASSERT(close(fd) == 0); // fd被关闭

```
**【修复建议】**

调用ASSERT，入参中不能使用赋值（例如 =、+=、-= 或<<=）、递增和递减（例如++或—）、修改堆（例如 ASSERT(new xxx)）
