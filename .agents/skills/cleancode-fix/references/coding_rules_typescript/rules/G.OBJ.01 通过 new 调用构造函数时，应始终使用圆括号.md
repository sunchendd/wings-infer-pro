# G.OBJ.01 通过 new 调用构造函数时，应始终使用圆括号

- **规则ID**：a4c0b8a0-ad6a-4e36-b83b-3964f328e4b4
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

提示

**【描述】**

通过 new 调用构造函数时，如果不带参数，可以省略后面的圆括号。但这样会造成与整体的代码风格不一致，建议团队约定使用圆括号。

**【正确示例】**

```
##### 场景1：通过new调用构造函数
- 修复示例：通过new调用构造函数时，带上圆括号。
```javascript
const person = new Person();
```

```
**【错误示例】**

```
```js
var person = new Person;
var person = new (Person);
```

```
**【修复建议】**

通过 new 调用构造函数时，应始终使用圆括号。
