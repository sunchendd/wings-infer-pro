# G.FMT.06 每行只能导入一个模块

- **规则ID**：04a4555a-1ea9-4d91-92c3-7a11d0e9ad6f
- **更新时间**：2026-04-07 04:15:01

---

**【问题级别】**

一般

**【描述】**

禁止一行导入多个模块语句，否则会影响程序阅读。

**【正确示例】**

```
##### 场景1：一行导入多个库
- 修复示例1：一行导入了一个库
```python
import os  # 符合
import sys
```
- 修复示例2：如果一行代码太长，可以放到元组中，然后换行
```python
from moviepy.editor import (VideoFileClip, TextClip,  # 符合
                            CompositeVideoClip, ColorClip)
```


```
**【错误示例】**

```
##### 场景1：一行导入多个库
- 错误示例：一行导入了两个库
```python
import os, sys  # 不符合
```


```
**【修复建议】**

1. 每行只能导入一个模块

2. 如果导入语句太长，可以放到元组中，然后换行。
