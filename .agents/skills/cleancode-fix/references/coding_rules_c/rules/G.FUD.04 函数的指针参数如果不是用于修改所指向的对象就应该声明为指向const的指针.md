# G.FUD.04 函数的指针参数如果不是用于修改所指向的对象就应该声明为指向const的指针

- **规则ID**：91a2777f-3720-45bb-932c-66a7a7731d48
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

如果函数的设计意图是不修改传入的数据，但是在函数内部被修改了，这将违背函数的预期行为，可能导致程序不符合预期。



因此，在函数定义中使用const修饰指针参数，以明确指出函数不会修改所指向的数据，增加代码可靠性。

**【正确示例】**

```
##### 场景1：函数本意是不需要修改入参指针指向的对象，但未加const保护
- 修复示例1：将指针参数声明为const

```c
void Log(const int32_t *val) // 符合
{            
    printf("val= %d", *val);
}
```

```
**【错误示例】**

```
##### 场景1：函数本意是不需要修改入参指针指向的对象，但未加const保护
- 错误示例：

```c
void Log(int32_t *val) // 不符合
{            
    printf("val= %d", *val);
}
```

```
**【修复建议】**

1. 如果函数设计上该指针指向对象不需要修改，将对应参数声明为 const 指针。

2. 避免将const限定的对象强制转换为非const对象，转换后，该非const对象被修改时，程序的行为是未定义的。
