# G.CLS.15-CPP 禁止重载逗号操作符、&&操作符和||操作符

- **规则ID**：1e6290c3-e618-4a63-a26e-9c638d0925a3
- **更新时间**：2025-03-25 19:22:12

---

**【问题级别】**

严重

**【描述】**

重载逗号操作符、&&操作符和||操作符会影响对象的求值顺序，并且会破坏&&和||操作符的短路求值属性。



C++17开始明确定义了重载逗号操作符的求值顺序与内置操作符一致。在C++17及之后的版本中可以重载逗号操作符。

**【正确示例】**

```
##### 场景1：重载逗号操作符
- 修复示例：禁止重载逗号操作符。
略
##### 场景2：重载&&操作符和||操作符
- 修复示例：禁止重载&&操作符和||操作符。
略

```
**【错误示例】**

```
##### 场景1：重载逗号操作符
- 错误示例：
```cpp
A operator , (const A &other) const // 不符合
{
    return other;
}
```
##### 场景2：重载&&操作符和||操作符
- 错误示例：
```cpp
class A {
public:
    explicit A(int a) : m(a) {}
    ~A() = default;
    bool operator && (const A &other) const // 不符合
    {
        return m && other.m;
    }
    bool operator || (const A &other) const // 不符合
    {
        return m || other.m;
    }

private:
    int m;
};
```

```
**【修复建议】**

不要重载逗号操作符、&&操作符和||操作符
