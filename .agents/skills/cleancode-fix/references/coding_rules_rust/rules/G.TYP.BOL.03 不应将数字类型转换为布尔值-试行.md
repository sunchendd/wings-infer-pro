# G.TYP.BOL.03 不应将数字类型转换为布尔值-试行

- **规则ID**：901d28e1-9b57-4a7a-b1b7-0ef16642c70e
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

一般

**【描述】**

这可能会让布尔值在内存中的表示无效。

**【正确示例】**

```
let x = 1_u8;
unsafe {
    let _: bool = std::mem::transmute(x); // where x: u8
}

```
**【错误示例】**

```
let x = 1_u8;
unsafe {
    let _: bool = (1u8 == x); 
}

```
