# G.NAM.04 标识符避免使用包名作为前缀

- **规则ID**：e99a7df8-7129-4b3e-b7f9-bb1c9da6e0ab
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

标识符再使用包名作为前缀，会导致代码过于累赘，不简洁。

**【正确示例】**

```
##### 场景1：导出的标识符使用了包名作为前缀
- 修复示例：删除包名前缀

  ```go
  // stream.go
  package stream

  type Buffer struct { // 符合：导出的标识符直接表明含义且不包含包名前缀
      ...
  }
  ```


```
**【错误示例】**

```
##### 场景1：导出的标识符使用了包名作为前缀
- 错误示例：

  ```go
  // stream.go
  package stream

  type StreamBuffer struct { // 不符合：导出的标识符使用了包名"stream"作为前缀
      ...
  }
  ```


```
**【修复建议】**

避免使用包名作为前缀
