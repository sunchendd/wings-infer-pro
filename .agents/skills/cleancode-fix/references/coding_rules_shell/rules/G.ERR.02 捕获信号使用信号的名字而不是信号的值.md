# G.ERR.02 捕获信号使用信号的名字而不是信号的值

- **规则ID**：75fe89e3-7d14-46a1-a60b-ab0a32492110
- **更新时间**：2026-04-07 04:30:00

---

**【问题级别】**

严重

**【描述】**

脚本中存在捕获信号的情况，具体捕获的信号使用信号名而不是信号值。 信号编号可能因平台而异。首选信号名称，它是固定的。

**【正确示例】**

```
```shell
#!/bin/bash
# 符合：捕获SIGINT信号
trap 'my_trap' SIGINT
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 不符合：捕获信号值为2的信号
trap 'my_trap' 2
```

```
**【修复建议】**

使用信号名代替信号值。
