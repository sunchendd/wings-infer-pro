# G.SAF.FFI.04 禁止使用外部内存不安全函数

- **规则ID**：3430253b-582e-49b1-b334-a4137e97ae22
- **更新时间**：2026-04-07 04:40:01

---

**【问题级别】**

一般

**【描述】**

禁止使用外部内存不安全函数

**【正确示例】**

```
```
不使用外部内存不安全函数
```

```
**【错误示例】**

```
```
extern "C" {
    fn memcpy(dest: *mut c_void, src: *const c_void, n: size_t) -> *mut c_void;
}
let ptr = unsafe { memcpy(dest, src, size); }
```

```
**【修复建议】**

对于这些不安全函数，在 Rust 中，一般有功能相同的安全函数可供使用。如对于内存拷贝和初始化，可以使用 std::mem 模块提供的函数进行处理。
