# G.PRE.07 宏的名称不应与关键字相同

- **规则ID**：5c5950ae-c330-4339-a82e-e294e6d3e0af
- **更新时间**：2025-03-25 19:23:04

---

**【问题级别】**

严重

**【描述】**

使用宏来改变语言关键字（包括用于实现语言扩展的关键字）的含义会导致代码难以理解。如果定义这种宏的同时又包含了标准头文件，则程序会产生未定义行为。

**【正确示例】**

```
##### 场景1：宏名和int重名
- 修复示例：

```cpp
#define DevId OTHER_TYPE // 符合：不要和关键字相同
#include <stdlib.h>
```
##### 场景2：宏名和while重名
- 修复示例：

```cpp
#define Traverse(x) for (; (x);) // 符合：不要和关键字相同
```
##### 场景3：宏名和const重名
- 修复示例：

```cpp
#define OTHER_DEFINE    // 符合：不要和关键字相同

int main()
{
    const int i = 0;
    i++;                // 编译报错

    return 0;
}
```

```
**【错误示例】**

```
// 不符合：改变了int的行为，导致后面包含标准头文件时，程序出现未定义的行为
#define int OTHER_TYPE
#include <stdlib.h>

// 不符合：重定义关键字
#define while(x) for (; (x);)

```
**【修复建议】**

修改宏的名称
