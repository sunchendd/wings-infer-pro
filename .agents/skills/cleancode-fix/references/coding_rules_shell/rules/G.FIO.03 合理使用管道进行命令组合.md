# G.FIO.03 合理使用管道进行命令组合

- **规则ID**：642fa7ed-5183-47ec-8f46-314ebe37747c
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

有一些命令是不会从stdin中读取信息的（比如echo、ls、rm、cp、true命令），这些命令无法使用管道进行组合。

**【正确示例】**

```
```shell
#!/bin/bash

# 管道右侧的echo命令不支持读取标准输入,使用xargs可以传递参数
ls | xargs echo

# 替换为支持读取标准输入的cat命令读取并打印
ls | cat

# 事实上ls命令可以直接打印命令输出，无需使用管道组合echo命令
ls
```

```
**【错误示例】**

```
```shell
#!/bin/bash

# 管道右侧的echo命令不支持读取标准输入,不能打印管道左侧命令的输出
ls | echo
```

```
**【修复建议】**

1. 在进行管道组合时，使用支持读取标准输入的命令如awk,cat,grep等。

2. 如果命令不支持读取标准输入，需要使用xargs传递。
