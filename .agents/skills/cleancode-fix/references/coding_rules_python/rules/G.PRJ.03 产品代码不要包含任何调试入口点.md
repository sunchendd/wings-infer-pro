# G.PRJ.03 产品代码不要包含任何调试入口点

- **规则ID**：a81781f9-91a5-49f7-b634-b9d8565a0156
- **更新时间**：2026-04-07 04:15:04

---

**【问题级别】**

致命

**【描述】**

由于调试或测试目的，开发者经常在代码中添加特定的调试或测试代码，这些代码并没有打算与应用一起交付或部署。当这类的调试或测试代码不小心被留在了应用中，这个应用对某些特殊交互就是开放的。这些后门入口点可能会导致安全风险。因此，开发者在交付前必须删除所有调试相关的代码。
