# G.CLS.14-CPP 禁止将指向派生类对象数组的指针赋值给指向基类的指针

- **规则ID**：1c94d3c7-faf4-4575-b014-6171cd290c10
- **更新时间**：2025-03-25 19:23:09

---

**【问题级别】**

严重

**【描述】**

在指针运算中，如果基类的指针指向了派生类的数组，那么在进行数组索引运算时，程序会产生未定义行为。

**【正确示例】**

```
Derived* der = new Derived[100];
der[10].Fun();

```
**【错误示例】**

```
如下代码中的base[10]会被解释成: *(base + 10 * sizeof(Base))。

Base* base = new Derived[100];
base[10].Fun();

```
**【修复建议】**

不要把指向派生类对象数组的指针赋值给指向基类的指针，做为基类指针使用。 202206版本07月小版本，增加开关"report_nonclass_array_singleton"，默认false只检查C++(指向派生类对象数组的指针赋值给指向基类的指针)；

true检查C、C++(单一对象的指针被错误地当作数组使用)。之前版本两场景都会检查。
