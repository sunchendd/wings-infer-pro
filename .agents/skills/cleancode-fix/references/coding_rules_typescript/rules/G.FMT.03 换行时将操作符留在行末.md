# G.FMT.03 换行时将操作符留在行末

- **规则ID**：1b7d5205-d09a-4c8d-a850-4a39c53a4f8b
- **更新时间**：2026-04-07 04:35:00

---

**【问题级别】**

提示

**【描述】**

当语句过长，或者可读性不佳时，需要在合适的地方换行。换行时将操作符放在行末，表示“未结束，后续还有”，保持与常用的格式化工具的默认配置一致。

**【正确示例】**

```
##### 场景1：换行后，操作符的位置
- 修复示例：换行后，操作符放在行末。
```javascript
flashPara.endAddr = flashPara.baseAddr + // 加号留在行末
  flashPara.size;      

```

```
**【错误示例】**

```
##### 场景1：换行后，操作符的位置
- 错误示例：换行后，操作符放在行首。
```javascript
flashPara.endAddr = flashPara.baseAddr  
  + flashPara.size;   // 加号留在行首     
```

```
**【修复建议】**

换行时将操作符放在行末，保持与常用的格式化工具的默认配置一致。
