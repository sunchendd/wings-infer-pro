# G.CTL.07 不要在迭代集合数据结构的过程中添加或删除元素

- **规则ID**：75373b3f-11ca-4293-bce6-078e5c5e929f
- **更新时间**：2026-04-07 04:20:00

---

**【问题级别】**

一般

**【描述】**

使用for-range或for循环可以便捷地访问集合数据结构（这里仅指slice）中的元素。程序如果在迭代集合数据结构过程中添加或删除元素，将可能导致不一致行为；或者因集合数据结构大小改变而索引访问此结构出现异常；或者因此导致死循环。

因此，不要在迭代slice的过程中添加或删除元素。

**【正确示例】**

```
##### 场景1：迭代slice时添加了元素。
- 修复示例：迭代时不添加或删除元素。
    ```go
    func main() {
        var a []int = []int{0, 1}
        for i := 0; i < len(a); i++ {
            ... // 符合：不添加或删除元素
        }
        n := len(a)
        for j := 0; j < n; j++ {
            a = append(a, 1, 2, 3)
        }
        ...
    }
    ```

```
**【错误示例】**

```
##### 场景1：迭代slice时添加了元素。
- 错误示例：迭代slice时添加了元素。
    ```go
    func main() {
        var a []int = []int{0, 1}
        for i := 0; i < len(a); i++ {
            a = append(a, 1, 2, 3) // 不符合：在迭代slice过程中添加了元素
            ...
        }
        ...
    }
    ```


```
**【修复建议】**

不要在迭代slice的过程中添加或删除元素。
