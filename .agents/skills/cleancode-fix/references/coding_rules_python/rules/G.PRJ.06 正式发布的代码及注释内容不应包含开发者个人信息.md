# G.PRJ.06 正式发布的代码及注释内容不应包含开发者个人信息

- **规则ID**：ff826272-abb8-407e-9595-e4180f5c7134
- **更新时间**：2026-04-07 04:15:04

---

**【问题级别】**

致命

**【描述】**

Python属于解释性语言，正式发布的代码及注释内容如果包含开发者个人信息，可能会泄露具体的开发人员信息，存在引发社会工程学方面的风险。因此应从正式发布的版本中删除开发者个人信息，比如工号、姓名、部门、邮箱、问题单号等。

版权声明是组织（华为）的声明，开发者个人没必要也不能用个人信息来做类似于版权声明的事情。

如果需要在代码中标明个人贡献，或者方便联系原作者进行代码维护，一般通过配置管理git等方式来实现，如果需要通过在开发代码中添加开发者个人信息，在发布代码时必须通过相关工具删除这类注释信息，否则会有社会工程学方面的风险。

**【正确示例】**

```
删除开发者个人信息，比如工号、姓名、部门、邮箱、问题单号等。

```
**【错误示例】**

```
def badTest():
    # POTENTIAL FLAW: Personal information is hard coded in the program
    employee_no = 'w12345678'

```
**【修复建议】**

删除开发者个人信息，比如工号、姓名、部门、邮箱、问题单号等。
