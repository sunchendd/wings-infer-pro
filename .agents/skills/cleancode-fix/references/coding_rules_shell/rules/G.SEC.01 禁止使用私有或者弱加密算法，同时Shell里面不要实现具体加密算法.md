# G.SEC.01 禁止使用私有或者弱加密算法，同时Shell里面不要实现具体加密算法

- **规则ID**：a7406a1b-6316-45d2-bdc6-3e3b2235bd75
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

禁止使用私有算法或者弱加密算法（比如DES，SHA1等）。应该使用经过验证的、安全的、公开的加密算法。有关如何选择和使用加密算法的更多信息，请参考《华为密码算法应用规范》。

**【正确示例】**

```
```shell
#!/bin/bash
openssl dgst -sha512 /tmp/test.txt
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 不符合：不符合密码算法应用规范
openssl dgst -sha /tmp/test.txt
```

```
**【修复建议】**

1. openssl dgst命令使用安全的加密算法（‘-sha256’， ‘-sha384’， ‘-sha512’， ‘-sha512-256’， ‘-sha3-256’， ‘-sha3-384’， ‘-sha3-512’）。

2. openssl enc命令使用安全的加密算法（’-aes-128-ctr‘， ’-aes-128-ofb‘， ’-aes-192-ctr‘， ’-aes-192-ofb‘， ’-aes-256-ctr‘， ’-aes-256-ofb‘， ’-chacha20‘）。

3. 不要使用私有加密算法。

4. 使用加密算法参考《华为密码算法应用规范》。
