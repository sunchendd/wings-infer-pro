# G.ERR.02 错误信息不应大写或以标点符号结尾

- **规则ID**：2994f41d-caa7-4660-85a9-c5b688e2dc14
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

错误字符串要求：除专有名词或缩略词外，应避免错误字符串以大写字母开头，或以标点符号结尾；因为通常错误信息会和其他内容组合之后输出。

**【正确示例】**

```
##### 场景1：出现字符串中间有大写字母开头的单词
- 修复示例：

  ```go
  fmt.Errorf("something bad") // 符合，该字符串和上下文拼接后，不会出现违反语法的情况.
  ```
##### 场景2：字符串以标点符号结尾
- 修复示例：

  ```go
  fmt.Errorf("something bad") // 符合
  ```


```
**【错误示例】**

```
##### 场景1：出现字符串中间有大写字母开头的单词
- 错误示例：

  ```go
  fmt.Errorf("Something bad") // 不符合，和上下文拼接后，出现字符串中间有大写字母开头的单词的情形
  ```
##### 场景2：字符串以标点符号结尾
- 错误示例：

  ```go
  fmt.Errorf("something bad.") // 不符合，字符串以标点符号结尾
  ```


```
**【修复建议】**

修改错误信息：避免错误字符串以大写字母开头，或以标点符号结尾。
