# G.FUD.02 宜合理使用 Result 类型或 must_use 修饰，保证用户有效处理返回值

- **规则ID**：e6f146eb-e2f6-49fe-b9a4-cea2669a08ba
- **更新时间**：2026-04-07 04:40:00

---

**【问题级别】**

提示

**【描述】**

RUST 中有以下方法可以在用户忽略函数返回值的时候出现编译告警：



- 返回值类型是 Result

- 函数定义增加 #[must_use] 修饰

- 函数返回的专有数据类型增加 #[must_use] 修饰

**【正确示例】**

```
```
#[must_use]
fn foo() -> i32 {
    // …
}

fn main() {
    let x = foo();
    // …
}
```

```
**【错误示例】**

```
```
#[must_use]
fn foo() -> i32 {
    // …
}

fn main() {
    foo();
    // …
}
```

```
**【修复建议】**

- RUST 中有以下方法可以在用户忽略函数返回值的时候出现编译告警：

  - 返回值类型是 `Result`

  - 函数定义增加 #[must_use] 修饰

  - 函数返回的专有数据类型增加 #[must_use] 修饰
