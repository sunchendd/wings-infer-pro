# G.ERR.02 捕获信号使用信号的名字而不是信号的值(试点)

- **规则ID**：6698be5b-c09e-48c0-a150-91a758d5f2ca
- **更新时间**：2025-06-05 04:30:00

---

**【问题级别】**

严重

**【描述】**

脚本中存在捕获信号的情况，具体捕获的信号使用信号名而不是信号值。 信号编号可能因平台而异。首

选信号名称，它是固定的

**【正确示例】**

```
#!/bin/bash
  # 符合：捕获SIGINT信号
  trap 'my_trap' SIGINT

```
**【错误示例】**

```
#!/bin/bash
  # 不符合：捕获信号值为2的信号
  trap 'my_trap' 2

```
**【修复建议】**

使用信号名代替信号值
