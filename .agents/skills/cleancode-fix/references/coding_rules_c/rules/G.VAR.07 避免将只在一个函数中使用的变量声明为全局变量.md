# G.VAR.07 避免将只在一个函数中使用的变量声明为全局变量

- **规则ID**：a65c0849-0ac2-4352-b6d0-b00c45e4dad4
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

变量如果仅在文件或函数范围内使用，在满足功能的同时，应在最小作用域内声明。

如果变量声明的范围比需要的范围大，则会降低代码的可读性，并可能被意外引用而产生预期之外的错误。

如：只在一个函数中使用的变量被声明为全局变量，扩大了变量的作用域，不符合本条规则。

**【正确示例】**

```
##### 场景1：全局变量只在一个函数内使用
- 修复示例：在IncreaseNumber()函数内声明`total`为一个静态变量，限制了被其他作用域引用的范围。静态修饰符在程序执行时一直存在，并且不会在函数调用之间消失

```c
void IncreaseNumber(void)
{
    static unsigned int total = 0; // 符合
    if (total > MAX_COUNT) {
        total = 0;
        ...
        return;
    }
    total++;
    ...
}
```

```
**【错误示例】**

```
##### 场景1：全局变量只在一个函数内使用
- 错误示例：变量`g_total`仅在IncreaseNumber函数中使用，该函数功能是访问并递增计数器变量`g_total`，当此变量`g_total`超过最大值`MAX_COUNT`时，重置计数器，并触发相应的业务处理
 
```c
unsigned int g_total = 0;

void IncreaseNumber(void)
{
    // 不符合：使用了全局变量g_total。根据场景看到，这里声明的范围太大了
    if (g_total > MAX_COUNT) {
        g_total = 0;
        ...
        return;
    }
    g_total++;
    ...
}
```

```
**【修复建议】**

如果变量只在一个函数内使用，建议变量作用域只限定在函数范围内。
