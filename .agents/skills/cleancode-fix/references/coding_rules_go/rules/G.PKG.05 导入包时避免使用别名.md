# G.PKG.05 导入包时避免使用别名

- **规则ID**：eaf0bc8f-470c-49c0-9ace-eb6de6d334ab
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

避免使用别名导入包。

**【正确示例】**

```
##### 场景1：使用别名导入包
- 修复示例：

  ```go
  import (
      "fmt"
      "os"
      "runtime/trace" // 符合：避免使用别名，直接导入包

      "aproject.com/oaservice" // 符合：避免使用别名，直接导入包
  )
  ```

```
**【错误示例】**

```
##### 场景1：使用别名导入包
- 错误示例：

  ```go
  import (
      "fmt"
      "os"
      rtrace "runtime/trace" // 不符合：使用别名

      oas "aproject.com/oaservice" // 不符合：使用别名
  )
  ```

```
**【修复建议】**

不要使用别名导入包，应直接导入包。
