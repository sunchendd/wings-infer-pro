# GoFence 整数转换符号错误

- **规则ID**：64c6005e-a0f4-4bd4-95da-7c237975f97f
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

有时候从带符号整型向无符号整型转换时，最高位会丧失作为符号位的功能，即产生符号丢失，从而数据失去原来的含义。

* 带符号整型数的值为非负，它向无符号整型转换后，值不变

* 带符号整型数的值为负时，它向无符号整型转换后，结果通常一个非常大的正数

**【正确示例】**

```
```
func foo() {
     var a int32 = math.MinInt32
     var b uint32
       // 正确：添加校验以确保不会发生符号错误
     if a < 0 {
           fmt.Println("转换错误")
     } else {
         b = uint32(a)
         fmt.Println("a=", a, "  ,b=", b)
     }
```

```
**【错误示例】**

```
```
下面代码中假设a为32位有符号的最小整数，把它转换为32位吴福海整数时，就会发生符号丢失现象。
func foo() {
    var a int32 = math.MinInt32
    var b uint32
    b = uint32(a) // 错误：产生符号丢失
    fmt.Println("a=", a, "  ,b=", b)//输出a= -2147483648   ,b= 2147483648
}
```

```
**【修复建议】**

在将有符号数向无符号数转换前，进行数据校验。--------------参考华为go语言编程规范3.1
