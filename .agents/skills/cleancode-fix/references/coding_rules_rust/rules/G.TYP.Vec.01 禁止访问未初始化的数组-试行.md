# G.TYP.Vec.01 禁止访问未初始化的数组-试行

- **规则ID**：e27879bb-f567-498c-8366-327b54bfec09
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

严重

**【描述】**

访问未初始化数组的内存会导致 未定义行为。

**【正确示例】**

```
fn main() {
    // 初始化有三个元素的数组
    let v = [1, 2, 3];
    println!("{:#?}", v);
}

```
**【错误示例】**

```
fn main() {
    // 初始化有三个元素的数组
    let v: Vec<i32> = vec![1, 2, 3];
    println!("{:#}", v);
}

```
