# G.TYP.CHR.01 整数到字符的类型转换应注意有效范围

**【问题级别】**

提示

**【描述】**

整数到字符的类型转换应注意有效范围

**【正确示例】**

```
确保转换为 char 的整数范围在 [0, 0xD7FF] 和 [0xE000, 0x10FFFF] 之间

```
**【错误示例】**

```
```
let x = char::from_u32(0xDE01);
```

```
**【修复建议】**

整数到字符的类型转换应注意有效范围
