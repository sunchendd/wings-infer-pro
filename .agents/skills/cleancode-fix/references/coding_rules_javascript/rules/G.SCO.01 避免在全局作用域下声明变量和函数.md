# G.SCO.01 避免在全局作用域下声明变量和函数

- **规则ID**：b403a54a-3127-42e3-8fa9-e4acdc47ed2b
- **更新时间**：2025-06-05 04:25:00

---

**【问题级别】**

提示

**【描述】**

对于浏览器中的脚本，每个script块的顶层都运行在全局作用域中，在全局作用域下变量和函数声明都会变成全局变量。建议全局变量应该使用一个唯一的，与工程/库相关的名字作为命名空间。否则，局部变量应该包裹在 IIFE 中。

**【正确示例】**

```
// 比如, 工程是 'eview', 那么全局变量的命名空间前缀可取为eview
window.eview = {};
window.eview.name = 'hello eview';
window.eview.button = function() {};
// 通过自执行匿名函数，避免外界访问，不污染全局作用域
(function() {
  const foo = 1;
  function bar() {}
})();

```
**【错误示例】**

```
// 在全局作用域
var foo = 1;
function bar() {}

```
**【修复建议】**

不要在全局作用域下声明变量和函数
