# G.OTH.03 不用的代码段包括import，直接删除，不要注释掉

- **规则ID**：03a3c836-7f8e-44a4-86ba-736d18ec52fc
- **更新时间**：2026-04-07 04:00:01

---

**【问题级别】**

一般

**【描述】**

不用的import，增加了代码的耦合度，不利于维护。

被注释掉的代码，无法被正常维护；当企图恢复使用这段代码时，极有可能引入易被忽略的缺陷。 

正确的做法是，不需要的代码直接删除掉。若再需要时，考虑移植或重写这段代码。

这里说的注释掉代码，包括用 /** */， /* */ 和 // 等等。



工具检查场景:

- 检查是否有无用的import语句

- 检查是否有注释掉的代码

**【正确示例】**

```
int b;

```
**【错误示例】**

```
// int a;
int b;

```
**【修复建议】**

删除注释或无用import语句
