# G.EXP.02 表达式的比较，应当遵循左侧倾向于变化、右侧倾向于不变的原则

- **规则ID**：fa8b7775-ae46-4ba6-b08f-3ba76126e975
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

当变量与常量比较时，如果常量放左边，如 if (MAX == v) 不符合阅读习惯，而 if (MAX > v) 更是难于理解。应当按人的正常阅读、表达习惯，将常量放右边。

**【正确示例】**

```
##### 场景1：比较表达式中，将常量放在了左边，不符合阅读习惯
- 修复示例：

```c
if (len < MAX_SIZE) { // 符合
  ...
}

if (len > MIN_SIZE) { // 符合
  ...
}
```


```
**【错误示例】**

```
##### 场景1：比较表达式中，将常量放在了左边，不符合阅读习惯
- 错误示例：

```c
if (MAX_SIZE >= len) { // 不符合
  ...
}

if (MIN_SIZE <= len) { // 不符合
  ...
}
```


```
**【修复建议】**

比较表达式将常量放右边。
