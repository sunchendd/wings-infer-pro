# G.LOG.02 及时删除使用完的临时文件(试点)

- **规则ID**：4ccb9b97-7887-4c2b-b025-fcfe7fb06ad8
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

- Shell脚本中通常会将临时文件存放在/tmp目录下，而/tmp默认对所有人可读写，如果将一些敏感信息保存在/tmp下的临时文件，该临时文件容易被监控、查看及攻击，导致临时文件攻击。

- 使用mktemp创建只有脚本作者能访问的临时目录，并用trap命令在脚本退出时删除整个临时目录。

**【正确示例】**

```
#!/bin/bash
  mktemp -d "/work_dir/tmp/tmp.log"

```
**【错误示例】**

```
#!/bin/bash
  # 不符合：在/tmp目录创建临时文件，容易被攻击
  mktemp -d "/tmp/tmp.log"

```
**【修复建议】**

- 临时文件不能创建在/tmp目录下

- 用 trap 命令在脚本退出时删除整个临时目录
