# G.CMT.05 代码注释置于对应代码的上方或右边

- **规则ID**：6e6b9b10-bd94-47a2-a5f7-9ff5092920fc
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

针对代码的注释，应该置于对应代码的上方或右边。

**【正确示例】**

```
##### 场景1：代码上方的注释不对齐
- 修复示例1：
  ```go
  // 符合：注释行格式对齐

  // MATCH /Unify the indent of comments/
  // Foo 函数的注释1
  // Foo 函数的注释2
  // Foo 函数的注释3
  func CMT05(a int, aa int, aaa int) {
  ```
##### 场景2：右边注释与代码之间没有空一格
- 修复示例1：
  ```go
  // 符合：右边注释与代码之间空一格

  func CMT05(a int, aa int, aaa int) { // Foo 函数的注释1
  ```


```
**【错误示例】**

```
##### 场景1：代码上方的注释不对齐
- 错误示例：

  ```go
  // 不符合：相邻注释行格式不对齐

  // MATCH /Unify the indent of comments/
      // Foo 函数的注释1
     // Foo 函数的注释2
  // Foo 函数的注释3
  func CMT05(a int, aa int, aaa int) {
  ```
##### 场景2：右边注释与代码之间没有空一格
- 错误示例：

  ```go
  // 不符合：右边注释与代码之间没有空一格

  func CMT05(a int, aa int, aaa int) {// Foo 函数的注释1
  ```


```
**【修复建议】**

- 代码上方的注释：与代码行间无空行，保持与代码一样的缩进。

- 代码右边的注释：与代码之间，至少留有1空格。通常右边的注释内容不宜过多，当注释超过行宽时，考虑将注释置于代码上方。
