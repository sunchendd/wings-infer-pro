# G.TYP.11 使用展开语法 … 或concat复制数组

- **规则ID**：df9f9627-4c55-42e8-848c-c5114c2bb2d2
- **更新时间**：2025-06-05 04:35:01

---

**【问题级别】**

提示

**【描述】**

展开语法可以通过减少赋值语句的使用，或者减少通过下标访问数组或对象的方式，使代码更加简洁优雅，可读性更佳。

**【正确示例】**

```
const itemsCopy = [...items];

```
**【错误示例】**

```
const len = items.length;
const itemsCopy = [];
// 复制数组
for (let i = 0; i < len; i++) {
  itemsCopy[i] = items[i];
}

```
**【修复建议】**

使用展开语法 ... 复制数组
