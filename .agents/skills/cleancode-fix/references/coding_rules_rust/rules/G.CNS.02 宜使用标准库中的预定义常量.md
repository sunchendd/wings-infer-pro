# G.CNS.02 宜使用标准库中的预定义常量

- **规则ID**：12d4f40b-98f1-46a7-ac14-e79e01c6aa4b
- **更新时间**：2026-04-07 04:40:00

---

**【问题级别】**

提示

**【描述】**

Rust标准库中已经提供了一些特殊常量的定义，其精确度通常会比开发者自行定义的高，所以若考虑数值精确度时则宜使用标准库已定义的特殊常量。



这些特殊常量都可以在标准库中找到，比如 std::f32::consts

**【正确示例】**

```
```
let x = std::f32::consts::PI;
let y = std::f64::consts::FRAC_1_PI;
```

```
**【错误示例】**

```
```
let x = 3.14;
let y = 1_f64 / x;
```

```
**【修复建议】**

Rust 中提供了一些特殊常量的定义（例如 std::f32::consts），其精确度通常会比开发者自行定义的高，所以若考虑数值精确度时，宜使用标准库预定义的特殊常量。
