# G.MET.06 始终将默认参数放在最后

- **规则ID**：04482e51-19bd-48c2-973e-2a1225ca9f76
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

提示

**【描述】**

将默认参数放在最后，在调用函数时，若默认参数没有值，就可以不传入这个参数，让调用代码更简单。

**【正确示例】**

```
##### 场景1：默认参数
- 修复示例：将默认参数放在了最后。
```javascript
function handleThings(name, opts = {}) {
  ...
}

```

```
**【错误示例】**

```
##### 场景1：默认参数
- 错误示例：将默认参数放在了第一个参数的位置。
```javascript
function handleThings(opts = {}, name) {
  ...
}

```

```
**【修复建议】**

当函数有多个参数时，应将默认参数放在最后。
