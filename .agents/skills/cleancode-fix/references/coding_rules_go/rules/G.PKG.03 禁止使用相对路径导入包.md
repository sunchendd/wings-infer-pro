# G.PKG.03 禁止使用相对路径导入包

- **规则ID**：c3ba1bc8-5918-4e47-ba0c-c4ad2b26bd2d
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

导入路径是唯一标识包的字符串，很多工具不能正确处理相对路径的导入，Go官方也不建议使用相对路径导入。

**【正确示例】**

```
##### 场景1：使用相对路径导入
- 修复示例：

  ```go
  import "github.com/repo/proj/src/net" // 符合：使用完整的路径
  ```


```
**【错误示例】**

```
##### 场景1：使用相对路径导入
- 错误示例：

  ```go
  import "../net"   // 不符合：使用了相对路径
  ```


```
**【修复建议】**

推荐使用mod包管理工具，并使用完整的路径导入
