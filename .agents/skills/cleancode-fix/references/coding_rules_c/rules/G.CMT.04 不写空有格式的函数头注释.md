# G.CMT.04 不写空有格式的函数头注释

- **规则ID**：c5f708ba-f0dd-407e-b533-596bbcda5cac
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

尽量通过函数名自注释其功能，**按需**写函数头注释。不要写空有格式的函数头注释；不要写无用、信息冗余的函数头注释。

**【正确示例】**

```
##### 场景1：空注释头
- 修复示例：函数头注释应当删除无用的信息，将重要、有用的信息表达清楚。

```c++
 /*
 * 返回实际写入的字节数，-1表示写入失败
 * 注意，内存 buf 由调用者负责释放
 */
 int WriteString(char *buf, int len);
```

```
**【错误示例】**

```
##### 场景1：空注释头
- 错误示例：参数项、返回值项为空

```c++
/*
 * 函数名：WriteString
 * 功能：写入字符串
 * 参数：
 * 返回值：
 */
int WriteString(char *buf, int len);
```

```
**【修复建议】**

补充内容或者删除空有格式的注释。
