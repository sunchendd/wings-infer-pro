# G.EXP.01 执行算术运算或比较操作的两个操作数要求具有相同的基本类型

- **规则ID**：aab42b89-b650-4e58-8bf8-459642da2e45
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

一般

**【描述】**

在执行算术运算或者比较操作时，C语言标准（参考C89标准第6.2.1.5章节、C99标准第6.3.1.8）允许不同类型操作数之间进行转换，包括显式转换和隐式转换，这对程序员来说自由度是相当大的。

然而，不管是显式转换还是隐式转换，均可能会导致数值丢失、符号丢失、精度丢失等问题。这就要求程序员必须明确识别类型转换之间的任何潜在风险，而显式转换肯定比隐式转换更容易识别风险，相同的基本类型之间的算术运算或比较操作肯定比显式转换更加容易被识别风险。



说明：自增和自减运算不在此规则约束范围内。

**【正确示例】**

```
如下示例代码中，修改x1的类型为 unsigned int 类型，使操作符的操作数具有相同基本数据类型：
uint32_t x1 = ...;
uint32_t x2 = ...;
enum enTA { CREATE, SET, DEL } a;
enum enTB { CANCEL, DELAY, TIMEOUT } b;
...
x1 += x2;
a > CREATE;
b == DELAY;

```
**【错误示例】**

```
如下示例代码中，操作符的操作数具有不同的基本类型，因此不符合本规范：
char c = ...;
int32_t x1 = ...;
uint32_t x2 = ...;
enum enTA { CREATE, SET, DEL } a;
enum enTB { CANCEL, DELAY, TIMEOUT } b;
...
x1 += x2;   // 不符合：有符号数和无符号数的混合使用
b > CREATE; // 不符合：不同枚举类型中的混合使用
a == b;     // 不符合：不同枚举类型中的混合使用
x2 += c;    // 不符合：无符号数和字符，混合使用


```
**【修复建议】**

执行算术运算或比较操作的两个操作数要求具有相同的基本类型
