# G.FMT.04 一行只有一条语句

- **规则ID**：acc1d981-a4dc-4908-968e-1c31b4d620e5
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

一个语句应该单独占一行，更加利于阅读和理解代码。

**【正确示例】**

```
##### 场景1：多个变量声明放在同一行
- 修复示例：

```c
int count = 10;                          // 符合
bool isCompleted = false;                // 符合

int a = 0;                               // 符合
int b = 0;                               // 符合

char *str = NULL;                        // 符合
char ch;                                 // 符合
char arr[10];                            // 符合

int x;
int y;
...
x = 1;                                   // 符合
y = 2;                                   // 符合
```
##### 场景2：一行多个语句
- 修复示例：

```c
void Func(int a, int b)
{
    if (b > 6) {
        a = b; // 符合
        b--;   // 符合
    }
}
```


```
**【错误示例】**

```
##### 场景1：多个变量声明放在同一行
- 错误示例：

```c
int count = 10; bool isCompleted = false; // 不符合：多个变量初始化需要分开放在多行

char *str, ch, arr[10];                   // 不符合：多个变量定义且类型不同，容易产生误解
int a = 0, b = 0;                         // 不符合：多个变量定义需要分开放在多行

int x;
int y;
...
x = 1; y = 2;                             // 不符合：一行中存在多个赋值语句
```
##### 场景2：一行多个语句
- 错误示例：

```c
void Func(int a, int b)
{
    if (b > 6) {
        a = b; b--; // 不符合
    }
}
```


```

将语句拆分到多行，一行只有一条语句。
