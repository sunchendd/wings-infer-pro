# G.FMT.07 合理安排空行

- **规则ID**：d9d15c70-e10d-4d94-9f37-022d16233995
- **更新时间**：2025-06-05 04:35:00

---

**【问题级别】**

提示

**【描述】**

使用空行可以凸显出代码块的相关程度，能提升代码的可读性。

**【正确示例】**

```
const obj = {
  foo() {},

  bar() {},
};

```
**【错误示例】**

```
const obj = {
  foo() {},
  bar() {},
};

```
**【修复建议】**

使用空行可以凸显出代码块的相关程度，能提升代码的可读性。
