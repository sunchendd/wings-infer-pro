# G.NAM.03 变量应采用小驼峰风格命名

- **规则ID**：92085b54-be64-4921-92af-841cf226605d
- **更新时间**：2025-06-05 04:35:03

---

**【问题级别】**

提示

**【描述】**

变量的名字通常是名词或名词短语，应采用小驼峰命名，以便于理解其含义。



该建议也适用于函数参数。

**【正确示例】**

```
const firstName = 'xiaoming';

```
**【错误示例】**

```
const firstname = 'xiaoming';

```
**【修复建议】**

变量的名字通常是名词或名词短语，应采用小驼峰命名
