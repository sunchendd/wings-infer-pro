# G.OTH.03 不用的代码段直接删除，不要注释掉

- **规则ID**：5ebb2621-377a-423f-bcba-041e3a014b00
- **更新时间**：2025-06-05 04:25:02

---

**【问题级别】**

一般

**【描述】**

不需要的代码直接删除掉，被注释掉的代码无法被正常维护。

**【正确示例】**

```
不用的代码段直接删除，不要注释掉

```
**【错误示例】**

```
// function oldFunc(){console.log('helloword')}

```
**【修复建议】**

失效代码不应放在注释里
