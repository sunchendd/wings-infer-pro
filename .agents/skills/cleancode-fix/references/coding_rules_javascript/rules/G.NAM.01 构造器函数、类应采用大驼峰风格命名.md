# G.NAM.01 构造器函数、类应采用大驼峰风格命名

- **规则ID**：2a5a43c9-fd96-48d5-a2a9-13f6adb8e2fd
- **更新时间**：2025-06-05 04:25:00

---

**【问题级别】**

提示

**【描述】**

构造器函数、类采用首字母大写的驼峰命名法。



构造器函数、类名通常是名词或名词短语，例如 Person 、 Student 、 Worker。不应使用动词，也应该避免类似Data、Info这样的模糊词。



**【正确示例】**

```
const marcoPolo = new MarcoPolo();

```
**【错误示例】**

```
const  marco = new marcoPolo();

```
**【修复建议】**

构造器函数、类采用首字母大写的驼峰命名法。
