**【问题级别】**

一般

**【描述】**

变量与常量进行比较时，确保常量在变量类型能够表示范围内。超出变量类型能够表示的范围时，这种比较是无意义的。

**【错误示例】**

```
【Instruction】&nbsp;&nbsp; 变量与常量进行>=、>、<=、<判断时，若常量数值等于变量类型临界值或超出临界值，则为无效校验，告警。
变量与临界值比较时，需要产品确认写法是否正确。【Example】&nbsp;&nbsp;//good example

 void test_good()
{
 char a;
 if(a <= 50)  
 {//........
 }
}



//bad example

 void test_bad()
{
 char a;
 if(a <= 0xFF)  //char类型最大值为0xFF，与0xFF比较无意义
 {//........
 }
}

```
**【修复建议】**

确保常量在变量类型表示的范围之内
