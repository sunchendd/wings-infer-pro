# G.NAM.03 导出的错误变量采用ErrXxx格式命名

- **规则ID**：1a4c0960-48eb-4a9d-a6a9-376c13f71c97
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

提示

**【描述】**

- 导出的错误 **类型** 的命名格式：**类型名** + **Error**（即：**XxxError**）

- 导出的错误 **变量** 的命名格式：**Err** + **名称**（即：**ErrXxx** ）

**【正确示例】**

```
##### 场景1：错误格式的类型命名
- 修复示例：按规范建议修改命名格式

  ```go
  // 符合：错误格式的类型名符合规则描述要求
  type FooError struct {
      ...
  }
  ```
##### 场景2：错误格式的变量命名
- 修复示例：按规范建议修改命名格式

  ```go
  // 符合：错误格式变量名符合规则描述要求
  var ErrSomething = errors.New("something wrong")
  ```


```
**【错误示例】**

```
##### 场景1：错误格式的类型命名
- 错误示例：

  ```go
  // 不符合：导出的错误类型的命名格式：类型名+Error（即：XxxError）
  type ErrorFoo struct {
      ...
  }
  ```
##### 场景2：错误格式的变量命名
- 错误示例：

  ```go
  // 不符合：导出的错误类型的命名格式：Error+变量名（即：ErrorXxx）
  var ErrorSomethingWrong = errors.New("something wrong")
  ```


```
**【修复建议】**

按规范建议修改命名格式
