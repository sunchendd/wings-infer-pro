# G.EXP.06 正确对变量进行赋值(试点)

- **规则ID**：6293b411-ab92-4d20-a9d3-aca4b52825c9
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

- 等号左侧要求：不要使用${}对应的变量作为赋值操作的左值， 对于位置参数赋值，使用set -- first second ..

- 等号右侧要求：建议使用 $((..)) 、 $(..) 、 "..."、整数 作为等号右侧数据

**【正确示例】**

```
#!/bin/bash
  greeting="Hello World"

```
**【错误示例】**

```
#!/bin/bash
  # 不符合： 左侧不能是变量
  $greeting="Hello World"
  ${greeting}="Hello World"

```
**【修复建议】**

- 左侧不能是变量，对于位置参数赋值，使用set -- first second ..

- 右侧为字符串请使用引号括起来

- 右侧为算术表达式，需要使用$((...))括起来

- 右侧想获取命令执行的标准输出使用$(...)括起来
