# G.EXP.13-CPP 使用char、wchar_t等类型表示字符

**【问题级别】**

一般

**【描述】**

signed char和unsigned char类型只能用于数值的存储和使用。



普通的char类型，在不同系统中可以实现为signed char或unsigned char，因此不要使用char类型来表示整数，它只能用于表示字符数据。



类似地，使用wchar_t表示宽字符；使用char16_t表示UTF-16字符；使用char32_t表示UTF-32字符；C++20中可以使用char8_t表示UTF-8字符。

**【正确示例】**

```
##### 场景1：整型运算用了字符类型
- 修复示例：

```cpp
void Foo(char c, int y)
{
    int x;
    int n;
    n = c - '0'; // 符合：字符间运算，取偏移量
    x = y + n;   // 符合：此处是整型运算
}
```

```
**【错误示例】**

```
##### 场景1：整型运算用了字符类型
- 错误示例：

```cpp
void Foo(char c, int y)
{
    int x;
    x = c + y; // 不符合：此处是整型运算，但是用了字符类型
}
```

```
