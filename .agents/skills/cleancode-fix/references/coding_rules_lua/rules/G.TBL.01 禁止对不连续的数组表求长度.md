# G.TBL.01 禁止对不连续的数组表求长度

- **规则ID**：b5f2cdc4-bf58-4fb8-9d98-aca4d976bb8b
- **更新时间**：2026-04-07 04:45:01

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：非法的表长度计算“xxx”,该表含有值为nil的成员

**【正确示例】**

```
```
local tab = {1, 2, 3, 4}
print(#tab)
```

```
**【错误示例】**

```
```
local t = { 1, 2, 3, 4 }
t[2] = nil
print(#t)
```

```
**【修复建议】**

t表不连续，有nil成员，不要进行#求表长操作
