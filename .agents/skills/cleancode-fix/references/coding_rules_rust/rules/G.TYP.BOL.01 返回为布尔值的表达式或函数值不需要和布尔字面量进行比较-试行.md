# G.TYP.BOL.01 返回为布尔值的表达式或函数值不需要和布尔字面量进行比较-试行

- **规则ID**：4364ecf7-136a-4a38-94dd-c69704331eb3
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

一般

**【描述】**

在 Rust 中，返回为布尔值的表达式或函数值可以直接当作布尔值使用。



总之，使用布尔表达式的时候，要尽可能地简洁明了。

**【正确示例】**

```
if x {}
if !y {}
assert!(!"a".is_empty());

```
**【错误示例】**

```
if x == true {}
if y == false {}
assert_eq!("a".is_empty(), false);
assert_ne!("a".is_empty(), true);

```
