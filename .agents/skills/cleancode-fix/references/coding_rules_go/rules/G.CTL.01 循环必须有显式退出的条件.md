# G.CTL.01 循环必须有显式退出的条件

- **规则ID**：6ae5dd9c-0092-4eb6-b0aa-6da0df2c474f
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

严重

**【描述】**

如果循环没有退出条件，循环在任何或预计时间内将不完成执行，导致死循环。

因此，应尽量将退出循环的条件放在for循环头的退出条件判断中，并确保退出条件可以达成。如无法避免空的for循环头，需要在循环过程中设置能确保退出的条件。

**【正确示例】**

```
##### 场景1：for语句不包含显式的退出条件
- 修复示例1：
    ```go
    for {
        ...
        // 符合：应确保someCondition一定能为True，从而退出循环
        if someCondition {
            break
        }
        ...
    }
    ```
- 修复示例2：
    ```go
    // 符合：确保loopCondition在一定次数后失效，从而退出循环
    for loopCondition {
        ...
    }
    ```
##### 场景2：循环条件不可达
- 修复示例：
    ```go
    // 符合：每次循环后更新循环变量，退出条件可达
    for i := 0; i < 10; i++ {
        fmt.Println("waiting...")
    }
    ```


```
**【错误示例】**

```
##### 场景1：for语句不包含显式的退出条件
- 错误示例：
    ```go
    for {
        ... // 不符合：此代码模块没有显式的退出条件
    }
    ```
##### 场景2：循环条件不可达
- 错误示例：
    ```go
    // 不符合：循环变量未被修改，退出条件不可达
    for i := 0; i < 10; {
        fmt.Println("waiting...")
    }
    ```


```
**【修复建议】**

循环语句中有显式退出条件，并能退出循环。
