# GoFence 整数截断

- **规则ID**：3b0bed37-6ef4-45b7-aa31-093d8f725865
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

将一个较大的整型转换为较小的整型，并且该数的原值超出较小整型的表示范围，就会发生截断错误，原值的低位被保留而高位被丢弃。截断错误会引起数据丢失，甚至可能引发安全问题。

**【正确示例】**

```
```
func foo() {
    var a int32 = math.MaxInt32
    var b int16
    // 正确：进行校验以确保在进行类型转化时不会产生截断
    if (a < math.MinInt16) || (a > math.MaxInt16) {
         fmt.Println("超出范围，数据截断")
    } else {
        b = int16(a)
        fmt.Println("b=",b)
    }
  }
```

```
**【错误示例】**

```
```
下面代码假设a为32位有符号整数的最大值，把它强制转换为16位有符号整数时，会导致数据被截断。
func foo() {
    var a int32 = math.MaxInt32
    var b int16
    b = int16(a) // 错误：不同类型强制转化会发生数据截断
    fmt.Println("b=", b)// 输出 b = -1
}
```

```
**【修复建议】**

当不同数据类型强制转化时需要校验数据的范围，以确定是否会发生数据的丢失。--------参考华为go语言编程规范3.1。
