# G.TYP.01 禁止省略浮点数小数点前后的 0

- **规则ID**：03417160-69d6-438c-af03-4b33161a60f2
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

一般

**【描述】**

省略浮点数小数点前后的 0，虽然不是一个语法错误，但这种格式的数字使真正的小数和点操作符变的难以区分。因此，必须在小数点前面和后面有一个数字，以明确表明是要创建一个小数。

**【正确示例】**

```
##### 场景1：浮点数
- 修复示例：在小数点前面和后面有一个数字，提高可读性。

```javascript
const num = 0.5;     //  符合
const num = 2.0;     //  符合
const num = -0.7;    //  符合
```

```
**【错误示例】**

```
##### 场景1：浮点数
- 错误示例：省略浮点数小数点前后的0。

```javascript
const num = .5;    //  不符合，省略了小数点前面的0
const num = 2.;    //  不符合，省略了小数点后面的0
const num = -.7;  //  不符合，省略了小数点前面的0
```

```
**【修复建议】**

不要省略浮点数小数点前后的 0，必须在小数点前面和后面有一个数字，以明确表明是要创建一个小数。
