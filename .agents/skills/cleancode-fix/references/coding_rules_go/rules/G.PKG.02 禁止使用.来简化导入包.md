# G.PKG.02 禁止使用.来简化导入包

- **规则ID**：0b790c3b-1802-4646-9e70-aa73efbdb001
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

`.`来简化导入包，这种写法不利于阅读，因为不清楚代码中出现的标识符是当前包还是导入包中的，使得程序难以理解。因此，禁止使用`.`来简化导入包。

**【正确示例】**

```
##### 场景1：使用“.”简化导入包
- 修复示例：

  ```go
  import "pubcode/api/broker"    // 符合
  ```

```
**【错误示例】**

```
##### 场景1：使用“.”简化导入包
- 错误示例：

  ```go
  import . "pubcode/api/broker"  // 不符合：使用了 .  简化导入包
  ```

```
**【修复建议】**

不要使用.来简化导入包，应直接导入包。
