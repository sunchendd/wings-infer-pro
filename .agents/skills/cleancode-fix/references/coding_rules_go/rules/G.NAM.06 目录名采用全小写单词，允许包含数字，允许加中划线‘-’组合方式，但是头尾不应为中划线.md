# G.NAM.06 目录名采用全小写单词，允许包含数字，允许加中划线‘-’组合方式，但是头尾不应为中划线

- **规则ID**：bdb23808-37f5-49e7-a83f-1e7723e2f66a
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

目录名仅能使用小写字母、数字、中划线，但是应该避免或少加中划线，源码所在的目录名不应包含中划线，含中划线的目录名将无法与包名保持一致（包名中包含中划线将出现编译错误）。

**【正确示例】**

```
##### 场景1：目录名包含大写字母
- 修复示例：按规则建议修改目录名

  ```go
  // 符合：目录名可以包含小写字母和数字
  md5
  ```


```
**【错误示例】**

```
##### 场景1：目录名包含大写字母
- 错误示例：

  ```go
  // 不符合：目录名不能包含大写字母
  Md5
  ```


```
**【修复建议】**

按规则建议修改目录名
