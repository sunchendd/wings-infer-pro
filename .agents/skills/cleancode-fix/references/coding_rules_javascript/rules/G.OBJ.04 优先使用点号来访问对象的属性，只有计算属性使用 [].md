# G.OBJ.04 优先使用点号来访问对象的属性，只有计算属性使用 []

- **规则ID**：f4baab67-b1c4-4c92-8699-c227b9f2effa
- **更新时间**：2026-04-07 04:25:01

---

**【问题级别】**

一般

**【描述】**

访问对象属性时，点号通常是首选，因为它更加易读，简洁，也更适于 JavaScript 压缩。

**【正确示例】**

```
##### 场景1：访问对象属性
- 修复示例：使用点号访问对象的属性。

```javascript
const name = obj.name;
```
##### 场景2：访问对象属性
- 修复示例：当是计算属性时，建议使用[]。

```javascript
const key = getKeyFromDB();
const prop = obj[key]; // 属性名是变量时使用[]
```

```
**【错误示例】**

```
##### 场景1：访问对象属性
- 错误示例：使用[]访问对象的属性。

```javascript
const name = obj['name'];
```

```
**【修复建议】**

使用点号来访问对象的属性，只有计算属性使用 []。
