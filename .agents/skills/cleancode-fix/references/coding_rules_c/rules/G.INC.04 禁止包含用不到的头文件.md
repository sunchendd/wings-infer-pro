# G.INC.04 禁止包含用不到的头文件

- **规则ID**：3f16a0e5-19d8-4a4f-8934-9f1675867bbd
- **更新时间**：2026-04-07 04:10:02

---

**【问题级别】**

严重

**【描述】**

用不到的头文件被包含的同时引入了不必要的依赖，增加了模块或单元之间的耦合度，只要该头文件被修改，代码就要重新编译。

因此，要删除用不到的头文件。

**【正确示例】**

```
##### 场景1：头文件未使用
- 修复示例：删除用不到的头文件。

  ```c
  // 符合：此处头文件"func.h"用不到，删除
  int Foo(int a, int b)
  {
      return a + b;
  }
  ```

```
**【错误示例】**

```
##### 场景1：头文件未使用
- 错误示例：func.h未使用。

  ```c
  #include "func.h"  // 不符合，func.h未使用
  int Foo(int a, int b)
  {
      return a + b;
  }
  ```

```
**【修复建议】**

删除用不到的头文件。

推荐使用[Huawei CodeCheck插件](https://3ms.huawei.com/km/groups/3946724/blogs/details/15159305?l=zh-cn)的自动修复/一键格式化功能，详细使用说明见。
