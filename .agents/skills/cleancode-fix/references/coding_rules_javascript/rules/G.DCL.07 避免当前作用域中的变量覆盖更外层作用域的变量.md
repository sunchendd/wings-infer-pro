# G.DCL.07 避免当前作用域中的变量覆盖更外层作用域的变量

- **规则ID**：439c059d-a039-4d52-b223-59686b5cae96
- **更新时间**：2026-04-07 04:25:00

---

**【问题级别】**

提示

**【描述】**

当前作用域中的变量覆盖了更外层作用域的变量时，这不仅会给阅读者带来困扰，还会导致无法获取和使用外出作用域的变量。

**【正确示例】**

```
##### 场景1：变量覆盖
- 修复示例：修改变量名，避免与外层作用域的变量重名。

```javascript
let bar = 3;
function foo() {
  let num = 10;  // 符合
}

```

```
**【错误示例】**

```
##### 场景1：变量覆盖
- 错误示例：函数foo()的内部定义的变量bar与外层的变量bar重名。

```javascript
let bar = 3;
function foo() {
  // bar 覆盖了全局环境中的 bar。这会混淆读者并且在 foo 中不能获取全局变量
  let bar = 10;
}

```

```
**【修复建议】**

应当避免当前作用域中的变量覆盖更外层作用域的变量。
