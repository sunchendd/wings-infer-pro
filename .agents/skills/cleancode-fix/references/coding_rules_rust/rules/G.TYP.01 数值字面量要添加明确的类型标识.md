# G.TYP.01 数值字面量要添加明确的类型标识

- **规则ID**：f3da0677-df9b-4811-bf16-7494668adafe
- **更新时间**：2025-06-05 04:40:00

---

**【问题级别】**

一般

**【描述】**

如果数值字面量没有被指定具体类型，那么单靠类型推导，整数类型会被默认绑定为 i32 类型，而浮点数则默认绑定为 f64 类型。这可能导致某些运行时的意外，比如因为类型预期错误，导致应该在编译期发现的问题遗留到运行时，比如导致数据计算溢出等问题。
