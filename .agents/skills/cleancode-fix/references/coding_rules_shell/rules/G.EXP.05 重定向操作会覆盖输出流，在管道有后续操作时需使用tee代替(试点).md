# G.EXP.05 重定向操作会覆盖输出流，在管道有后续操作时需使用tee代替(试点)

- **规则ID**：18c134f4-4f76-483b-b19a-e0297b221d39
- **更新时间**：2025-06-05 04:30:00

---

**【问题级别】**

严重

**【描述】**

如果在管道中间使用重定向操作，后续操作会接收空的输入。

**【正确示例】**

```
#!/bin/bash

# 期望标准输出写入文件,然后在其中查找指定字符串,使用tee命令可以将标准输出传递给grep,可以查找到结果
echo abc | tee out.txt | grep '^ab'

```
**【错误示例】**

```
#!/bin/bash

# 期望标准输出写入文件,然后在其中查找指定字符串,但实际运行时grep接收到的输入为空,查找结果始终为空
# 输出告警信息：管道左侧的> out.txt操作会覆盖标准输出
echo abc > out.txt | grep '^ab'

```
**【修复建议】**

- 在管道有后续操作时需使用tee命令
