# G.NAM.05 文件名采用全小写单词，允许包含数字，允许加下划线‘_’组合方式

- **规则ID**：889ec101-36f5-4de5-94a1-462ec6c3e80b
- **更新时间**：2026-04-07 04:20:01

---

**【问题级别】**

一般

**【描述】**

文件名不采用驼峰的原因是：不同系统对文件名大小写处理不同（如Windows 系统不区分大小写，但是 Unix / Linux, Mac 系统则默认区分）。



如果包含点号和下划线的方式，注意避免跟下面保留特定用法产生冲突：



1. 以`.` 或 `_` 开头命名的文件会被go工具筛选排除在外。

2. 以`_test.go`结尾命名的文件只会在go test工具中编译运行。

3. 符合 `*_GOOS` 、`*_GOARCH`、`*_GOOS_GOARCH` 表达式的文件名会被识别为隐式的系统与架构构建约束（例如：`source_windows_amd64.go`，只会在`windows 64`位系统下编译）。包括但不限于：`_386.go、_arm.go、_android.go、_darwin.go、_linux.go、_windows.go、_linux_amd64.go、_linux_arm.go`等。

**【正确示例】**

```
##### 场景1：文件名使用了驼峰命名
- 修复示例：

  ```go
  // 符合：小写单词加下划线‘_’组合方式
  http_client.go
  ```
##### 场景2：文件名使用了字符‘-’
- 修复示例：

  ```go
  // 符合：小写单词加下划线‘_’组合方式
  http_client.go
  ```


```
**【错误示例】**

```
##### 场景1：文件名使用了驼峰命名
- 错误示例：

  ```go
  // 不符合：使用了驼峰命名
  HttpClient.go
  ```


```
**【修复建议】**

文件名采用全小写单词，允许包含数字，允许加下划线‘_’组合方式。
