# G.PRE.13 所有#else、#elif、#endif和与之对应的#if、#ifdef、#ifndef预处理指令应出现在同一文件中

- **规则ID**：402db43e-2f4a-43bf-922c-528066404056
- **更新时间**：2026-04-07 04:10:03

---

**【问题级别】**

严重

**【描述】**

当使用多个文件来构成这些预处理块时，难以直观发现代码块的关联，增加了阅读和维护的复杂度，从而更容易产生错误。



有时候，编译时可能发生匹配不到对应的预处理块而产生编译错误；或者编译时的预处理块匹配错误而导致执行错误，通常这种执行错误难以定位问题。



所有 `#else`、`#elif`、`#endif` 和与之对应的 `#if`、`#ifdef`、`#ifndef`预处理指令应出现在同一文件中。

**【正确示例】**

```
##### 场景1：#endif在另一个文件中
- 修复示例：

```c
// sample.h 开始
#if defined(__VXWORKS__)
#include "vx_config.h"
...
#endif // 符合：预处理指令在同一个文件中闭合
// sample.h 结束
```


```
**【错误示例】**

```
##### 场景1：#endif在另一个文件中
- 错误示例：

```c
// sample.h 开始
#if defined(__VXWORKS__)  // 未在相同文件中闭合该预处理块
#include "vx_config.h"

// 不符合：这里结束前，本应当有 #endif 与前面的 #if defined 形成闭合
// sample.h 结束
```


```
**【修复建议】**

修改预处理指令在同一个文件中闭合。
