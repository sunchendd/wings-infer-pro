# G.OTH.05 禁止代码中包含公网地址

- **规则ID**：5facdaf4-5e59-4005-8e38-05d9e45f3200
- **更新时间**：2025-03-25 19:24:07

---

**【问题级别】**

一般

**【描述】**

对产品发布的软件（包含软件包/补丁包）中包含的公网地址（包括公网IP地址、公网URL地址/域名、邮箱地址）要求如下：

1、禁止包含用户界面不可见、或产品资料未描述的未公开的公网地址。

2、已公开的公网地址禁止写在代码或者脚本中，可以存储在配置文件或数据库中。



对于开源/第三方软件自带的公网地址必须至少满足上述第1条公开性要求。

**【正确示例】**

```
不要硬编码公网ip

```
**【错误示例】**

```
硬编码公网IP导致IP泄漏，触发安全红线，违反公司安全规定。
IP=公网IP+私网IP
私网IP的范围如下：
A类：10.0.0.0~10.255.255.255
B类：172.16.0.0~172.31.255.255
C类：192.168.0.0~192.168.255.255
D类（组播IP地址）：224.0.0.1~239.255.255.255
系统回旋地址：127.0.0.0~127.255.255.255
APIPA地址：169.254.*
广播地址：255.255.255.255
源地址：0.0.0.0
除上述私网IP，其他均为公网IP
https://rnd-skb.huawei.com/seccoding/ruleModellib/rulemodel/getDetail/CRG20180904194513205466#

```
**【修复建议】**

宏定义中、变量赋值中、特定函数（*strcmp、*strncmp、*memcmp）中禁止使用硬编码公网IP
