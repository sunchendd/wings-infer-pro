# G.EXP.01 不要在单个表达式中对相同的变量赋值超过一次

- **规则ID**：eeb5f880-8af9-47f2-910c-4a9f1587e384
- **更新时间**：2026-04-07 04:00:01

---

**【问题级别】**

严重

**【描述】**

对相同的变量进行多次赋值的表达式会产生混淆，并且容易产生非预期的行为。清晰的变量赋值会使代码更易懂，也更能保证程序按预期运行。

**【正确示例】**

```
##### 场景1：使用count对循环计数，而实际count最终结果却为0
- 修复示例1：

  ```java
  int count = 0;
  for (int i = 0; i < 100; i++) {
      ...
      count++;
  }
  System.out.println(count); // count的值为100   
  ```


```
**【错误示例】**

```
##### 场景1：使用count对循环计数，而实际count最终结果却为0
- 错误示例：

  ```java
  int count = 0;
  for (int i = 0; i < 100; i++) {
      ...
      count = count++;
  }
  System.out.println(count); // count的值为0
  ```


```
**【修复建议】**

不要在单个表达式中对相同的变量赋值超过一次
