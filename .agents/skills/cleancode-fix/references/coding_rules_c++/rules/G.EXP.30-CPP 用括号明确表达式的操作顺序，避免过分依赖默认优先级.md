# G.EXP.30-CPP 用括号明确表达式的操作顺序，避免过分依赖默认优先级

- **规则ID**：89fb3731-7a29-4608-8ada-ff43fbe8da71
- **更新时间**：2025-03-25 19:22:27

---

**【问题级别】**

一般

**【描述】**

当表达式包含不常用、优先级易混淆的操作符时，建议使用括号明确表达式的操作顺序，防止因默认的优先级与实现意图不符而导致程序出错，提升代码的可读性。然而过多的括号也会分散代码，使其可读性降低，应适度使用。



二元及以上操作符，如果涉及多种操作符混合使用并且优先级容易混淆的场景，特别是位操作符与其他操作符混合使用时，建议使用括号明确表达式操作顺序。

**【正确示例】**

```
if ((a & b) == 0) ...       // 符合：明确先进行逻辑位运算
x = (a & 0xFF) + b;         // 符合：明确先进行逻辑位运算
x = 1 << (2 + 3);           // 符合：明确先进行加法运算
x = (1 << 2) + 3;           // 符合：明确先进行移位运算
x = (a == b) ? a : (a – b); // 符合：使用括号提升可读性
x = a + b + c;              // 符合：操作符相同，可以不加括号
x = Foo(a + b, c);          // 符合：逗号两边的表达式，不需要括号
if (a > b && c > d) ...     // 符合：逻辑表达式，根据子表达式的复杂情况选择是否加括号

```
**【错误示例】**

```
if (a & b == 0) ...         // 不符合：涉及逻辑位运算，需要括号
x = a & 0xFF + b;           // 不符合：涉及逻辑位运算，需要括号
x = 1 << 2 + 3;             // 不符合：涉及移位运算，需要括号
x = a == b ? a : a – b;     // 不符合：操作符不同，建议括号

```
**【修复建议】**

添加括号明确表达式顺序
