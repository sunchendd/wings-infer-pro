# G.EXP.24-CPP 移位操作符的右操作数必须是非负数且小于左操作数的基本类型位宽

- **规则ID**：cea4fa09-2f37-4383-9b16-52c8a06a219f
- **更新时间**：2025-03-25 19:23:14

---

**【问题级别】**

严重

**【描述】**

移位运算时，首先对每个操作数执行整数提升，其结果的类型是提升后的左操作数的类型。如果右操作数的值为负数，或者右操作数的值大于或等于整数提升后左操作数的位宽，那么程序会产生未定义行为。



例如：当移位操作的左操作数为32位无符号整数类型时，确保右操作数的取值范围是[0,31]。

**【正确示例】**

```
uint32_t input = ...
uint32_t value = input << 31;                        // 符合
uint64_t count = static_cast<uint64_t>(input) << 32; // 符合

```
**【错误示例】**

```
uint32_t input = ...
uint32_t value = input << 32;                        // 不符合

```
**【修复建议】**

移位运算符的右操作数必须是非负数且小于左手操作数的基本类型位宽。
