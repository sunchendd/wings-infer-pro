# G.EXP.14 +=、=操作前后不能有空格(试点)

- **规则ID**：b581b667-829b-416e-ac15-9d0d16eb45ce
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

如果+=、=操作前后出现空格，会被当做单独的命令执行

**【正确示例】**

```
#!/bin/bash
  var+="my text"
  export LC_ALL="POSIX"

```
**【错误示例】**

```
#!/bin/bash
  # 不符合: += 前后都有空格
  var += "my text"
  # 不符合：= 前后有空格
  export LC_ALL = "POSIX"

```
**【修复建议】**

+=、=操作前后去掉空格
