# G.EXP.35-CPP 使用nullptr作为空指针常量

- **规则ID**：84cbc84d-6e61-4553-83ab-640ed4bcddb6
- **更新时间**：2025-03-25 19:22:29

---

**【问题级别】**

严重

**【描述】**

C++11开始引入了nullptr关键字代表空指针，在此之前使用NULL宏来表示空指针常量，导致出现问题



**【正确示例】**

```
int *p = nullptr;

```
**【错误示例】**

```
int *p = 0; // 不符合

```
**【修复建议】**

使用nullptr替换空指针常量
