# G.EDV.08 防止正则表达式引起的ReDos攻击

- **规则ID**：16e8fe12-b82c-4110-8f33-71cb37c4a029
- **更新时间**：2026-04-07 04:15:02

---

**【问题级别】**

严重

**【描述】**

ReDos攻击是正则编写不当导致的常见安全风险。Python语言的正则引擎本质上是非确定型有穷自动机（NFA），通过回溯机制尝试正则表达式的所有可能执行路径。NFA引擎采用回溯机制，回溯机制存在效率问题，在最坏的情况下，即使“注定”失败，依旧需要与所有可能的路径进行对比匹配，在确认所有可能路径都不匹配，才返回匹配失败。若直接使用外部输入数据进行正则匹配，攻击者可通过构造特殊的正则表达式或目标字符串触发“回溯陷阱”，造成拒绝服务，这种攻击方式称为正则表达式拒绝服务（ReDoS）。

容易存在ReDos攻击的正则表达式主要有：

1、具有自我重复的重复性分组的正则, 例如：



^(\d+)+$

^(\d*)*$

^(\d+)*$

^(\d+|\s+)*$

2、包含替换的重复性分组，例如：



^(\d|\d|\d)+$

^(\d|\d?)+$

对于ReDos攻击的防护手段主要包括：



进行正则匹配前，先对匹配的文本的长度进行校验；

应检视程序内的正则表达式，避免使用存在风险的表达式结构. 尽量不要使用过于复杂的正则，尽量少用分组。应当将多余的分组删除。

避免动态构建正则，若不可避免，则必须使用白名单或黑名单对外部数据进行校验和净化；

def regex_evaluate():
