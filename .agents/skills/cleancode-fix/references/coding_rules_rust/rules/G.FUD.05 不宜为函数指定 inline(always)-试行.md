# G.FUD.05 不宜为函数指定 inline(always)-试行

- **规则ID**：c175f1c3-94da-4fc0-9a10-1b3097c75a4e
- **更新时间**：2025-06-05 04:40:03

---

**【问题级别】**

提示

**【描述】**

inline 虽然可以提升性能，但也会增加编译时间和编译大小。Rust 中性能、编译时间和编译大小之间需要权衡。



不宜过早优化。

**【正确示例】**

```
// 实现内存回收功能，调用非常频繁。性能优先
#[inline(always)]
pub fn buf_recycle(buf_id: usize) { 
    // ... 
}

```
**【错误示例】**

```
#[inline(always)]
fn not_quite_hot_code(..) { ... }

```
