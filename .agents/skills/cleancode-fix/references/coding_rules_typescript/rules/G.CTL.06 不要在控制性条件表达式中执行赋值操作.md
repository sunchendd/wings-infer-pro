# G.CTL.06 不要在控制性条件表达式中执行赋值操作

- **规则ID**：1724a608-ab3a-4222-9a11-41104e82c60f
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

一般

**【描述】**

控制性条件表达式常用于if、while、for、?:等条件判断中。

在控制性条件表达式中执行赋值，常常导致意料之外的行为，且代码的可读性非常差。

**【正确示例】**

```
##### 场景1：赋值
- 修复示例：先赋值，在if条件判断中直接使用

```javascript
const isFoo = someBoolean; // 先赋值，在if条件判断中直接使用
if (isFoo) {
  ...
}
```

```
**【错误示例】**

```
##### 场景1：赋值
- 错误示例：在控制性判断中赋值

```javascript
// 在控制性判断中赋值不易理解  
if (isFoo = false) {
  ...
}  
```

```
**【修复建议】**

不要在控制性条件表达式中执行赋值操作。
