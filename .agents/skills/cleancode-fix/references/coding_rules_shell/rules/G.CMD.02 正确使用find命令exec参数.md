# G.CMD.02 正确使用find命令exec参数

- **规则ID**：025aab77-9c77-4f10-95a4-a2f7a5de6904
- **更新时间**：2026-04-07 04:30:00

---

**【问题级别】**

严重

**【描述】**

1. exec参数后面跟command执行命令，以; 为结束标志。且在; 前最好增加\ 避免被Shell扩展。

2. 如果需要执行Shell组合操作命令，比如 cat {} | wc -l ，需要指定sh或者bash，后接-c参数，将命令用引号包起来。

3. 如果有多个匹配条件且是逻辑或的关系（-o选项）时，需要使用"\( \)"格式包含匹配条件，如果是逻辑与的关系不需要"\( \)" 格式。

**【正确示例】**

```
```shell
#!/bin/bash
find . -type f -exec file {} \;
```

```
**【错误示例】**

```
```shell
#!/bin/bash
# 执行失败，没有加 \;
find . -type f -exec file {}
find . -type f -exec file {} ;
```

```
**【修复建议】**

1. exec参数后面跟command执行命令，使用";"作为结束标志。

2. 执行Shell组合操作命令，使用sh/bash -c进行执行。

3. 如果有多个匹配条件且是逻辑或的关系（-o选项）时，使用"\( \)" 格式包含匹配条件。
