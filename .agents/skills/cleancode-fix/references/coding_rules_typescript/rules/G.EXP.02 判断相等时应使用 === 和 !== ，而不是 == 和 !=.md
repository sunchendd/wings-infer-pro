# G.EXP.02 判断相等时应使用 === 和 !== ，而不是 == 和 !=

- **规则ID**：6fec13b5-7a98-4b48-b727-b0661dc2ee22
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

一般

**【描述】**

JavaScript 中使用双等 == 做相等判断时会自动做类型转换，如：[] == false、[] == ![]、3 == '03’都是true，当类型确定时使用全等 === 做比较可以提高效率。

**【正确示例】**

```
##### 场景1：相等判断
- 修复示例：判断相等时应使用 === 不等时用 !==

```javascript
age === bee
age !== bee
```

```
**【错误示例】**

```
##### 场景1：相等判断
- 错误示例：判断相等时用 ==，判断不相等时用 !=

```javascript
age == bee
age != bee
```

```
**【修复建议】**

判断相等时应使用 === 和 !== ，而不是 == 和 !=。
