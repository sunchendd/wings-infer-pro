# G.FMT.11 使用拖尾逗号

- **规则ID**：2d7eaaca-725f-448d-8b9a-f3ea9eca98f5
- **更新时间**：2026-04-07 04:25:00

---

**【问题级别】**

提示

**【描述】**

最终元素和结束括号之间存在换行符时，应包含尾后逗号。在上一行已经使用了尾后逗号的情况下，如果要添加新的属性，可以仅仅添加新的一行，而不需要修改上一行。另一个支持拖尾逗号的原因是，当对象或数组添加或删除元素时，它提高了代码差异的清晰度。

**【正确示例】**

```
##### 场景1：定义对象时的拖尾逗号
- 修复示例：添加了拖尾逗号
```javascript
const hero = {
  firstName: 'Dana',
  lastName: 'Scully',  // 符合
};

```
##### 场景2：定义数组时的拖尾逗号
- 修复示例：添加了拖尾逗号
```javascript
const heroes = [
  'Batman',
  'Superman',   // 符合
];

```

```
**【错误示例】**

```
##### 场景1：定义对象时的拖尾逗号
- 错误示例：定义对象时，最后一个元素后面没有拖尾逗号
```javascript
const hero = {
  firstName: 'Dana',
  lastName: 'Scully'   // 不符合，没有添加拖尾逗号
};

```
##### 场景2：定义数组时的拖尾逗号
- 错误示例：定义数组时，最后一个元素后面没有拖尾逗号
```javascript
const heroes = [
  'Batman',
  'Superman'    // 不符合，没有添加拖尾逗号
];

```

```
**【修复建议】**

定义数组或对象时，最后一个元素与结束括号之间存在换行符时，应在最后一个元素后面加上拖尾逗号。
