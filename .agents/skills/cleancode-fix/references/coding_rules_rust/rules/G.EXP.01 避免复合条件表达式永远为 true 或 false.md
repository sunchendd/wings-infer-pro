# G.EXP.01 避免复合条件表达式永远为 true 或 false

- **规则ID**：ab5c38e4-7f1c-46a9-a1de-50d2545c093a
- **更新时间**：2026-04-07 04:40:01

---

**【问题级别】**

提示

**【描述】**

代码中使用了不兼容的位掩码，通常是代码编写错误导致的

**【正确示例】**

```
```
if (x && 1 == 2) { }
```

```
**【错误示例】**

```
```
if (x & 1 == 2) { }
```

```
**【修复建议】**

检查是否为拼写错误，例如将 `&&` 写成 `&`. `||` 写成 `|`
