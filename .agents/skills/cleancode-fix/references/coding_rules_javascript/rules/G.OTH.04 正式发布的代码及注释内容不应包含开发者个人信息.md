# G.OTH.04 正式发布的代码及注释内容不应包含开发者个人信息

- **规则ID**：82a3957a-98fc-4dd5-84d9-59e744ec4066
- **更新时间**：2025-06-05 04:25:02

---

**【问题级别】**

严重

**【描述】**

正式发布的代码及注释内容如果包含开发者个人信息，可能会泄露具体的开发人员信息，存在引发社会工程学方面的风险。

**【正确示例】**

```
正式发布的代码及注释内容不应包含开发者个人信息

```
**【错误示例】**

```
//@email abc@huawei.com

```
**【修复建议】**

注释内容不应包含开发者个人信息
