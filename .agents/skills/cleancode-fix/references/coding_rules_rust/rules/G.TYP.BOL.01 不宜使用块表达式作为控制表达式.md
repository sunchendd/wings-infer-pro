# G.TYP.BOL.01 不宜使用块表达式作为控制表达式

- **规则ID**：66e422c3-6ccf-4d41-a873-53882a3f9ae7
- **更新时间**：2026-04-07 04:40:00

---

**【问题级别】**

一般

**【描述】**

使用块表达式作为控制表达式，易引入带副作用的函数调用，导致程序运行逻辑和预期不符，代码的可读性也同步变差。



Rust中的控制表达式包括：



- if语句

- while语句

- match语句

**【正确示例】**

```
```
if true { /* ... */ }
# fn somefunc() -> bool { true };
let res = { let x = somefunc(); x };
if res { /* ... */ }
```

```
**【错误示例】**

```
```
if { true } { /* ... */ }
# fn somefunc() -> bool { true };
if { let x = somefunc(); x } { /* ... */ }
```

```
**【修复建议】**

考虑将作为条件式的代码块提取为函数，再将函数调用作为if表达式的条件语句
