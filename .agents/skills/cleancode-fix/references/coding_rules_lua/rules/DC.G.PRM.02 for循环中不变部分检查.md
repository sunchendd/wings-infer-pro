# DC.G.PRM.02 for循环中不变部分检查

- **规则ID**：e8de27b8-8fc3-4dbf-af33-8a297d9f565a
- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：“xxx”该部分跟for循环无关，可以挪到循环外去

**【正确示例】**

```
```
local var1 = 1
local var2 = foo(var1)
for i = 1 do
    ...
End
```

```
**【错误示例】**

```
```
for i = 1 do
    local var1 = 1
    local var2 = foo(var1) -- foo返回值不变
    ...
End
```

```
**【修复建议】**

在循环体中进行与循环无关的操作会影响循环效率，因此应避免在循环体中进行与循环无关的操作
