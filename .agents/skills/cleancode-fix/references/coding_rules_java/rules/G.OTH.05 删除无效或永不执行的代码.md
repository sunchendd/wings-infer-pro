# G.OTH.05 删除无效或永不执行的代码

- **规则ID**：aca213ee-0491-4c1a-9455-5cb054c73e3d
- **更新时间**：2026-04-07 04:00:05

---

**【问题级别】**

提示

**【描述】**

变量在使用前，被多次重复赋值，冗余的赋值可能是代码逻辑错误（应给其他变量赋值）或是无效的代码。

**【正确示例】**

```
##### 场景1：
- 修复示例1：

```java
// 【GOOD】对都需要后续使用的数据，进行分开字段赋值。
name = getName();
buffer = getNewBuffer(buf);
```
- 修复示例2：

```java
// 【GOOD】去除不需要的赋值操作。
buffer = getNewBuffer(buf);
```


```
**【错误示例】**

```
##### 场景1：
- 错误示例：

```java
// 【POTENTIAL FLAW】代码为变量 r 赋值，并在没有使用所赋数值的情况下，对其加以重写。
buffer = getName();
buffer = getNewBuffer(buf);
```


```
**【修复建议】**

删除不需要的重复赋值操作（如修复示例2），对都需要后续使用的数据，分别赋值给不同变量（如修复示例1）。
