# DC.G.MOD.01 模块名和文件名必须相同

- **规则ID**：af31eba7-a8ef-4b70-aca7-36fa458dfd4f
- **更新时间**：2026-04-07 04:45:01

---

**【问题级别】**

严重

**【描述】**

模块名和文件名不一致

**【正确示例】**

```
```
文件名: foo.lua
module("foo", package.seeall)
```

```
**【错误示例】**

```
```
文件名: foo1.lua：
module("foo", package.seeall)
```

```
**【修复建议】**

模块名和文件名要相同
