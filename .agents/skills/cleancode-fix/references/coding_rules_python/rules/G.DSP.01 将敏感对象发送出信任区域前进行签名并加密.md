**【描述】**

敏感数据传输过程中存在被窃取和恶意篡改的可能。使用安全的加密算法加密传输对象可以保护数据，防止对象被非法篡改，保持其完整性。在以下场景中，需要对对象加密和数字签名来保证数据安全：



序列化或传输敏感数据

没有使用类似于SSL传输通道

敏感数据需要长久保存（比如在硬盘驱动器上）

关于加密算法的规定请参考公司规范库发布的《密码算法应用规范》。
