# G.EXP.06-CPP 避免使用全局变量

- **规则ID**：f8c518af-0678-4bf5-98e3-88e801d0b237
- **更新时间**：2025-03-25 19:22:19

---

**【问题级别】**

一般

**【描述】**

使用全局变量会导致业务代码和全局变量之间产生数据耦合，并且很难跟踪数据的变化，建议避免使用全局变量。



如果需要使用全局变量，建议将数据进行封装，并提供修改数据的接口，使用者只通过接口修改数据。此外，还需要注意避免因并发而出现竞争条件。



在不同编译单元中的全局变量以及全局常量的初始化顺序没有被严格定义，使用时需要注意它们的初始化是否有互相依赖。



该条款同样适用于命名空间作用域下的变量。

**【正确示例】**

```
constexpr int SOME_VALUE = 10; // 符合：使用全局常量

```
**【错误示例】**

```
int g_someValue = 10;          // 不符合：使用全局变量

void ConsumeValue()
{
    ... // 此处并不能确定g_someValue是不是10，并且很难跟踪数据的变化
}

```
**【修复建议】**

按照实际情况排查是否确实需要使用全局变量，对于不需要使用的，修改为局部变量
