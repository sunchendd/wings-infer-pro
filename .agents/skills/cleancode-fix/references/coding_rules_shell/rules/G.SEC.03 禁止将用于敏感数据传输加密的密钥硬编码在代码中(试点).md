**【描述】**

如果传输加密密钥是硬编码的，当数据密文在网络上（尤其是跨越非可信网络）传输时，由于密文数据暴露在传输过程中，密钥遭暴力破解的可能性大大增加。一旦密钥被黑客获取并公布，华为在全球不同地区运行的此类设备都存在被破解/攻击的可能。因此必须保证用户对传输加密密钥的控制。
