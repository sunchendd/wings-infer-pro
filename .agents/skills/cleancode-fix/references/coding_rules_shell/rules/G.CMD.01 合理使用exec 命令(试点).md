# G.CMD.01 合理使用exec 命令(试点)

- **规则ID**：4f031420-9666-4580-8f28-874a6e726ee0
- **更新时间**：2025-06-05 04:30:00

---

**【问题级别】**

严重

**【描述】**

exec命令执行不会创建新子进程，执行完毕后会直接退出当前进程，不会执行后续的命令。

**【正确示例】**

```
#!/bin/bash
  ls ./
  ls /home

```
**【错误示例】**

```
#!/bin/bash
  exec ls ./
  # 上条ls /xxx 命令执行完毕后 ls /home将不会被执行
  exec ls /home

```
**【修复建议】**

不使用exec执行命令  

【例外】  

如果需要执行出错后就退出，可以使用exec命令。
