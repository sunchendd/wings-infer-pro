# G.TYP.15 其它类型转化为数字使用Number()，并且应显式检查返回值是否为NaN

- **规则ID**：98c68726-4e37-424c-a9e5-c9cc8e1712b2
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

提示

**【描述】**

不推荐使用parseInt函数来做转换数字的操作，因为parseInt只处理字符串的前缀数字，这可能与预期不一致。其他类型转化为数字建议使用Number()，紧接着应该显式检查返回值是否为NaN。

**【正确示例】**

```
##### 场景1：其它类型转换为数字
- 修复示例：使用Number转换为数字，并在转换后，使用Number.isNaN进行判断。
```javascript
let num = Number('123asd123'); 
if(Number.isNaN(num)){
    ...
}
```

```
**【错误示例】**

```
##### 场景1：其它类型转换为数字
- 错误示例1：在做运算时，没有做显式转换。

```javascript
'2' - 1; // 1
'223abc' - 1; // NaN
```
- 错误示例2：使用parseInt方法做转换。

```javascript
parseInt("123asd123", 10); // 返回123，由于parseInt只处理字符串的前缀数字，这可能与预期不一致
```

```
**【修复建议】**

Number() 将其它类型转换为数字的规则如下:

 - boolean值，true和false被转换为1和0；

- 数值，不变（会识别十进制/八进制-0开头/十六进制-0x开头）

- null，返回0

- undefined，返回NaN

- 字符串 :

    1. 如果字符串中只包含数字（包括正负号），转换为十进制数值，数值前面有0的会去掉0;

    2. 浮点数，转换为相应的浮点数，但是后面小数位只含0的会去掉0;

    3. 十六进制格式‘0x’，转换为有效的十进制值（Number()会自动把字符串形式的十进制数和十六进制数都转换为十进制，但是不识别八进制，会被当做十进制数处理。）;

    4. 字符串为空或空白符，转换为0;

    5. 包含除上述之外的字符，转换为NaN;

    

按上述规则转换后，要显式检查返回值是否为NaN。
