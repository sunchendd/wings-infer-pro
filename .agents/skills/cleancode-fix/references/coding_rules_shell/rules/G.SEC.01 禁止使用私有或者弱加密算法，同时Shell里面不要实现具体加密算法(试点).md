# G.SEC.01 禁止使用私有或者弱加密算法，同时Shell里面不要实现具体加密算法(试点)

- **规则ID**：00dae7a2-733a-4e35-9f86-f6786d1c5ad5
- **更新时间**：2025-06-05 04:30:01

---

**【问题级别】**

严重

**【描述】**

禁止使用私有算法或者弱加密算法（比如DES，SHA1等）。应该使用经过验证的、安全的、公开的加密算法。

有关如何选择和使用加密算法的更多信息，请参考《华为密码算法应用规范》。

**【正确示例】**

```
#!/bin/bash
  openssl dgst -sha512 /tmp/test.txt

```
**【错误示例】**

```
#!/bin/bash
  # 不符合：不符合密码算法应用规范
  openssl dgst -sha /tmp/test.txt

```
**【修复建议】**

- openssl dgst命令使用安全的加密算法('-sha256', '-sha384', '-sha512', '-sha512-256', '-sha3-256', '-sha3-384', '-sha3-512')

- openssl enc命令使用安全的加密算法('-aes-128-ctr', '-aes-128-ofb', '-aes-192-ctr', '-aes-192-ofb', '-aes-256-ctr', '-aes-256-ofb', '-chacha20')

- 不要使用私有加密算法

- 使用加密算法参考《华为密码算法应用规范》。
