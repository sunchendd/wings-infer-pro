# G.TYP.BOL.05 非必要时，布尔运算应使用逻辑运算符( &&/||)而非位运算符 (&/|)-试行

- **规则ID**：43ef5a46-6740-489a-964f-edab52446a63
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

提示

**【描述】**

位运算不支持短路（short-circuiting），所以会影响性能。逻辑运算符则支持短路。

**【正确示例】**

```
let (x,y) = (true, false);
if x && !y {} //  逻辑运算符，支持短路

```
**【错误示例】**

```
let (x,y) = (true, false);
if x & !y {} //  位运算符，不支持短路

```
