# G.FMT.03 使用统一的大括号换行风格

- **规则ID**：88ecf4c4-40e5-4183-b511-47e543223c67
- **更新时间**：2026-04-07 04:10:04

---

**【问题级别】**

一般

**【描述】**

选择并统一使用一种大括号换行风格，避免多种风格并存。

**【正确示例】**

```
##### 场景1：选择K&R风格，但是使用时没有保持风格一致
- 修复示例：选择并统一使用K&R风格。

```c
struct MyType {     // 符合：跟随语句放行末，前置1空格
    ...
};                  // 符合：右大括号后面紧跟分号

int Foo(int a)
{                   // 符合：函数左大括号独占一行，放行首
    if (a > 0) {    // 符合：左大括号跟随语句放行末，前置1空格
        ...
    } else {        // 符合：右大括号、"else"、以及后续的左大括号均在同一行
        ...
    }
    ...
}                   // 符合：右大括号独占一行
```
##### 场景2：选择Allman风格，但是使用时没有保持风格一致
- 修复示例：选择并统一使用Allman风格。

```c
struct MyType
{               // 符合：另起并独占一行
    ...
};
int Foo(int a)
{               // 符合：左大括另起并独占一行
    if (a > 0)
    {
        ...
    }
    else        // 符合：前后的左右大括号均独占一行，所以 'else' 也只能独占一行
    {
        ...
    }
    ...
}
```
