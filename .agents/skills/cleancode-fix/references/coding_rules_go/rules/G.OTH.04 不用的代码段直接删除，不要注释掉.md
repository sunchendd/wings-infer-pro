# G.OTH.04 不用的代码段直接删除，不要注释掉

- **规则ID**：32fe496a-b1f9-478b-8e23-8a682a3eec6b
- **更新时间**：2026-04-07 04:20:02

---

**【问题级别】**

一般

**【描述】**

被注释掉的代码，无法被正常维护；当企图恢复使用这段代码时，极有可能引入易被忽略的缺陷。



正确的做法是，不需要的代码直接删除掉。若再需要时，可以通过版本管理工具（例如git）获取到代码的历史记录进行恢复。



这里说的“注释掉”的方式，包括 `/* */` 和 `//`。

**【正确示例】**

```
##### 场景1：不用的代码未删除，而是注释了
- 修复示例：删除不用的代码

  ```go
  func TestUnaryOperation() { // 符合
  }
  ```


```
**【错误示例】**

```
##### 场景1：不用的代码未删除，而是注释了
- 错误示例：

  ```go
  func TestUnaryOperation() {
      // a++
      // b--
  }
  ```


```
**【修复建议】**

不用的代码段直接删除
