# G.TYP.SLC.01 宜使用迭代器而非下标遍历切片和数组

- **规则ID**：d0434819-1f10-4f83-8a73-b936b6eb0b1f
- **更新时间**：2026-04-07 04:40:00

---

**【问题级别】**

提示

**【描述】**

在 for 循环中使用索引下标访问有可能导致边界错误。

**【正确示例】**

```
```
let vec = vec!['a', 'b', 'c'];
for i in vec {
    println!("{}", i);
}
```

```
**【错误示例】**

```
```
let vec = vec!['a', 'b', 'c'];
for i in 0..vec.len() {
    println!("{}", vec[i]);
}
```

```
**【修复建议】**

遍历切片和数组时，宜使用迭代器来避免索引访问。
