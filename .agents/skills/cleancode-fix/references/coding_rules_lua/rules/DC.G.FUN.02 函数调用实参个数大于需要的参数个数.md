# DC.G.FUN.02 函数调用实参个数大于需要的参数个数

- **规则ID**：ab7b3e69-84b0-4108-8fdd-4f59bd714e2b
- **更新时间**：2026-04-07 04:45:01

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：实参个数太多：函数"xxx"需要xx个参数，而实参个数为xx

**【正确示例】**

```
```
function foo(para) 
    ...
end

do
    ...
    foo(1) 
end
```

```
**【错误示例】**

```
```
function foo(para) 
    ...
end

do
    ...
    foo(1, 2) 
end
```

```
**【修复建议】**

多于函数形参个数的实参会被忽略，这很可能是编码疏忽而非有意设计，进而隐藏着非预期的功能错误，因此应确保函数调用实参个数不大于形参个数。
