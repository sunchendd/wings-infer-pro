# G.EXP.42-CPP 避免使用goto语句

- **规则ID**：565b6908-b7f3-4203-8ea2-0aa5cbdb3cd4
- **更新时间**：2025-03-25 19:22:31

---

**【问题级别】**

一般

**【描述】**

goto语句破坏了程序结构，使程序可读性变差，难以理解，难以查错。



除非确实需要，否则应避免使用goto语句。在使用goto语句时，建议只向下跳转。

**【正确示例】**

```
##### 场景1：使用goto导致逻辑不清晰
- 修复示例1：非必须场景，不应使用goto语句，可使用结构化的控制语句（如if、for、while等）来实现程序逻辑。

```cpp
void DoSomething()
{
    ...
    if (...) {
        DoSomethingA(); // 符合
    }

    if (...) {
        DoSomethingB(); // 符合
    }

    if (...) {
        DoSomethingC(); // 符合
    }
    ...
}
```

```
**【错误示例】**

```
##### 场景1：使用goto导致逻辑不清晰
- 错误示例：

```cpp
A:
if (...) {
    goto B; // 不符合：使用了goto语句
}
C:
if (...) {
    goto A; // 不符合：使用了goto语句
} else if (...) {
    goto B; // 不符合：使用了goto语句
} else {
    goto C; // 不符合：使用了goto语句
}
B:
...
```

```
**【修复建议】**

避免使用goto语句
