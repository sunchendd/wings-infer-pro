# G.TYP.SLC.02 应保证数组索引在有效范围内

- **规则ID**：705f7ddf-6f45-45d5-8e95-8c9a113da304
- **更新时间**：2026-04-07 04:40:00

---

**【问题级别】**

一般

**【描述】**

RUST 的数组/切片越界访问不会出现内存被越界读写的后果，但会导致 panic。使用索引访问数组的时候需要保证索引值在有效范围。

**【正确示例】**

```
```
fn main() {
    fn get_index() -> usize {
        5
    }
    let arr = [1, 2, 3, 4, 5];
    let index = get_index();
    // 符合：校验索引是否越界
    if index >= arr.len() {
        // 错误处理示例，此处产品应根据业务场景，选择合适的处理方式
        panic!("index out of bounds");
    }
    let _ = arr[index]; 
}
```

```
**【错误示例】**

```
```
fn main() {
    let arr = [1, 2, 3, 4, 5];
    // 不符合：越界访问
    let _ = arr[5]; 
}
```

```
**【修复建议】**

使用索引访问时需校验索引有效性，或使用安全的 `get` 方法
