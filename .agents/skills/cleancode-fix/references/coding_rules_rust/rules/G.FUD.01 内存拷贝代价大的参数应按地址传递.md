# G.FUD.01 内存拷贝代价大的参数应按地址传递

- **规则ID**：a6e6be1c-a572-4dea-aff1-111469c798ed
- **更新时间**：2026-04-07 04:40:01

---

**【问题级别】**

提示

**【描述】**

通过值传递的参数可能会导致不必要的 memcpy 拷贝，这可能会造成性能损失。

**【正确示例】**

```
```
#[derive(Clone, Copy)]
struct TooLarge([u8; 2048]);
// Good
fn foo(v: &TooLarge) {}
```

```
**【错误示例】**

```
```
#[derive(Clone, Copy)]
struct TooLarge([u8; 2048]);
// Bad
fn foo(v: TooLarge) {}
```

```
**【修复建议】**

Rust 中的所有权转移也意味着一次栈内存的拷贝，因此所有非引用和指针类型的参数传递都是值传递，需要考虑内存拷贝的代价，设计合理的参数类型：



- 对于输入参数，拷贝代价小的类型使用值传递，拷贝代价大的类型传递只读引用。

- 对于返回类型，如果拷贝代价大，宜设计传递可写借用参数并返回它。
