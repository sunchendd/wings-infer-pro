# G.EXP.04 正确使用双方括号和方括号

- **规则ID**：910e5d2f-24ef-48f0-bbfe-aa1eda0ed7dc
- **更新时间**：2026-04-07 04:30:01

---

**【问题级别】**

严重

**【描述】**

1. 在 [[ 和 ]] 之间不会有路径名称扩展或单词分割发生，所以使用 [[ ... ]] 能够减少错误。

2. [[ ... ]] 允许正则表达式匹配，而 [ ... ] 不允许，因此在需要进行正则表达式匹配时请使用[[ ... ]]。

3. Shell中使用=~判断某字符串是否包含特定模式，如下实例。右侧规则不要用引号包含。如果包含引号，正则表达式规则不会展开，执行会异常。

**【正确示例】**

```
```shell
#!/bin/bash
file_name="test.sh"
if [[ "${file_name}" =~ \.sh ]];then
    echo "found sh"
fi
```

```
**【错误示例】**

```
```shell
#!/bin/bash
file_name="test.sh"
if [ "${file_name}" =~ \.sh ];then
    echo "found sh"
fi
```

```
**【修复建议】**

在 [[ 和 ]] 之间不会有路径名称扩展或单词分割发生，所以使用 [[ ... ]] 能够减少错误。另外，[[ ... ]]允许正则表达式匹配，而 [ ... ] 不允许，因此在需要进行正则表达式匹配时请使用[[ ... ]]。
