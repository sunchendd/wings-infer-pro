# G.TYP.ARR.03 当数组元素为原生数据类型（Primitive），排序时宜使用非稳定排序-试行

- **规则ID**：390c264a-2bf9-4170-a5c7-bb995b820f93
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

一般

**【描述】**

稳定排序会消耗更多的内存和 CPU 周期，相对而言，非稳定排序性能更佳。



当然，在必须要稳定排序的场合，不应该使用非稳定排序。



注： Vec<T> 动态数组也适用此规则。

**【正确示例】**

```
let mut vec = vec![2, 1, 3];
vec.sort_unstable(); // unstable sort

```
**【错误示例】**

```
let mut vec = vec![2, 1, 3];
vec.sort();  // stable sort

```
