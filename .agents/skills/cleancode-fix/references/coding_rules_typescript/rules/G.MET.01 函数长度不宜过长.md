# G.MET.01 函数长度不宜过长

- **规则ID**：8ef55063-484d-478f-963e-3e2c600fead1
- **更新时间**：2025-06-05 04:35:01

---

**【问题级别】**

提示

**【描述】**

简短的函数易理解、易维护、易扩展、易测试。函数长度建议不超过100行，函数内的业务逻辑处理建议最好不超过50行（非空非注释）（即：尽量让一个函数能在一个电脑屏幕内看完）。

**【正确示例】**

```
函数长度不宜过长

```
**【错误示例】**

```
函数长度超过100行

```
**【修复建议】**

函数长度不宜过长
