# G.TYP.04-TS 使用接口来声明对象类型

- **规则ID**：1dd916cd-1bec-4ace-b22a-a5f428887695
- **更新时间**：2026-04-07 04:35:02

---

**【问题级别】**

提示

**【描述】**

声明对象类型时，接口和类型别名几乎等价的，为了项目统一，这里推荐优先选用接口。

**【正确示例】**

```
##### 场景1：对象类型
- 修复示例：基本类型使用类型别名

```typescript
type Name = string;
interface Dog {
  wong();
}
interface Cat {
  miao();
}
```

```
**【错误示例】**

```
##### 场景1：对象类型
- 错误示例：使用类型别名来定义对象类型

```typescript
type Foo = {
  name: string;
  age: number;
  walk: (miles: number) => void;
};
```

```
**【修复建议】**

1.能用接口实现，就优先使用接口。

 2.对于基本类型、联合类型、元组，只能使用类型别名。
