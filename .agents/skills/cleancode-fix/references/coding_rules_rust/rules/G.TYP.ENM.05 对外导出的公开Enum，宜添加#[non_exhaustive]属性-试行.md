# G.TYP.ENM.05 对外导出的公开Enum，宜添加#[non_exhaustive]属性-试行

- **规则ID**：b0c51b3c-a131-49e7-871f-e16fd54e664b
- **更新时间**：2025-06-05 04:40:02

---

**【问题级别】**

提示

**【描述】**

作为对外公开的 Enum，为了保持稳定性，应该使用 #[non_exhaustive]属性，避免因为将来Enum 枚举变体的变化而影响到下游的使用。

**【正确示例】**

```
#[non_exhaustive]
enum E {
    A,
    B,
}

```
**【错误示例】**

```
enum E {
    A,
    B,
    #[doc(hidden)]
    _C, // 这里用 下划线作为前缀定义的变体，作为隐藏的变体，不对外展示
}
// 用户无法自定义实现该 枚举的方法，达到一种稳定公开枚举的目的。

```
