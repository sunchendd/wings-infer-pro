# DC.G.VAR.08 局部变量使用前是否多次赋值检查

- **规则ID**：f3556b17-f34c-4dc8-8a44-227628762698
- **更新时间**：2026-04-07 04:45:02

---

**【问题级别】**

严重

**【描述】**

行号：xxx，列号：xxx：局部变量：“xxx”在第一次使用前多次赋值，上一次赋值在第xx行

**【正确示例】**

```
```
local val = get_value()
if val == 1 then
    ...
End
```

```
**【错误示例】**

```
```
local val = 0
val = get_value() -- Bad: 对变量val进行了二次赋值
if val == 1 then
    ...
End
```

```
**【修复建议】**

在读取前对局部变量多次赋值属于冗余赋值，应予以避免。
