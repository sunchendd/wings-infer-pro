# G.TYP.14 使用显式的类型转换

- **规则ID**：61b2b3ef-2e36-47c3-a122-451dacd8ffbe
- **更新时间**：2026-04-07 04:35:01

---

**【问题级别】**

一般

**【描述】**

在JavaScript中，有许多不同的方式进行类型转换。其中有些可能难于阅读和理解，因此，应该使用显式的类型转换。

**【正确示例】**

```
##### 场景1：字符串类型
- 修复示例：如果字符串 foo 中包含字符 '.'，则将变量 baz 设为 true，否则设为 false

```javascript
const baz = foo.indexOf('.') !== -1;
```
##### 场景2：数字类型
- 修复示例：将变量 foo 显式转换为数字类型，并将转换后的结果赋值给变量 num。

```javascript
const num = Number(foo);
```

```
**【错误示例】**

```
##### 场景1：字符串类型
- 错误示例：找到字符串 foo 中第一个出现 '.' 的位置，并将其隐式按位取反后赋值给变量 baz

```javascript
const baz = ~foo.indexOf('.');
```
##### 场景2：数字类型
- 错误示例：将变量 foo 通过 + 号隐式转换为数字类型，并将结果赋值给变量 num。

```javascript
const num = +foo;
```

```
**【修复建议】**

使用显式的类型转换。
