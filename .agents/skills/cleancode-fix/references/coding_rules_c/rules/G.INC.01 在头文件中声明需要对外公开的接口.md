# G.INC.01 在头文件中声明需要对外公开的接口

- **规则ID**：93cf1beb-90aa-4c88-91db-1467847951cb
- **更新时间**：2026-04-07 04:10:02

---

**【问题级别】**

严重

**【描述】**

如果在头文件中只有内联函数的声明而没有定义，当其他源文件包含该头文件并调用内联函数时，编译器无法找到内联函数的定义，从而导致链接错误。因此，应该在头文件中提供内联函数的定义。

**【正确示例】**

```
##### 场景1：头文件中未定义内联函数
- 修复示例1：

  ```c
  // testcase.h
  inline void Fun() {  // 符合
      ...
  }
  ```

```
**【错误示例】**

```
##### 场景1：头文件中未定义内联函数
- 错误示例：

  ```c
  // testcase.h
  inline void Fun();  // 不符合：头文件中未定义内联函数
  ```

```
**【修复建议】**

内联函数的定义要放在头文件中。
