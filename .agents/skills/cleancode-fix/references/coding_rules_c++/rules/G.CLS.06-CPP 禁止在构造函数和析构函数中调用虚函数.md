# G.CLS.06-CPP 禁止在构造函数和析构函数中调用虚函数

- **规则ID**：6384c7ed-b309-4e9c-ae0a-750edcf241e2
- **更新时间**：2025-03-25 19:22:07

---

**【问题级别】**

严重

**【描述】**

在构造函数和析构函数中调用当前对象的虚函数，会导致未实现多态的行为。



在C++中，一个基类一次只构造一个完整的对象。

**【正确示例】**

```
##### 场景1：在构造函数和析构函数中调用虚函数
- 修复示例：

```cpp
class Message {
public:
    void Bar(); // 非虚函数，且此函数内部也未调用虚函数
    Message()
    {
        ...
        Bar(); // 符合：调用非虚函数
    }
    ~Message()
    {
        ...
        Bar(); // 符合：调用非虚函数
    }
    ...
};
```

```
**【错误示例】**

```
##### 场景1：在构造函数和析构函数中调用虚函数
- 错误示例：

```cpp
class Message {
public:
    virtual void Foo();
    Message()
    {
        ...
        Foo(); // 不符合：调用虚函数
    }
    ~Message()
    {
        ...
        Foo(); // 不符合：调用虚函数
    }
    ...
};
```

```
